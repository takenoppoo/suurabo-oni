別冊章末問題の解答

1.　次の和を \(n\) の式で表せ（因数分解した形で答えよ）。 \[\sum_{k=1}^{n}\left(4 k^{2} + 2 k + 3\right)\]

公式を使えるように分ける

\(\sum_{k=1}^n k^2=\dfrac{n(n+1)(2n+1)}6,\ \ \sum_{k=1}^n k=\dfrac{n(n+1)}2,\ \ \sum_{k=1}^n c=cn\)。

公式に代入する

\[\sum_{k=1}^n\left(4 k^{2} + 2 k + 3\right)=4\cdot\dfrac{n(n+1)(2n+1)}{6}+2\cdot\dfrac{n(n+1)}{2}+3\,n\]

共通因数でくくる

\(n\) を くくり、通分して整理する。

\[=\dfrac{n \left(4 n^{2} + 9 n + 14\right)}{3}\]

（例題1の型）

【答案】

\[\dfrac{n \left(4 n^{2} + 9 n + 14\right)}{3}\]

答

2.　数列 \(1,\ 7,\ 19,\ 37,\ 61,\ \cdots\) の一般項 \(a_n\) を求めよ。

階差数列を調べる

隣り合う項の差 \(b_n=a_{n+1}-a_n\) を求める。

\[b_1=6,\ b_2=12,\ b_3=18,\ b_4=24\]

公差 \(6\) の等差数列だから

\[b_n=6+(n-1)\times\left(6\right)=6 n\]

公式を使う

\(n\geqq2\) のとき

\[a_n=a_1+\sum_{k=1}^{n-1}b_k=1+\sum_{k=1}^{n-1}\left(6 k\right)\]

Σを計算する

\[=1+\left(6\right)\cdot\dfrac{(n-1)n}{2}+\left(0\right)(n-1)=3 n^{2} - 3 n + 1\]

\(n=1\) のとき

\(a_1=1\) で、与えられた初項 \(a_1=1\) と一致するので、\(n=1\) でも成り立つ。

（例題2の型）

【答案】

\[a_n=3 n^{2} - 3 n + 1\]

答

3.　次の和を \(n\) の式で表せ。 \[\sum_{k=1}^{n}\dfrac{1}{k(k+3)}\]

部分分数に分ける

\[\dfrac{1}{k(k+3)}=\dfrac{1}{3}\left(\dfrac1k-\dfrac1{k+3}\right)\]

書き並べる

\(\sum_{k=1}^n\dfrac{1}{k(k+3)}\) は、\(\dfrac{1}{3}\) と次の和の積。

\[\left(\dfrac11-\dfrac1{4}\right)+\left(\dfrac12-\dfrac1{5}\right)+\left(\dfrac13-\dfrac1{6}\right)+\cdots+\left(\dfrac1{n}-\dfrac1{n+3}\right)\]

消える項に注意

途中の項は消え、最初の 3 個の正の項と最後の 3 個の負の項だけ残る。

\[\left(\dfrac1{1}+\dfrac1{2}+\dfrac1{3}\right)-\left(\dfrac1{n+1}+\dfrac1{n+2}+\dfrac1{n+3}\right)\]

まとめる

\[S_n=\dfrac{1}{3}\times\{\cdots\}=\dfrac{n \left(11 n^{2} + 48 n + 49\right)}{18 \left(n + 1\right) \left(n + 2\right) \left(n + 3\right)}\]

（例題3の型）

【答案】

\[\dfrac{n \left(11 n^{2} + 48 n + 49\right)}{18 \left(n + 1\right) \left(n + 2\right) \left(n + 3\right)}\]

答

4.　次の和 \(S_n\) を求めよ。 \[S_n=\sum_{k=1}^{n}k\cdot\left(4\right)^{k}\]

和を書き並べる

\[S_n=\left(4\right)+2\cdot\left(4\right)^2+3\cdot\left(4\right)^3+\cdots+n\cdot\left(4\right)^n\]

\(4\) 倍して1項ずらす

\[\left(4\right)S_n=\left(4\right)^2+2\cdot\left(4\right)^3+\cdots+(n-1)\left(4\right)^n+n\cdot\left(4\right)^{n+1}\]

辺々ひく

\((1-r)S_n\) は等比数列の和と端の項だけになる。

\[(1-\left(4\right))S_n=\left(4\right)+\left(4\right)^2+\cdots+\left(4\right)^n-n\cdot\left(4\right)^{n+1}\]\[-3\,S_n=\dfrac{\left(4\right)\left(\left(4\right)^n-1\right)}{\left(4\right)-1}-n\cdot\left(4\right)^{n+1}\]

\(S_n\) を求める

\[S_n=\dfrac{4 \cdot 4^{n} n}{3} - \dfrac{4 \cdot 4^{n}}{9} + \dfrac{4}{9}\]

（例題4の型）

【答案】

\[S_n=\dfrac{4 \cdot 4^{n} n}{3} - \dfrac{4 \cdot 4^{n}}{9} + \dfrac{4}{9}\]

答

5.　数列 \(\{a_n\}\) の初項から第 \(n\) 項までの和 \(S_n\) が \(S_n=2 n^{2} - 3 n + 2\) で表されるとき、一般項 \(a_n\) を求めよ。

\(a_1\) を求める

\(a_1=S_1\)。

\[a_1=1\]

\(n\geqq2\) のとき

\(a_n=S_n-S_{n-1}\)。

\[a_n=\left(2 n^{2} - 3 n + 2\right)-\left\{2 n^{2} - 7 n + 7\right\}=4 n - 5\]

\(n=1\) を確かめる

\(4 n - 5\) に \(n=1\) を代入すると \(-1\)。\(a_1=1\) と一致しないので、\(a_1\) は別に書く。

（例題5の型）

【答案】

\[a_1=1,\ \ n\geqq2\ \text{のとき}\ a_n=4 n - 5\]

答

6.　\(\displaystyle\sum_{k=1}^{n}k(k+5)\) を \(n\) の式で表せ。

展開して分ける

\[\sum_{k=1}^{n}k(k+5)=\sum k^2+5\sum k=\dfrac{n(n+1)(2n+1)}{6}+5\cdot\dfrac{n(n+1)}{2}\]

共通因数でくくる

\[=\dfrac{n(n+1)}{6}\{(2n+1)+15\}=\dfrac{n \left(n + 1\right) \left(n + 8\right)}{3}\]

確認

\(n=10\) で \(660\) に一致。

（例題6の型）

【答案】

\[\dfrac{n \left(n + 1\right) \left(n + 8\right)}{3}\]

答

7.　数列 \(4,\ 7,\ 11,\ 16,\ 22,\ 29,\ \cdots\) の階差数列が等差数列であるとき、一般項 \(a_n\) を求めよ。

階差数列

階差数列 \(b_n=3+1(n-1)\)。\(a_1,a_2,\ldots\)：

\[4,\ 7,\ 11,\ 16,\ 22,\ 29,\ \cdots\]

一般項の公式

\[a_n=a_1+\sum_{k=1}^{n-1}b_k=4+\sum_{k=1}^{n-1}(k + 2)\]

計算

\[a_n=\dfrac{n^{2}}{2} + \dfrac{3 n}{2} + 2\]

\(n=1\) でも成り立つ。

（例題7の型）

【答案】

\[a_n=\dfrac{n^{2}}{2} + \dfrac{3 n}{2} + 2\]

答

8.　\(\displaystyle\sum_{k=1}^{9}\dfrac{1}{(2k+1)(2k+1+2)(2k+1+4)}\) を計算せよ。

部分分数

\[\dfrac1{(2k+1)(2k+1+2)(2k+1+4)}=\dfrac1{4}\left\{\dfrac1{(2k+1)(2k+1+2)}-\dfrac1{(2k+1+2)(2k+1+4)}\right\}\]

和をとる

隣り合う項が打ち消し合い、最初と最後だけが残る。

\[\dfrac1{4}\left\{\dfrac1{3\cdot5}-\dfrac1{21\cdot23}\right\}\]

計算

\[\dfrac{13}{805}\]

（例題8の型）

【答案】

\[\dfrac{13}{805}\]

答

9.　\(\displaystyle\sum_{k=1}^{5}k\cdot4^{k-1}\) を求めよ。

\(S\) と \(rS\)

\[S=1+2r+3r^2+\cdots+5r^{4}\]\[rS=\ \ \ \ \ r+2r^2+\cdots+4r^{4}+5r^{5}\]

引く

\[(1-r)S=1+r+r^2+\cdots+r^{4}-5r^{5}\]

\(r=4\) を代入して計算。

値

\[S=1593\]

（例題9の型）

【答案】

\[1593\]

答

10.　数列 \(\{a_n\}\) の初項から第 \(n\) 項までの和が \(S_n=2 n^{2} + 3 n\) であるとき、一般項 \(a_n\) を求めよ。

\(n\geqq2\)

\[a_n=S_n-S_{n-1}=(2 n^{2} + 3 n)-(3 n + 2 \left(n - 1\right)^{2} - 3)=4 n + 1\]

\(n=1\) の確認

\[a_1=S_1=5,\qquad 4 n + 1\ \text{に }n=1\text{ を代入}=5\]

一致するので全ての \(n\geqq1\) で成り立つ。

（例題10の型）

【答案】

\[a_n=4 n + 1\]

答
