1.　\(\left(5 x - 2 y\right)^{6}\) の展開式における \(x^{2}y^{4}\) の項の係数を求めよ。

一般項を書く

\(\left(5 x - 2 y\right)^{6}\) の展開式の一般項は\[{}_{6}\mathrm{C}_{r}\left(5 x\right)^{6-r}\left(- 2 y\right)^{r}\]

\(r\) は 0 から 6 までの整数。

目的の項になる \(r\) を決める

\(x^{2}y^{4}\) の \(y\) の指数が \(4\) なので \(r=4\)。（\(x\) の指数は \(6-4=2\) で一致。）

係数を計算する

\[{}_{6}\mathrm{C}_{4}\left(5 x\right)^{2}\left(- 2 y\right)^{4}=15\times25\times16=6000\]

よって係数は \(6000\)。

（例題1の型）

【答案】

\[6000\]

答

2.　\(\left(3 x^{2} + \dfrac{1}{x}\right)^{7}\) の展開式における\(x^{2}\) の項の係数を求めよ。

一般項を書く

\[{}_{7}\mathrm{C}_{r}\left(3 x^{2}\right)^{7-r}\left(\dfrac{1}{x}\right)^{r}={}_{7}\mathrm{C}_{r}\cdot 3^{7-r}\cdot (1)^{r}\cdot x^{2(7-r)+(-1)r}\]

\(x\) の指数を整理して、条件の式を作る

\[2(7-r)+(-1)\cdot r=- 3 r + 14\]

これが \(2\) に等しいので

\[- 3 r + 14=2\ \Rightarrow\ r=4\]

係数を計算する

\[{}_{7}\mathrm{C}_{4}\cdot 3^{3}\cdot(1)^{4}=35\times27\times1=945\]

（例題2の型）

【答案】

\[945\]

答

3.　\(\left(x^{2} + 3 x + 1\right)^{4}\) の展開式における \(x^{2}\) の項の係数を求めよ。

一般項（多項定理）を書く

\(x^2\) を \(i\) 個、\(3x\) を \(j\) 個、\(1\) を \(l\) 個とる（\(i+j+l=4\)）。係数は

\[\dfrac{4!}{i!\,j!\,l!}\,(x^2)^i(3x)^j(1)^l\]

\(x^{2}\) になる組 \((i,j,l)\) を数え上げる

\(x\) の指数：\(2i+j=2\)、個数：\(i+j+l=4\) を同時に満たす非負整数の組は

\[(0,2,2),\ (1,0,3)\]

各組の係数を計算する

\[\begin{aligned}(i,j,l)=(0,2,2):\ \dfrac{4!}{0!\,2!\,2!}\cdot 1^{0}(3)^{2}(1)^{2}=54\\ (i,j,l)=(1,0,3):\ \dfrac{4!}{1!\,0!\,3!}\cdot 1^{1}(3)^{0}(1)^{3}=4\end{aligned}\]

合計する

\[54+4=58\]

（例題3の型）

【答案】

\[58\]

答

4.　\(n=7\) とする。(1) \({}_{7}\mathrm{C}_{0}+2{}_{7}\mathrm{C}_{1}+4{}_{7}\mathrm{C}_{2}+\cdots+128{}_{7}\mathrm{C}_{7}\) の値を求めよ。(2) \({}_{7}\mathrm{C}_{0}+{}_{7}\mathrm{C}_{2}+{}_{7}\mathrm{C}_{4}+{}_{7}\mathrm{C}_{6}\) の値を求めよ。

二項定理に \(a=1,\ b=2\) を代入する

\((1+x)^n=\sum_{r}{}_n\mathrm{C}_r x^r\) に \(x=2\) を入れる。

\[(1+2)^{7}=\sum_{r=0}^{7}2^{r}\,{}_{7}\mathrm{C}_{r}\]

(1) の値

\[{}_{7}\mathrm{C}_{0}+2{}_{7}\mathrm{C}_{1}+4{}_{7}\mathrm{C}_{2}+\cdots+128{}_{7}\mathrm{C}_{7}=3^{7}=2187\]

(2) \(x=1\) と \(x=-1\) を代入して差・和を作る

\((1+1)^{7}=C_0+C_1+C_2+\cdots+C_{7}\)、\((1-1)^{7}=C_0-C_1+C_2-\cdots-C_{7}=0\)。2式を足すと、偶数番目の和の2倍：

\[2\,(C_0+C_2+C_4+\cdots)=2^{7}\ \Rightarrow\ C_0+C_2+C_4+\cdots=2^{6}=64\]

（例題4の型）

【答案】

\[\text{(1) }2187,\quad \text{(2) }64\]

答

5.　\(9^{27}\) を \(64\) で割った余りを求めよ。

底を \(p+1\) の形に直して二項定理を使う

\(9=8+1\) なので

\[9^{27}=(8+1)^{27}=1+{}_{27}\mathrm{C}_{1}\cdot 8+{}_{27}\mathrm{C}_{2}\cdot 8^2+\cdots\]

\(8^2\) で割り切れる部分を見分ける

\(8^2\) 以降の項はすべて \(8^2=64\) の倍数。残るのは最初の2項：

\[1+27\times8=217\]

余りを求める

\[217=64\times3+25\]

よって余りは \(25\)。

（例題5の型）

【答案】

\[25\]

答

6.　\(\left(x+\dfrac{3}{x}\right)^{10}\) の展開式における定数項を求めよ。

一般項

\[{}_{10}C_r(x)^{10-r}\left(\dfrac{3}{x}\right)^r={}_{10}C_r\cdot1^{10-r}3^{r}\,x^{10-2r}\]

\(x^{0}\) の項

\(10-2r=0\) より \(r=5\)。

係数

\[{}_{10}C_{5}\cdot1^{5}\cdot3^{5}=61236\]

（例題6の型）

【答案】

\[61236\]

答

7.　\((1-x+2x^2)^{5}\) の展開式における \(x^3\) の係数を求めよ。

3つの項の展開

\((1-x+2x^2)^{5}\) の一般項は \(\dfrac{5!}{p!\,q!\,s!}(-x)^p(2x^2)^q\cdot1^s\)。

\(x^3\) になる組

\(p+2q=3\)：\((p,q)=(3,0)\)、\((p,q)=(1,1)\)。

係数

\[-10-40=-50\]

（例題7の型）

【答案】

\[-50\]

答

8.　\({}_{9}C_1\cdot1+{}_{9}C_2\cdot2+\cdots+{}_{9}C_{9}\cdot9\) の値を求めよ。

\(k\,{}_nC_k\) の変形

\(k\,{}_nC_k=n\,{}_{n-1}C_{k-1}\)。

和の計算

\[\sum_{k=1}^{n}k\,{}_nC_k=n\sum_{k=1}^{n}{}_{n-1}C_{k-1}=n\cdot2^{n-1}\]

値

\[9\cdot2^{8}=2304\]

（例題8の型）

【答案】

\[2304\]

答

9.　\(12^{15}\) を \(121\) で割った余りを求めよ。

二項定理で展開

\(12=11+1\) とみて

\[(11+1)^{15}=1+15\cdot11+(11^2\text{の倍数})\]

余り

\(11^2=121\) で割った余り：

\[1+165=45\ (\text{ただし }45<121)\]

（例題9の型）

【答案】

\[45\]

答

10.　\(\displaystyle\sum_{k\,(\text{偶数})}{}_{12}C_k\,2^k\) の値を求めよ。

二項定理

\[(2+1)^n+(2-1)^n=2\sum_{k\ \text{偶数}}{}_nC_k\,2^{k}\cdot1\]

代入

\(n=12\) で

\[3^{12}+1=531442,\qquad \dfrac{531442}{2}=265721\]

（例題10の型）

【答案】

\[265721\]
