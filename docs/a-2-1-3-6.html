別冊練習問題 6 の解答　3つの部分分数への分解（数値代入法）

(1)　\(\dfrac{2 x^{2} - x + 4}{(x-1)(x-2)(x-3)}=\dfrac{a}{x-1}+\dfrac{b}{x-2}+\dfrac{c}{x-3}\) が \(x\) についての恒等式となるように \(a,b,c\) を定めよ。

両辺に分母をかける

\(\dfrac{2 x^{2} - x + 4}{(x-1)(x-2)(x-3)}=\dfrac{a}{x-1}+\dfrac{b}{x-2}+\dfrac{c}{x-3}\) の分母をはらう。

\[2 x^{2} - x + 4=a(x-2)(x-3)+b(x-1)(x-3)+c(x-1)(x-2)\]

数値代入法

\(x=1,2,3\) を代入すると、それぞれ1つの文字だけ残る。

\[x=1:\ 5=2a\quad x=2:\ 10=-b\quad x=3:\ 19=2c\]

答え

\[a=\dfrac{19}{2},\ b=-10,\ c=\dfrac{5}{2}\]

【答案】

\[a=\dfrac{19}{2},\ b=-10,\ c=\dfrac{5}{2}\]

答

両辺に分母をかける

\(\dfrac{3 x^{2} + 5}{(x-1)(x-2)(x-3)}=\dfrac{a}{x-1}+\dfrac{b}{x-2}+\dfrac{c}{x-3}\) の分母をはらう。

\[3 x^{2} + 5=a(x-2)(x-3)+b(x-1)(x-3)+c(x-1)(x-2)\]

数値代入法

\(x=1,2,3\) を代入すると、それぞれ1つの文字だけ残る。

\[x=1:\ 8=2a\quad x=2:\ 17=-b\quad x=3:\ 32=2c\]

答え

\[a=16,\ b=-17,\ c=4\]

【答案】

\[a=16,\ b=-17,\ c=4\]

(3)　\(\dfrac{x^{2} - 3 x + 2}{(x-1)(x-2)(x-3)}=\dfrac{a}{x-1}+\dfrac{b}{x-2}+\dfrac{c}{x-3}\) が \(x\) についての恒等式となるように \(a,b,c\) を定めよ。

両辺に分母をかける

\(\dfrac{x^{2} - 3 x + 2}{(x-1)(x-2)(x-3)}=\dfrac{a}{x-1}+\dfrac{b}{x-2}+\dfrac{c}{x-3}\) の分母をはらう。

\[x^{2} - 3 x + 2=a(x-2)(x-3)+b(x-1)(x-3)+c(x-1)(x-2)\]

数値代入法

\(x=1,2,3\) を代入すると、それぞれ1つの文字だけ残る。

\[x=1:\ 0=2a\quad x=2:\ 0=-b\quad x=3:\ 2=2c\]

答え

\[a=1,\ b=0,\ c=0\]

【答案】

\[a=1,\ b=0,\ c=0\]
