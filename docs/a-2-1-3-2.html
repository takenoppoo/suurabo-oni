別冊練習問題 2 の解答　分数式の恒等式（部分分数分解）

(1)　等式 \(\dfrac{7 x - 4}{(x - 2)(x + 1)}=\dfrac{a}{x - 2}+\dfrac{b}{x + 1}\) が \(x\) についての恒等式となるように、定数 \(a,b\) の値を定めよ。

分母を払う

\[7 x - 4=a\left(x + 1\right)+b\left(x - 2\right)\]

右辺を展開して \(x\) で整理する

\[7 x - 4=a - 2 b + x \left(a + b\right)\]

係数を比べて連立方程式を解く

\[\begin{cases}x:\ a+b=7\\ \text{定数項}:\ a - 2 b=-4\end{cases}\]

解くと

\[a=\dfrac{10}{3},\quad b=\dfrac{11}{3}\]

別解（数値代入法）

\(x=2\) を代入：「\(10=a(3)\)」より \(a=\dfrac{10}{3}\)。\(x=-1\) を代入：「\(-11=b(-3)\)」より \(b=\dfrac{11}{3}\)。

【答案】

\[a=\dfrac{10}{3},\ b=\dfrac{11}{3}\]

答

(2)　等式 \(\dfrac{3 x + 10}{(x + 3)(x - 2)}=\dfrac{a}{x + 3}+\dfrac{b}{x - 2}\) が \(x\) についての恒等式となるように、定数 \(a,b\) の値を定めよ。

分母を払う

\[3 x + 10=a\left(x - 2\right)+b\left(x + 3\right)\]

右辺を展開して \(x\) で整理する

\[3 x + 10=- 2 a + 3 b + x \left(a + b\right)\]

係数を比べて連立方程式を解く

\[\begin{cases}x:\ a+b=3\\ \text{定数項}:\ - 2 a + 3 b=10\end{cases}\]

解くと

\[a=- \dfrac{1}{5},\quad b=\dfrac{16}{5}\]

別解（数値代入法）

\(x=-3\) を代入：「\(1=a(-5)\)」より \(a=- \dfrac{1}{5}\)。\(x=2\) を代入：「\(16=b(5)\)」より \(b=\dfrac{16}{5}\)。

【答案】

\[a=- \dfrac{1}{5},\ b=\dfrac{16}{5}\]

答

(3)　等式 \(\dfrac{9 x - 3}{(x - 1)(x - 4)}=\dfrac{a}{x - 1}+\dfrac{b}{x - 4}\) が \(x\) についての恒等式となるように、定数 \(a,b\) の値を定めよ。

分母を払う

\[9 x - 3=a\left(x - 4\right)+b\left(x - 1\right)\]

右辺を展開して \(x\) で整理する

\[9 x - 3=- 4 a - b + x \left(a + b\right)\]

係数を比べて連立方程式を解く

\[\begin{cases}x:\ a+b=9\\ \text{定数項}:\ - 4 a - b=-3\end{cases}\]

解くと

\[a=-2,\quad b=11\]

別解（数値代入法）

\(x=1\) を代入：「\(6=a(-3)\)」より \(a=-2\)。\(x=4\) を代入：「\(33=b(3)\)」より \(b=11\)。

【答案】

\[a=-2,\ b=11\]
