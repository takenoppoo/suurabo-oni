別冊練習問題 1 の解答　恒等式の係数決定（係数比較）

(1)　等式 \(x^{3} + 4 x^{2} - x + 6=a(x-1)^3+b(x-1)^2+c(x-1)+d\) が \(x\) についての恒等式となるように、定数 \(a,b,c,d\) の値を定めよ。

右辺を展開して \(x\) について整理する

\[\begin{aligned}\text{右辺}&=a(x-1)^3+b(x-1)^2+c(x-1)+d\\ &=a x^{3} - a + b - c + d + x^{2} \left(- 3 a + b\right) + x \left(3 a - 2 b + c\right)\end{aligned}\]

両辺の係数を比べる

恒等式なので、両辺の各次数の係数が等しい。

\[\begin{cases}x^3:\ a=1\\ x^2:\ - 3 a + b=4\\ x^1:\ 3 a - 2 b + c=-1\\ x^0:\ - a + b - c + d=6\end{cases}\]

上から順に解く

\[a=1,\quad b=7,\quad c=10,\quad d=10\]

確かめ：右辺に代入して展開すると左辺と一致する。

【答案】

\[a=1,\ b=7,\ c=10,\ d=10\]

答

(2)　等式 \(3 x^{3} - x^{2} + 2 x - 5=a(x--1)^3+b(x--1)^2+c(x--1)+d\) が \(x\) についての恒等式となるように、定数 \(a,b,c,d\) の値を定めよ。

右辺を展開して \(x\) について整理する

\[\begin{aligned}\text{右辺}&=a(x--1)^3+b(x--1)^2+c(x--1)+d\\ &=a x^{3} + a + b + c + d + x^{2} \left(3 a + b\right) + x \left(3 a + 2 b + c\right)\end{aligned}\]

両辺の係数を比べる

恒等式なので、両辺の各次数の係数が等しい。

\[\begin{cases}x^3:\ a=3\\ x^2:\ 3 a + b=-1\\ x^1:\ 3 a + 2 b + c=2\\ x^0:\ a + b + c + d=-5\end{cases}\]

上から順に解く

\[a=3,\quad b=-10,\quad c=13,\quad d=-11\]

確かめ：右辺に代入して展開すると左辺と一致する。

【答案】

\[a=3,\ b=-10,\ c=13,\ d=-11\]

(3)　等式 \(2 x^{3} + x^{2} - 4 x + 3=a(x-3)^3+b(x-3)^2+c(x-3)+d\) が \(x\) についての恒等式となるように、定数 \(a,b,c,d\) の値を定めよ。

右辺を展開して \(x\) について整理する

\[\begin{aligned}\text{右辺}&=a(x-3)^3+b(x-3)^2+c(x-3)+d\\ &=a x^{3} - 27 a + 9 b - 3 c + d + x^{2} \left(- 9 a + b\right) + x \left(27 a - 6 b + c\right)\end{aligned}\]

両辺の係数を比べる

恒等式なので、両辺の各次数の係数が等しい。

\[\begin{cases}x^3:\ a=2\\ x^2:\ - 9 a + b=1\\ x^1:\ 27 a - 6 b + c=-4\\ x^0:\ - 27 a + 9 b - 3 c + d=3\end{cases}\]

上から順に解く

\[a=2,\quad b=19,\quad c=56,\quad d=54\]

確かめ：右辺に代入して展開すると左辺と一致する。

【答案】

\[a=2,\ b=19,\ c=56,\ d=54\]
