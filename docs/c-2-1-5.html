章末問題剰余定理・因数定理・高次方程式

例題1〜5で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. 整式 \(P(x)\) を \(x-2\) で割ると余りが \(-3\)、\(x+3\) で割ると余りが \(12\) である。\(P(x)\) を \((x-2)(x+3)\) で割ったときの余りを求めよ。
  2. 整式 \(P(x)=x^3+ax^2+bx-6\) が \(x-1\) でも \(x+3\) でも割り切れるとき、定数 \(a,\ b\) の値を求めよ。また、方程式 \(P(x)=0\) を解け。
  3. 3次方程式 \(x^{3} + 3 x^{2} + 4 x + 4=0\) を解け。（複素数の範囲で）
  4. 方程式 \(x^{4} - 3 x^{2} - 10=0\) を解け。（複素数の範囲で）
  5. 実数 \(p,q\) に対して、3次方程式 \(x^3+px^2+qx-26=0\) の1つの解が \(2+3i\) であるとき、\(p,q\) の値と他の解を求めよ。
