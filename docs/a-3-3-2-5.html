別冊練習問題 5 の解答　回転体の体積

(1)　曲線 \(y=e^{2x}\ (0\leqq x\leqq1)\) と \(x\) 軸、\(y\) 軸、直線 \(x=1\) で囲まれた部分を \(x\) 軸のまわりに回転してできる立体の体積を求めよ。

体積の公式

\(x\) 軸のまわりの回転体：

\[V=\pi\int_a^b\{f(x)\}^2dx\]

積分の式

\[V=\pi\int_0^1\left(e^{2x}\right)^2dx=\pi\int_0^1e^{4x}dx\]

計算

\[V=\pi\left[\dfrac{e^{4x}}{4}\right]_0^1=\dfrac{\pi\left(e^{4}-1\right)}{4}\]

【答案】

\[\dfrac{\pi\left(e^{4}-1\right)}{4}\]

答

【答案】
