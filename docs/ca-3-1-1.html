ホーム ＞ 数学III ＞ 数列の極限

別冊章末問題の解答

1.　次の極限値を求めよ。 \[\lim_{n\to\infty}\dfrac{4 n^{2} - 5 n + 6}{8 n^{2} + 1}\]

最高次の項でわる

分母の最高次は \(n^2\)。分母・分子を \(n^2\) でわる。

\[\dfrac{4 n^{2} - 5 n + 6}{8 n^{2} + 1}=\dfrac{4 - \dfrac{5}{n} + \dfrac{6}{n^{2}}}{8 + \dfrac{1}{n^{2}}}\]

\(\dfrac1n,\ \dfrac1{n^2}\to0\) を使う

\(\lim_{n\to\infty}\dfrac1n=0,\ \ \lim_{n\to\infty}\dfrac1{n^2}=0\)。

\[\lim_{n\to\infty}\dfrac{4 - \dfrac{5}{n} + \dfrac{6}{n^{2}}}{8 + \dfrac{1}{n^{2}}}=\dfrac{4}{8}=\dfrac{1}{2}\]

（例題1の型）

【答案】

\[\dfrac{1}{2}\]

答

2.　次の極限値を求めよ。 \[\lim_{n\to\infty}\left(\sqrt{n^{2} + 3 n + 1}-\sqrt{n^{2} - n + 2}\right)\]

\(\infty-\infty\) の形

そのままでは不定形。分子の有理化をする。

有理化する

\[\sqrt{n^{2} + 3 n + 1}-\sqrt{n^{2} - n + 2}=\dfrac{(n^{2} + 3 n + 1)-(n^{2} - n + 2)}{\sqrt{n^{2} + 3 n + 1}+\sqrt{n^{2} - n + 2}}=\dfrac{4 n - 1}{\sqrt{n^{2} + 3 n + 1}+\sqrt{n^{2} - n + 2}}\]

根号の中から \(n\) をくくり出す

\(n>0\) なので \(\sqrt{n^2}=n\)。

\[\sqrt{n^{2} + 3 n + 1}=n\sqrt{1+\dfrac{3}{n}+\dfrac{1}{n^2}},\qquad \sqrt{n^{2} - n + 2}=n\sqrt{1-\dfrac{1}{n}+\dfrac{2}{n^2}}\]

分母・分子を \(n\) でわる。

\(n\) でわる

\[=\dfrac{4 - \dfrac{1}{n}}{\sqrt{1+\dfrac{3}{n}+\dfrac{1}{n^2}}+\sqrt{1-\dfrac{1}{n}+\dfrac{2}{n^2}}}\]

極限を求める

\(\dfrac1n\to0,\ \dfrac1{n^2}\to0\) だから、

\[\to\dfrac{4}{\sqrt1+\sqrt1}=\dfrac{4}{2}=2\]

（例題2の型）

【答案】

\[2\]

答

3.　次の極限値を求めよ。 \[\lim_{n\to\infty}\dfrac{3\cdot5^n+2\cdot3^n}{1\cdot5^n+6\cdot3^n}\]

底の大きい方でわる

底が大きい \(5^n\) で分母・分子をわる。

\[\dfrac{3\cdot5^n+2\cdot3^n}{1\cdot5^n+6\cdot3^n}=\dfrac{3+2\left(\dfrac{3}{5}\right)^n}{1+6\left(\dfrac{3}{5}\right)^n}\]

\(|r|<1\) なら \(r^n\to0\)

\(\left(\dfrac{3}{5}\right)^n\to0\)。

\[\to3=3\]

（例題3の型）

【答案】

\[3\]

答

4.　\(a_1=2,\ \ a_{n+1}=\dfrac{3}{4} a_n+1\) で定められる数列 \(\{a_n\}\) の一般項と、極限値 \(\displaystyle\lim_{n\to\infty}a_n\) を求めよ。

特性方程式で \(\alpha\)

\(\alpha=\dfrac{3}{4}\alpha+1\)。

\[\alpha=4\]

一般項

\(a_{n+1}-\alpha=\dfrac{3}{4}(a_n-\alpha)\)。

\[a_n=4-2\left(\dfrac{3}{4}\right)^{n-1}\]

極限

\(|\dfrac{3}{4}|<1\) なので \(\left(\dfrac{3}{4}\right)^{n-1}\to0\)。

\[\lim_{n\to\infty}a_n=4\]

（例題4の型）

【答案】

\[a_n=4-2\left(\dfrac{3}{4}\right)^{n-1},\ \ \lim a_n=4\]

答

5.　数列 \(a_n=\dfrac{4n+\sin n}{5n+2}\) の極限値を求めよ。

有界な項を不等式ではさむ

\(-1\leqq\sin n\leqq1\) の各辺に \(1\) をかけて \(4n\) をたし、\(5n+2\) でわる。

\[\dfrac{4n-1}{5n+2}\leqq a_n\leqq\dfrac{4n+1}{5n+2}\]

両側の極限を求める

両側とも \(n\) でわって

\[\lim_{n\to\infty}\dfrac{4n-1}{5n+2}=\dfrac{4}{5},\qquad \lim_{n\to\infty}\dfrac{4n+1}{5n+2}=\dfrac{4}{5}\]

はさみうちの原理

両側の極限が一致するので

\[\lim_{n\to\infty}a_n=\dfrac{4}{5}\]

（例題5の型）

【答案】

\[\dfrac{4}{5}\]

答

6.　\(\displaystyle\lim_{n\to\infty}\left(\sqrt{n^2+8n+1}-n\right)\) を求めよ。

有理化

\[\sqrt{n^2+8n+1}-n=\dfrac{(n^2+8n+1)-n^2}{\sqrt{n^2+8n+1}+n}=\dfrac{8n+1}{\sqrt{n^2+8n+1}+n}\]

\(n\) で割る

\[=\dfrac{8+\dfrac{1}{n}}{\sqrt{1+\dfrac{8}{n}+\dfrac{1}{n^2}}+1}\]

極限

\[\to\dfrac{8}{1+1}=4\]

（例題6の型）

【答案】

\[4\]

答

7.　\(\displaystyle\lim_{n\to\infty}\dfrac{3^n+8^n}{3^{n+1}+8^{n+1}}\) を求めよ。

底の大きい方でわる

\(8>3\) なので \(8^n\) で分母・分子を割る。

\[\dfrac{1+\left(\dfrac{3}{8}\right)^n}{8+3\left(\dfrac{3}{8}\right)^n}\]

極限

\(\left(\dfrac{3}{8}\right)^n\to0\)。

\[\dfrac{1}{8}=\dfrac{1}{8}\]

（例題7の型）

【答案】

\[\dfrac{1}{8}\]

答

8.　\(\displaystyle\lim_{n\to\infty}\left(1+\dfrac{2}{n}\right)^{3n}\) を求めよ。

e の定義

\(\lim_{m\to\infty}\left(1+\dfrac1m\right)^m=e\)。

形をそろえる

\(m=\dfrac{n}{2}\) とおくと \(\dfrac{2}{n}=\dfrac1m\)。

\[\left(1+\dfrac{2}{n}\right)^{3n}=\left\{\left(1+\dfrac1m\right)^{m}\right\}^{6}\]

極限

\[\to e^{6}\]

（例題8の型）

【答案】

\[e^{6}\]

答

9.　\(a_1=3,\ a_{n+1}=\sqrt{2+a_n}\) で定まる数列の極限を求めよ。（収束することを認めてよい）

極限が存在すると仮定

\(\lim a_n=\alpha\) とすると \(\alpha=\sqrt{2+\alpha}\)。

\[\alpha^2-\alpha-2=0\ \Rightarrow\ \alpha=2\quad(\alpha>0)\]

収束の確認

\(a_1=3\) から \(a_n\) は増加（または減少）し、\(\alpha\) をこえない（有界な単調数列は収束）。

\[a_2=2.2361,\ a_3=2.0582,\ a_4=2.0145\]

答え

\[\lim_{n\to\infty}a_n=2\]

（例題9の型）

【答案】

\[2\]

答

10.　\(\displaystyle\lim_{n\to\infty}\dfrac{1^{1}+2^{1}+\cdots+n}{n^{2}}\) を求めよ。

区分求積の形

\[\sum_{k=1}^{n}\dfrac{k}{n^{2}}=\dfrac1n\sum_{k=1}^{n}\left(\dfrac kn\right)^{1}\]

定積分に

\[\lim_{n\to\infty}\dfrac1n\sum_{k=1}^{n}f\left(\dfrac kn\right)=\int_0^1f(x)\,dx\]

\(f(x)=x\)。

計算

\[\int_0^1xdx=\dfrac1{2}\]

（例題10の型）

【答案】

\[\dfrac{1}{2}\]

答
