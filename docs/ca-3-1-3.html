別冊章末問題の解答

1.　次の極限値を求めよ。 \[\lim_{x\to4}\dfrac{x^{2} - 2 x - 8}{x^{2} - 5 x + 4}\]

0/0 の不定形

\(x\to4\) で分母・分子とも 0。共通因数 \(x-4\) をくくり出す。

約分する

\[\dfrac{x^{2} - 2 x - 8}{x^{2} - 5 x + 4}=\dfrac{(x - 4)(x + 2)}{(x - 4)(x - 1)}=\dfrac{x + 2}{x - 1}\quad(x\neq4)\]

代入する

\[\lim_{x\to4}\dfrac{x + 2}{x - 1}=\dfrac{6}{3}=2\]

（例題1の型）

【答案】

\[2\]

答

2.　次の極限値を求めよ。 \[\lim_{x\to6}\dfrac{\sqrt{x+3}-3}{x-6}\]

0/0 の不定形

\(x\to6\) で分母・分子とも 0。分子を有理化する。

分子を有理化

\[\dfrac{\sqrt{x+3}-3}{x-6}\cdot\dfrac{\sqrt{x+3}+3}{\sqrt{x+3}+3}=\dfrac{(x+3)-9}{(x-6)(\sqrt{x+3}+3)}=\dfrac{1}{\sqrt{x+3}+3}\]

代入する

\[\lim_{x\to6}\dfrac1{\sqrt{x+3}+3}=\dfrac1{3+3}=\dfrac{1}{6}\]

（例題2の型）

【答案】

\[\dfrac{1}{6}\]

答

3.　次の極限値を求めよ。 \[\lim_{x\to\infty}\left(\sqrt{x^{2} + 5 x}-\sqrt{x^{2} + x}\right)\]

\(\infty-\infty\) の形

有理化する。

有理化

\[\sqrt{x^{2} + 5 x}-\sqrt{x^{2} + x}=\dfrac{4 x}{\sqrt{x^{2} + 5 x}+\sqrt{x^{2} + x}}\]

\(x\) でわって \(x\to\infty\)

\[=\dfrac{4}{\sqrt{1+\frac{5}{x}}+\sqrt{1+\frac{1}{x}}}\to\dfrac{4}{2}=2\]

（例題3の型）

【答案】

\[2\]

答

4.　次の極限値を求めよ。 \[\lim_{x\to0}\dfrac{\sin 4x}{9x}\]

公式を使う形にする

\(\lim_{\theta\to0}\dfrac{\sin\theta}{\theta}=1\)。\(\sin 4x\) の中身 \(4x\) を分母にそろえる。

変形

\[\dfrac{\sin 4x}{9x}=\dfrac{\sin 4x}{4x}\cdot\dfrac{4}{9}\]

極限

\[\lim_{x\to0}\dfrac{\sin 4x}{4x}=1\cdot\dfrac{4}{9}=\dfrac{4}{9}\]

（例題4の型）

【答案】

\[\dfrac{4}{9}\]

答

5.　関数 \(f(x)=\begin{cases}\dfrac{x^{2} + 3 x + 2}{x+1}&(x\neq -1)\\[2mm] m&(x=-1)\end{cases}\) が \(x=-1\) で連続となるように、定数 \(m\) の値を定めよ。

連続の条件

\(x=-1\) で連続 \(\iff \lim_{x\to-1}f(x)=f(-1)\)。

極限値

\[\lim_{x\to-1}\dfrac{x^{2} + 3 x + 2}{x+1}=\lim_{x\to-1}\dfrac{(x+1)(x+2)}{x+1}=\lim_{x\to-1}(x+2)=1\]

定数を決める

\(f(-1)=m\) なので

\[m=1\]

（例題5の型）

【答案】

\[m=1\]

答

6.　\(\displaystyle\lim_{x\to0}\dfrac{1-\cos1x}{x^2}\) を求めよ。

半角の形に

\[1-\cos1x=2\sin^2\dfrac{x}{2}\]

基本極限に直す

\(\lim_{t\to0}\dfrac{\sin t}{t}=1\)。

\[\dfrac{1-\cos1x}{x^2}=2\left(\dfrac{\sin\dfrac{1}{2}x}{x}\right)^2=2\cdot\left(\dfrac{1}{2}\right)^2\left(\dfrac{\sin\frac{1}{2}x}{\frac{1}{2}x}\right)^2\]

極限

\[\to2\cdot\dfrac{1}{4}=\dfrac{1}{2}\]

（例題6の型）

【答案】

\[\dfrac{1}{2}\]

答

7.　\(\displaystyle\lim_{x\to0}\dfrac{e^{4x}-1}{5x}\) を求めよ。

基本極限

\(\lim_{t\to0}\dfrac{e^t-1}{t}=1\)。

形をそろえる

\[\dfrac{e^{4x}-1}{5x}=\dfrac{4}{5}\cdot\dfrac{e^{4x}-1}{4x}\]

極限

\(t=4x\to0\) として \(\dfrac{e^t-1}{t}\to1\)。

\[\dfrac{4}{5}\]

（例題7の型）

【答案】

\[\dfrac{4}{5}\]

答

8.　方程式 \(x + \log{\left(x \right)} - 2=0\) は、区間 \((1,\ 2)\) に少なくとも1つの実数解をもつことを示せ。

連続関数

\(f(x)=x + \log{\left(x \right)} - 2\) は連続。

端点の符号

\[f(1)=-1<0,\qquad f(2)=\log{\left(2 \right)}>0\]

中間値の定理

\(f(1)f(2)<0\) なので、\(1<x<2\) に \(f(x)=0\) の実数解が少なくとも1つ存在する。

（例題8の型）

【答案】

\[\text{証明終}\]

答

9.　\(\displaystyle\lim_{x\to5}\dfrac{x^2-25}{|x-5|}\) は存在するか。右側極限・左側極限を調べて答えよ。

場合分け

\(x>5\) のとき \(|x-5|=x-5\)、\(x<5\) のとき \(|x-5|=-(x-5)\)。

右側から

\[\lim_{x\to5}\dfrac{(x-5)(x+5)}{x-5}=10\]

左側から

\[\lim_{x\to5-0}\dfrac{(x-5)(x+5)}{-(x-5)}=-10\]

右側と左側が異なるので、極限は存在しない。

（例題9の型）

【答案】

\[\text{右側 }10,\ \text{左側 }-10\ \text{より極限は存在しない}\]

答

10.　関数 \(f(x)=\begin{cases}\dfrac{\sqrt{x+2}-3}{x-7}&(x\neq7)\\ k&(x=7)\end{cases}\) が \(x=7\) で連続となるような定数 \(k\) の値を求めよ。

連続の条件

\(x=7\) で連続 \(\iff \lim_{x\to7}f(x)=f(7)\)。

極限を求める

有理化：

\[\dfrac{\sqrt{x+2}-3}{x-7}=\dfrac{(x+2)-9}{(x-7)(\sqrt{x+2}+3)}=\dfrac{1}{\sqrt{x+2}+3}\to\dfrac1{6}\]

定数

\[k=\dfrac{1}{6}\]

（例題10の型）

【答案】

\[k=\dfrac{1}{6}\]
