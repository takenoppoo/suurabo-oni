別冊練習問題 1 の解答　整式の割り算（筆算）

(1)　整式 \(4 x^{4} - 5 x^{2} + 3 x + 1\) を \(2 x^{2} - x + 1\) で割ったときの商と余りを求めよ。

商を1項ずつ立てて引く

最高次の項どうしを割って商の項を決め、（割る式）×（商の項）を引く。余りの次数が割る式より小さくなるまで繰り返す。

\(4 x^{4}\div\left(2 x^{2}\right)=2 x^{2}\) を商に立てる。

\[4 x^{4} - 5 x^{2} + 3 x + 1-\left(2 x^{2}\right)\left(2 x^{2} - x + 1\right)=2 x^{3} - 7 x^{2} + 3 x + 1\]

\(2 x^{3}\div\left(2 x^{2}\right)=x\) を商に立てる。

\[2 x^{3} - 7 x^{2} + 3 x + 1-\left(x\right)\left(2 x^{2} - x + 1\right)=- 6 x^{2} + 2 x + 1\]

\(- 6 x^{2}\div\left(2 x^{2}\right)=-3\) を商に立てる。

\[- 6 x^{2} + 2 x + 1-\left(-3\right)\left(2 x^{2} - x + 1\right)=- x + 4\]

商と余りを読む

\[\text{商 }2 x^{2} + x - 3,\quad \text{余り }- x + 4\]

確かめ

\[\begin{aligned}&\left(2 x^{2} - x + 1\right)\left(2 x^{2} + x - 3\right)+\left(- x + 4\right)\\ &=4 x^{4} - 5 x^{2} + 3 x + 1\end{aligned}\]

【答案】

\[\text{商 }2 x^{2} + x - 3,\quad \text{余り }- x + 4\]

答

(2)　整式 \(3 x^{4} - 2 x^{3} - 4 x^{2} + x + 6\) を \(3 x^{2} + x - 2\) で割ったときの商と余りを求めよ。

商を1項ずつ立てて引く

最高次の項どうしを割って商の項を決め、（割る式）×（商の項）を引く。余りの次数が割る式より小さくなるまで繰り返す。

\(3 x^{4}\div\left(3 x^{2}\right)=x^{2}\) を商に立てる。

\[3 x^{4} - 2 x^{3} - 4 x^{2} + x + 6-\left(x^{2}\right)\left(3 x^{2} + x - 2\right)=- 3 x^{3} - 2 x^{2} + x + 6\]

\(- 3 x^{3}\div\left(3 x^{2}\right)=- x\) を商に立てる。

\[- 3 x^{3} - 2 x^{2} + x + 6-\left(- x\right)\left(3 x^{2} + x - 2\right)=- x^{2} - x + 6\]

\(- x^{2}\div\left(3 x^{2}\right)=- \dfrac{1}{3}\) を商に立てる。

\[- x^{2} - x + 6-\left(- \dfrac{1}{3}\right)\left(3 x^{2} + x - 2\right)=- \dfrac{2 x}{3} + \dfrac{16}{3}\]

商と余りを読む

\[\text{商 }x^{2} - x - \dfrac{1}{3},\quad \text{余り }- \dfrac{2 x}{3} + \dfrac{16}{3}\]

確かめ

\[\begin{aligned}&\left(3 x^{2} + x - 2\right)\left(x^{2} - x - \dfrac{1}{3}\right)+\left(- \dfrac{2 x}{3} + \dfrac{16}{3}\right)\\ &=3 x^{4} - 2 x^{3} - 4 x^{2} + x + 6\end{aligned}\]

【答案】

\[\text{商 }x^{2} - x - \dfrac{1}{3},\quad \text{余り }- \dfrac{2 x}{3} + \dfrac{16}{3}\]

答

(3)　整式 \(2 x^{4} + 5 x^{3} - x^{2} - 3 x + 4\) を \(x^{2} + 2 x - 1\) で割ったときの商と余りを求めよ。

商を1項ずつ立てて引く

最高次の項どうしを割って商の項を決め、（割る式）×（商の項）を引く。余りの次数が割る式より小さくなるまで繰り返す。

\(2 x^{4}\div\left(x^{2}\right)=2 x^{2}\) を商に立てる。

\[2 x^{4} + 5 x^{3} - x^{2} - 3 x + 4-\left(2 x^{2}\right)\left(x^{2} + 2 x - 1\right)=x^{3} + x^{2} - 3 x + 4\]

\(x^{3}\div\left(x^{2}\right)=x\) を商に立てる。

\[x^{3} + x^{2} - 3 x + 4-\left(x\right)\left(x^{2} + 2 x - 1\right)=- x^{2} - 2 x + 4\]

\(- x^{2}\div\left(x^{2}\right)=-1\) を商に立てる。

\[- x^{2} - 2 x + 4-\left(-1\right)\left(x^{2} + 2 x - 1\right)=3\]

商と余りを読む

\[\text{商 }2 x^{2} + x - 1,\quad \text{余り }3\]

確かめ

\[\begin{aligned}&\left(x^{2} + 2 x - 1\right)\left(2 x^{2} + x - 1\right)+\left(3\right)\\ &=2 x^{4} + 5 x^{3} - x^{2} - 3 x + 4\end{aligned}\]

【答案】

\[\text{商 }2 x^{2} + x - 1,\quad \text{余り }3\]
