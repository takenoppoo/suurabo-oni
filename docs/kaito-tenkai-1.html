(1)　\((x^2+ax+4)(x^2-3x+b)\) で \(x^3,\ x\) の係数が 0 のとき、\(a,\ b,\ x^2\) の係数

\(x^3\)：\(-3+a=0\) より \(a=3\)。

\(x\)：\(ab+4\times(-3)=3b-12=0\) より \(b=4\)。

\(x^2\)：\(b-3a+4=4-9+4=-1\)。

【答案】

\[a=3,\ b=4,\ x^2\text{ の係数 }-1\]

答

(2)　\((x^2+ax+2)(x^2+4x+b)\) で \(x^3,\ x\) の係数が 0 のとき、\(a,\ b,\ x^2\) の係数

\(x^3\)：\(4+a=0\) より \(a=-4\)。

\(x\)：\(ab+2\times4=-4b+8=0\) より \(b=2\)。

\(x^2\)：\(b+4a+2=2-16+2=-12\)。

【答案】

\[a=-4,\ b=2,\ x^2\text{ の係数 }-12\]

答

(3)　\((x^2+ax-5)(x^2-2x+b)\) で \(x^3,\ x\) の係数が 0 のとき、\(a,\ b,\ x^2\) の係数

\(x^3\)：\(-2+a=0\) より \(a=2\)。

\(x\)：\(ab+(-5)\times(-2)=2b+10=0\) より \(b=-5\)。

\(x^2\)：\(b-2a-5=-5-4-5=-14\)。

【答案】

\[a=2,\ b=-5,\ x^2\text{ の係数 }-14\]
