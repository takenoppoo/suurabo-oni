別冊練習問題 1 の解答　二項定理で特定の項の係数

(1)　\(\left(3 x - y\right)^{7}\) の展開式における \(x^{3}y^{4}\) の項の係数を求めよ。

一般項を書く

\(\left(3 x - y\right)^{7}\) の展開式の一般項は\[{}_{7}\mathrm{C}_{r}\left(3 x\right)^{7-r}\left(- y\right)^{r}\]

\(r\) は 0 から 7 までの整数。

目的の項になる \(r\) を決める

\(x^{3}y^{4}\) の \(y\) の指数が \(4\) なので \(r=4\)。（\(x\) の指数は \(7-4=3\) で一致。）

係数を計算する

\[{}_{7}\mathrm{C}_{4}\left(3 x\right)^{3}\left(- y\right)^{4}=35\times27\times1=945\]

よって係数は \(945\)。

【答案】

\[945\]

答

(2)　\(\left(- 2 x + 5 y\right)^{5}\) の展開式における \(x^{2}y^{3}\) の項の係数を求めよ。

一般項を書く

\(\left(- 2 x + 5 y\right)^{5}\) の展開式の一般項は\[{}_{5}\mathrm{C}_{r}\left(- 2 x\right)^{5-r}\left(5 y\right)^{r}\]

\(r\) は 0 から 5 までの整数。

目的の項になる \(r\) を決める

\(x^{2}y^{3}\) の \(y\) の指数が \(3\) なので \(r=3\)。（\(x\) の指数は \(5-3=2\) で一致。）

係数を計算する

\[{}_{5}\mathrm{C}_{3}\left(- 2 x\right)^{2}\left(5 y\right)^{3}=10\times4\times125=5000\]

よって係数は \(5000\)。

【答案】

\[5000\]

答

(3)　\(\left(4 x + 3 y\right)^{5}\) の展開式における \(x^{4}y^{1}\) の項の係数を求めよ。

一般項を書く

\(\left(4 x + 3 y\right)^{5}\) の展開式の一般項は\[{}_{5}\mathrm{C}_{r}\left(4 x\right)^{5-r}\left(3 y\right)^{r}\]

\(r\) は 0 から 5 までの整数。

目的の項になる \(r\) を決める

\(x^{4}y^{1}\) の \(y\) の指数が \(1\) なので \(r=1\)。（\(x\) の指数は \(5-1=4\) で一致。）

係数を計算する

\[{}_{5}\mathrm{C}_{1}\left(4 x\right)^{4}\left(3 y\right)^{1}=5\times256\times3=3840\]

よって係数は \(3840\)。

【答案】

\[3840\]
