章末問題2次方程式

例題1〜5で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. \(x^2+ax+a+3=0\ \text{が重解をもつような}\ a\ \text{の値と重解を求めよ。}\)
  2. \(x^2-3x-5=0\ \text{の2解を}\ \alpha,\beta\ \text{とするとき},\ \alpha^2+\beta^2,\ \alpha^3+\beta^3\ \text{を求めよ。}\)
  3. \(x^2-4x+a=0\ \text{の2つの解の差が}\ 2\sqrt3\ \text{であるとき},\ a\ \text{の値を求めよ。}\)
  4. \(x^2-2ax+2a+3=0\ \text{が異なる2つの正の解をもつような}\ a\ \text{の範囲を求めよ。}\)
  5. \(x^2+ax+6=0,\ x^2+6x+a=0\ \text{が共通な実数解をもつような}\ a\ \text{の値を求めよ。}\)
