別冊練習問題 3 の解答　2直線の交点の位置ベクトル

(1)　△\(OAB\) で、辺 \(OA\) 上に \(OC=\dfrac{2}{3}\,OA\) となる点 \(C\)、辺 \(OB\) 上に \(OD=\dfrac{1}{2}\,OB\) となる点 \(D\) をとる。\(AD\) と \(BC\) の交点を \(P\) とするとき、\(\overrightarrow{OP}\) を \(\vec a=\overrightarrow{OA}\)、\(\vec b=\overrightarrow{OB}\) で表せ。

点を位置ベクトルで表す

\(\overrightarrow{OA}=\vec a,\ \overrightarrow{OB}=\vec b\) とすると

\[\overrightarrow{OC}=\dfrac{2}{3}\vec a,\qquad \overrightarrow{OD}=\dfrac{1}{2}\vec b\]

直線 \(AD\) 上の点として表す

\(AP:PD=u:(1-u)\) とおくと（\(\overrightarrow{OP}=(1-u)\overrightarrow{OA}+u\overrightarrow{OD}\)）

\[\overrightarrow{OP}=(1-u)\vec a+\dfrac{1}{2}\,u\,\vec b\quad\cdots①\]

直線 \(BC\) 上の点として表す

\(BP:PC=v:(1-v)\) とおくと

\[\overrightarrow{OP}=\dfrac{2}{3}\,v\,\vec a+(1-v)\vec b\quad\cdots②\]

係数を比較する

\(\vec a,\vec b\) は一次独立なので、①②の係数が等しい。

\[\begin{cases}1-u=\dfrac{2}{3}\,v\\ \dfrac{1}{2}\,u=1-v\end{cases}\]\[u=\dfrac{1}{2},\quad v=\dfrac{3}{4}\]

答え

\[\overrightarrow{OP}=\dfrac{1}{2}\vec a+\dfrac{1}{4}\vec b\]

【答案】

\[\overrightarrow{OP}=\dfrac{1}{2}\vec a+\dfrac{1}{4}\vec b\]

答

点を位置ベクトルで表す

\(\overrightarrow{OA}=\vec a,\ \overrightarrow{OB}=\vec b\) とすると

\[\overrightarrow{OC}=\dfrac{1}{3}\vec a,\qquad \overrightarrow{OD}=\dfrac{3}{4}\vec b\]
