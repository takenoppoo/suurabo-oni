別冊練習問題 10 の解答　和 Sn から一般項（n=1 の確認）

(1)　数列 \(\{a_n\}\) の初項から第 \(n\) 項までの和が \(S_n=2 n^{2} - n + 3\) であるとき、一般項 \(a_n\) を求めよ。

\(n\geqq2\)

\[a_n=S_n-S_{n-1}=(2 n^{2} - n + 3)-(- n + 2 \left(n - 1\right)^{2} + 4)=4 n - 3\]

\(n=1\) の確認

\[a_1=S_1=4,\qquad 4 n - 3\ \text{に }n=1\text{ を代入}=1\]

一致しないので \(a_1=4\) と \(n\geqq2\) で場合分け。

【答案】

\[a_1=4,\ a_n=4 n - 3\ (n\geqq2)\]

答

(2)　数列 \(\{a_n\}\) の初項から第 \(n\) 項までの和が \(S_n=n^{2} + n + 2\) であるとき、一般項 \(a_n\) を求めよ。

\(n\geqq2\)

\[a_n=S_n-S_{n-1}=(n^{2} + n + 2)-(n + \left(n - 1\right)^{2} + 1)=2 n\]

\(n=1\) の確認

\[a_1=S_1=4,\qquad 2 n\ \text{に }n=1\text{ を代入}=2\]

一致しないので \(a_1=4\) と \(n\geqq2\) で場合分け。

【答案】

\[a_1=4,\ a_n=2 n\ (n\geqq2)\]

答

(3)　数列 \(\{a_n\}\) の初項から第 \(n\) 項までの和が \(S_n=3 n^{2} - 1\) であるとき、一般項 \(a_n\) を求めよ。

\(n\geqq2\)

\[a_n=S_n-S_{n-1}=(3 n^{2} - 1)-(3 \left(n - 1\right)^{2} - 1)=6 n - 3\]

\(n=1\) の確認

\[a_1=S_1=2,\qquad 6 n - 3\ \text{に }n=1\text{ を代入}=3\]

一致しないので \(a_1=2\) と \(n\geqq2\) で場合分け。

【答案】

\[a_1=2,\ a_n=6 n - 3\ (n\geqq2)\]
