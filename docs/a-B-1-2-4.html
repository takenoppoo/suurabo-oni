別冊練習問題 4 の解答　（等差）×（等比）の和

(1)　次の和 \(S_n\) を求めよ。 \[S_n=\sum_{k=1}^{n}k\cdot3^{k}\]

和を書き並べる

\[S_n= 3+2\cdot3^2+3\cdot3^3+\cdots+n\cdot3^n\]

\(3\) 倍して1項ずらす

\[\left(3\right)S_n=3^2+2\cdot3^3+\cdots+(n-1)3^n+n\cdot3^{n+1}\]

辺々ひく

\((1-r)S_n\) は等比数列の和と端の項だけになる。

\[(1-\left(3\right))S_n= 3+3^2+\cdots+3^n-n\cdot3^{n+1}\]\[-2\,S_n=\dfrac{\left(3\right)\left(3^n-1\right)}{\left(3\right)-1}-n\cdot3^{n+1}\]

\(S_n\) を求める

\[S_n=\dfrac{3^{n+1} n}{2} - \dfrac{3^{n+1}}{4} + \dfrac{3}{4}\]

【答案】

\[S_n=\dfrac{3^{n+1} n}{2} - \dfrac{3^{n+1}}{4} + \dfrac{3}{4}\]

答

(2)　次の和 \(S_n\) を求めよ。 \[S_n=\sum_{k=1}^{n}k\cdot\left(-2\right)^{k}\]

和を書き並べる

\[S_n=\left(-2\right)+2\cdot\left(-2\right)^2+3\cdot\left(-2\right)^3+\cdots+n\cdot\left(-2\right)^n\]

\(-2\) 倍して1項ずらす

\[\left(-2\right)S_n=\left(-2\right)^2+2\cdot\left(-2\right)^3+\cdots+(n-1)\left(-2\right)^n+n\cdot\left(-2\right)^{n+1}\]

辺々ひく

\((1-r)S_n\) は等比数列の和と端の項だけになる。

\[(1-\left(-2\right))S_n=\left(-2\right)+\left(-2\right)^2+\cdots+\left(-2\right)^n-n\cdot\left(-2\right)^{n+1}\]\[3\,S_n=\dfrac{\left(-2\right)\left(\left(-2\right)^n-1\right)}{\left(-2\right)-1}-n\cdot\left(-2\right)^{n+1}\]

\(S_n\) を求める

\[S_n=\dfrac{2 \left(-2\right)^{n} n}{3} + \dfrac{2 \left(-2\right)^{n}}{9} - \dfrac{2}{9}\]

【答案】

\[S_n=\dfrac{2 \left(-2\right)^{n} n}{3} + \dfrac{2 \left(-2\right)^{n}}{9} - \dfrac{2}{9}\]

答

(3)　次の和 \(S_n\) を求めよ。 \[S_n=\sum_{k=1}^{n}k\cdot\left(\dfrac{1}{2}\right)^{k}\]

和を書き並べる

\[S_n=\left(\dfrac{1}{2}\right)+2\cdot\left(\dfrac{1}{2}\right)^2+3\cdot\left(\dfrac{1}{2}\right)^3+\cdots+n\cdot\left(\dfrac{1}{2}\right)^n\]

\(\dfrac{1}{2}\) 倍して1項ずらす

\[\left(\dfrac{1}{2}\right)S_n=\left(\dfrac{1}{2}\right)^2+2\cdot\left(\dfrac{1}{2}\right)^3+\cdots+(n-1)\left(\dfrac{1}{2}\right)^n+n\cdot\left(\dfrac{1}{2}\right)^{n+1}\]

辺々ひく

\((1-r)S_n\) は等比数列の和と端の項だけになる。

\[(1-\left(\dfrac{1}{2}\right))S_n=\left(\dfrac{1}{2}\right)+\left(\dfrac{1}{2}\right)^2+\cdots+\left(\dfrac{1}{2}\right)^n-n\cdot\left(\dfrac{1}{2}\right)^{n+1}\]\[\dfrac{1}{2}\,S_n=\dfrac{\left(\dfrac{1}{2}\right)\left(\left(\dfrac{1}{2}\right)^n-1\right)}{\left(\dfrac{1}{2}\right)-1}-n\cdot\left(\dfrac{1}{2}\right)^{n+1}\]

\(S_n\) を求める

\[S_n=2^{- n} \left(2^{n + 1} - n - 2\right)\]

【答案】

\[S_n=2^{- n} \left(2^{n + 1} - n - 2\right)\]
