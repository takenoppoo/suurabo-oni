別冊練習問題 2 の解答　無理式の極限（有理化）

(1)　次の極限値を求めよ。 \[\lim_{n\to\infty}\left(\sqrt{n^{2} + 6 n}-\sqrt{n^{2} + 2 n + 3}\right)\]

\(\infty-\infty\) の形

そのままでは不定形。分子の有理化をする。

有理化する

\[\sqrt{n^{2} + 6 n}-\sqrt{n^{2} + 2 n + 3}=\dfrac{(n^{2} + 6 n)-(n^{2} + 2 n + 3)}{\sqrt{n^{2} + 6 n}+\sqrt{n^{2} + 2 n + 3}}=\dfrac{4 n - 3}{\sqrt{n^{2} + 6 n}+\sqrt{n^{2} + 2 n + 3}}\]

根号の中から \(n\) をくくり出す

\(n>0\) なので \(\sqrt{n^2}=n\)。

\[\sqrt{n^{2} + 6 n}=n\sqrt{1+\dfrac{6}{n}},\qquad \sqrt{n^{2} + 2 n + 3}=n\sqrt{1+\dfrac{2}{n}+\dfrac{3}{n^2}}\]

分母・分子を \(n\) でわる。

\(n\) でわる

\[=\dfrac{4 - \dfrac{3}{n}}{\sqrt{1+\dfrac{6}{n}}+\sqrt{1+\dfrac{2}{n}+\dfrac{3}{n^2}}}\]

極限を求める

\(\dfrac1n\to0,\ \dfrac1{n^2}\to0\) だから、

\[\to\dfrac{4}{\sqrt1+\sqrt1}=\dfrac{4}{2}=2\]

(2)　次の極限値を求めよ。 \[\lim_{n\to\infty}\left(\sqrt{n^{2} + 5 n + 2}-\sqrt{n^{2} + n + 1}\right)\]

\(\infty-\infty\) の形

そのままでは不定形。分子の有理化をする。

有理化する

\[\sqrt{n^{2} + 5 n + 2}-\sqrt{n^{2} + n + 1}=\dfrac{(n^{2} + 5 n + 2)-(n^{2} + n + 1)}{\sqrt{n^{2} + 5 n + 2}+\sqrt{n^{2} + n + 1}}=\dfrac{4 n + 1}{\sqrt{n^{2} + 5 n + 2}+\sqrt{n^{2} + n + 1}}\]

根号の中から \(n\) をくくり出す

\(n>0\) なので \(\sqrt{n^2}=n\)。

\[\sqrt{n^{2} + 5 n + 2}=n\sqrt{1+\dfrac{5}{n}+\dfrac{2}{n^2}},\qquad \sqrt{n^{2} + n + 1}=n\sqrt{1+\dfrac{1}{n}+\dfrac{1}{n^2}}\]

分母・分子を \(n\) でわる。

\(n\) でわる

\[=\dfrac{4 + \dfrac{1}{n}}{\sqrt{1+\dfrac{5}{n}+\dfrac{2}{n^2}}+\sqrt{1+\dfrac{1}{n}+\dfrac{1}{n^2}}}\]

極限を求める

\(\dfrac1n\to0,\ \dfrac1{n^2}\to0\) だから、

\[\to\dfrac{4}{\sqrt1+\sqrt1}=\dfrac{4}{2}=2\]

(3)　次の極限値を求めよ。 \[\lim_{n\to\infty}\left(\sqrt{n^{2} + 8 n + 3}-\sqrt{n^{2} + 2 n}\right)\]

\(\infty-\infty\) の形

そのままでは不定形。分子の有理化をする。

有理化する

\[\sqrt{n^{2} + 8 n + 3}-\sqrt{n^{2} + 2 n}=\dfrac{(n^{2} + 8 n + 3)-(n^{2} + 2 n)}{\sqrt{n^{2} + 8 n + 3}+\sqrt{n^{2} + 2 n}}=\dfrac{6 n + 3}{\sqrt{n^{2} + 8 n + 3}+\sqrt{n^{2} + 2 n}}\]

根号の中から \(n\) をくくり出す

\(n>0\) なので \(\sqrt{n^2}=n\)。

\[\sqrt{n^{2} + 8 n + 3}=n\sqrt{1+\dfrac{8}{n}+\dfrac{3}{n^2}},\qquad \sqrt{n^{2} + 2 n}=n\sqrt{1+\dfrac{2}{n}}\]

分母・分子を \(n\) でわる。

\(n\) でわる

\[=\dfrac{6 + \dfrac{3}{n}}{\sqrt{1+\dfrac{8}{n}+\dfrac{3}{n^2}}+\sqrt{1+\dfrac{2}{n}}}\]

極限を求める

\(\dfrac1n\to0,\ \dfrac1{n^2}\to0\) だから、

\[\to\dfrac{6}{\sqrt1+\sqrt1}=\dfrac{6}{2}=3\]
