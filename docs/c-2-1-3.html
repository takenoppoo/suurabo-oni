章末問題恒等式・等式の証明・不等式の証明

例題1〜10で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. 等式 \(4 x^{3} - 5 x^{2} + x + 2=a(x--2)^3+b(x--2)^2+c(x--2)+d\) が \(x\) についての恒等式となるように、定数 \(a,b,c,d\) の値を定めよ。
  2. 等式 \(\dfrac{4 x - 9}{(x - 3)(x + 1)}=\dfrac{a}{x - 3}+\dfrac{b}{x + 1}\) が \(x\) についての恒等式となるように、定数 \(a,b\) の値を定めよ。
  3. \(a+b+c=0\) のとき、等式 \(a^{2} + a b + b^{2}=b^{2} + b c + c^{2}\) が成り立つことを証明せよ。
  4. \(a^{2} + 2 b^{2} + c^{2}\geqq 2 a b + 2 b c\) を証明せよ。ただし文字はすべて実数とし、等号が成り立つときの条件も答えよ。
  5. \(x>3\) のとき、\(5 x + \dfrac{20}{x - 3}\) の最小値と、そのときの \(x\) の値を求めよ。
  6. \(\dfrac{4 x^{2} + x - 2}{(x-1)(x-2)(x-3)}=\dfrac{a}{x-1}+\dfrac{b}{x-2}+\dfrac{c}{x-3}\) が \(x\) についての恒等式となるように \(a,b,c\) を定めよ。
  7. \(a+b+c=0\) のとき、\(a^3+b^3+c^3=3abc\) を証明せよ。
  8. 次の不等式を証明せよ。等号が成り立つ条件も答えよ。\(4x^2+y^2+2\geqq 4x+2y -\,0\)
  9. \(x>1\) のとき、\(x+\dfrac{36}{x-1}\) の最小値と、そのときの \(x\) の値を求めよ。
  10. \(x>0,\ y>0,\ x+y=14\) のとき、\(xy\) の最大値と \(\dfrac1x+\dfrac1y\) の最小値を求めよ。
