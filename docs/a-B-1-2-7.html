別冊練習問題 7 の解答　階差数列が等差数列のときの一般項

(1)　数列 \(3,\ 4,\ 7,\ 12,\ 19,\ 28,\ \cdots\) の階差数列が等差数列であるとき、一般項 \(a_n\) を求めよ。

階差数列

階差数列 \(b_n=1+2(n-1)\)。\(a_1,a_2,\ldots\)：

\[3,\ 4,\ 7,\ 12,\ 19,\ 28,\ \cdots\]

一般項の公式

\[a_n=a_1+\sum_{k=1}^{n-1}b_k=3+\sum_{k=1}^{n-1}(2 k - 1)\]

計算

\[a_n=n^{2} - 2 n + 4\]

\(n=1\) でも成り立つ。

【答案】

\[a_n=n^{2} - 2 n + 4\]

答

(2)　数列 \(2,\ 6,\ 12,\ 20,\ 30,\ 42,\ \cdots\) の階差数列が等差数列であるとき、一般項 \(a_n\) を求めよ。

階差数列

階差数列 \(b_n=4+2(n-1)\)。\(a_1,a_2,\ldots\)：

\[2,\ 6,\ 12,\ 20,\ 30,\ 42,\ \cdots\]

一般項の公式

\[a_n=a_1+\sum_{k=1}^{n-1}b_k=2+\sum_{k=1}^{n-1}(2 k + 2)\]

計算

\[a_n=n^{2} + n\]

\(n=1\) でも成り立つ。

【答案】

\[a_n=n^{2} + n\]

答

(3)　数列 \(5,\ 4,\ 6,\ 11,\ 19,\ 30,\ \cdots\) の階差数列が等差数列であるとき、一般項 \(a_n\) を求めよ。

階差数列

階差数列 \(b_n=-1+3(n-1)\)。\(a_1,a_2,\ldots\)：

\[5,\ 4,\ 6,\ 11,\ 19,\ 30,\ \cdots\]

一般項の公式

\[a_n=a_1+\sum_{k=1}^{n-1}b_k=5+\sum_{k=1}^{n-1}(3 k - 4)\]

計算

\[a_n=\dfrac{3 n^{2}}{2} - \dfrac{11 n}{2} + 9\]

\(n=1\) でも成り立つ。

【答案】

\[a_n=\dfrac{3 n^{2}}{2} - \dfrac{11 n}{2} + 9\]
