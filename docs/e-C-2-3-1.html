ホーム ＞ 数学C ＞ 複素数平面

例題 1平面上の曲線と複素数平面　極形式での積と商

\(z_1=1 + i,\ z_2=1 - i\) のとき、\(z_1z_2\) と \(\dfrac{z_1}{z_2}\) を、極形式を用いて計算せよ。

解き方（まず考え方）

\(z=r(\cos\theta+i\sin\theta)\)。積は絶対値をかけ偏角をたす、商は絶対値をわり偏角をひく。複素数のかけ算は「拡大と回転」。

コツかけ算＝拡大＋回転。わり算＝縮小＋逆回転。

解答

STEP 1 極形式にする

\(z=r(\cos\theta+i\sin\theta)\)。

\[z_1=\sqrt{2}\left(\cos\dfrac{\pi}{4}+i\sin\dfrac{\pi}{4}\right),\qquad z_2=\sqrt{2}\left(\cos- \dfrac{\pi}{4}+i\sin- \dfrac{\pi}{4}\right)\]
STEP 2 積

\(z_1z_2=r_1r_2\{\cos(\theta_1+\theta_2)+i\sin(\theta_1+\theta_2)\}\)。

\[z_1z_2=2\left(\cos0+i\sin0\right)=2\]
STEP 3 商

\(\dfrac{z_1}{z_2}=\dfrac{r_1}{r_2}\{\cos(\theta_1-\theta_2)+i\sin(\theta_1-\theta_2)\}\)。

\[\dfrac{z_1}{z_2}=1\left(\cos\dfrac{\pi}{2}+i\sin\dfrac{\pi}{2}\right)=i\]

【答案（テストに書く形）】

\[z_1z_2=2,\ \dfrac{z_1}{z_2}=i\]

答

練習問題 1

  1. \(z_1=\sqrt{3} + i,\ z_2=1 + \sqrt{3} i\) のとき、\(z_1z_2\) と \(\dfrac{z_1}{z_2}\) を、極形式を用いて計算せよ。
  2. \(z_1=\dfrac{3}{2} + \dfrac{3 \sqrt{3} i}{2},\ z_2=\sqrt{3} + i\) のとき、\(z_1z_2\) と \(\dfrac{z_1}{z_2}\) を、極形式を用いて計算せよ。
  3. \(z_1=-1 + \sqrt{3} i,\ z_2=\dfrac{1}{2} + \dfrac{\sqrt{3} i}{2}\) のとき、\(z_1z_2\) と \(\dfrac{z_1}{z_2}\) を、極形式を用いて計算せよ。
