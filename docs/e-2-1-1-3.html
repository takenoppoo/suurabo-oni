例題 3いろいろな式　分数式の加減（通分して約分）

次の計算をして、できるだけ簡単な分数式で答えよ。 \[\dfrac{2}{x - 1}+\dfrac{3}{x + 2}-\dfrac{6}{x^{2} + x - 2}\]

解き方（まず考え方）

分数式の足し算・引き算は分数と同じ。①分母を因数分解 ②最小公倍数で通分 ③分子を展開して整理 ④分子を因数分解して約分、の順に進める。

コツ通分は「全員の分母をそろえて同じ大きさのピザにする」こと。そろえてから、ピースの数（分子）を足す。

解答

STEP 1 分母を因数分解して通分する

\(x^{2} + x - 2=\left(x - 1\right)\left(x + 2\right)\) なので、共通分母は \(\left(x - 1\right)\left(x + 2\right)\)。

\[\dfrac{2}{x - 1}+\dfrac{3}{x + 2}-\dfrac{6}{x^{2} + x - 2}=\dfrac{2\left(x + 2\right)+3\left(x - 1\right)-6}{\left(x - 1\right)\left(x + 2\right)}\]
STEP 2 分子を展開して整理する
\[\dfrac{2 x + 4+3 x - 3-6}{\left(x - 1\right)\left(x + 2\right)}=\dfrac{5 x - 5}{\left(x - 1\right)\left(x + 2\right)}\]
STEP 3 分子を因数分解して約分する
\[\dfrac{5 x - 5}{\left(x - 1\right)\left(x + 2\right)}=\dfrac{5 \left(x - 1\right)}{\left(x - 1\right)\left(x + 2\right)}=\dfrac{5}{x + 2}\]

【答案（テストに書く形）】

\[\dfrac{5}{x + 2}\]
