別冊練習問題 5 の解答　sinθ+cosθ=t とおく最大・最小

(1)　\(0\leqq\theta<2\pi\) のとき、\(y=2\sin\theta\cos\theta+1(\sin\theta+\cos\theta)\) の最大値・最小値を求めよ。

\(t=\sin\theta+\cos\theta\) とおく

\(t=\sqrt2\sin\left(\theta+\dfrac\pi4\right)\) だから \(-\sqrt2\leqq t\leqq\sqrt2\)。

\(\sin\theta\cos\theta\) を \(t\) で表す

\(t^2=1+2\sin\theta\cos\theta\) より

\[2\sin\theta\cos\theta=t^2-1\]

\(y\) を \(t\) の2次関数にする

\[y=(t^2-1)+1t=t^{2} + t - 1\]\[y=\left(t+\dfrac{1}{2}\right)^2- \dfrac{5}{4}\]

\(-\sqrt2\leqq t\leqq\sqrt2\) での最大・最小

頂点 \(t=- \dfrac{1}{2}\) は範囲の内側。

\[t=- \sqrt{2}:\ y=- \sqrt{2} + 1,\quad t=\sqrt{2}:\ y=1 + \sqrt{2},\quad t=- \dfrac{1}{2}:\ y=- \dfrac{5}{4}\]

答え

最大値 \(1 + \sqrt{2}\)、最小値 \(- \dfrac{5}{4}\)。

【答案】

\[\text{最大値 }1 + \sqrt{2},\quad \text{最小値 }- \dfrac{5}{4}\]

答

(2)　\(0\leqq\theta<2\pi\) のとき、\(y=2\sin\theta\cos\theta-4(\sin\theta+\cos\theta)+1\) の最大値・最小値を求めよ。

\(t=\sin\theta+\cos\theta\) とおく

\(t=\sqrt2\sin\left(\theta+\dfrac\pi4\right)\) だから \(-\sqrt2\leqq t\leqq\sqrt2\)。

\(\sin\theta\cos\theta\) を \(t\) で表す

\(t^2=1+2\sin\theta\cos\theta\) より

\[2\sin\theta\cos\theta=t^2-1\]

\(y\) を \(t\) の2次関数にする

\[y=(t^2-1)-4t+1=t^{2} - 4 t\]\[y=\left(t-2\right)^2-4\]

\(-\sqrt2\leqq t\leqq\sqrt2\) での最大・最小

頂点 \(t=2\) は範囲の外側。

\[t=- \sqrt{2}:\ y=2 + 4 \sqrt{2},\quad t=\sqrt{2}:\ y=- 4 \sqrt{2} + 2\]

答え

最大値 \(2 + 4 \sqrt{2}\)、最小値 \(- 4 \sqrt{2} + 2\)。

【答案】

\[\text{最大値 }2 + 4 \sqrt{2},\quad \text{最小値 }- 4 \sqrt{2} + 2\]

答

(3)　\(0\leqq\theta<2\pi\) のとき、\(y=2\sin\theta\cos\theta+3(\sin\theta+\cos\theta)-1\) の最大値・最小値を求めよ。

\(t=\sin\theta+\cos\theta\) とおく

\(t=\sqrt2\sin\left(\theta+\dfrac\pi4\right)\) だから \(-\sqrt2\leqq t\leqq\sqrt2\)。

\(\sin\theta\cos\theta\) を \(t\) で表す

\(t^2=1+2\sin\theta\cos\theta\) より

\[2\sin\theta\cos\theta=t^2-1\]

\(y\) を \(t\) の2次関数にする

\[y=(t^2-1)+3t-1=t^{2} + 3 t - 2\]\[y=\left(t+\dfrac{3}{2}\right)^2- \dfrac{17}{4}\]

\(-\sqrt2\leqq t\leqq\sqrt2\) での最大・最小

頂点 \(t=- \dfrac{3}{2}\) は範囲の外側。

\[t=- \sqrt{2}:\ y=- 3 \sqrt{2},\quad t=\sqrt{2}:\ y=3 \sqrt{2}\]

答え

最大値 \(3 \sqrt{2}\)、最小値 \(- 3 \sqrt{2}\)。

【答案】

\[\text{最大値 }3 \sqrt{2},\quad \text{最小値 }- 3 \sqrt{2}\]
