別冊練習問題 3 の解答　解の条件から定数を決める（実数解の確認つき）

(1)　\(x^2-8x+a=0\ \text{の2つの解の差が}\ 2\)

\(\alpha+\beta=8,\ \alpha\beta=a\)。\(64-4a=4\) より \(a=15\)。確かめ：\(x^2-8x+15=(x-3)(x-5)\)、差 \(2\)。

【答案】

\[a=15\]

答

(2)　\(x^2-4x+a=0\ \text{の2つの解の2乗の和が}\ 20\)

\(\alpha+\beta=4,\ \alpha\beta=a\)。\(\alpha^2+\beta^2=16-2a=20\) より \(a=-2\)。確かめ：\(x^2-4x-2=0\) の判別式 \(D/4=4+2=6>0\)（実数解あり）。

【答案】

\[a=-2\]

答

(3)　\(x^2+6x+a=0\ \text{の2つの解の差が}\ 4\)

\(\alpha+\beta=-6,\ \alpha\beta=a\)。\((\alpha-\beta)^2=36-4a=16\) より \(a=5\)。確かめ：\(x^2+6x+5=(x+1)(x+5)\)、解 \(-1,-5\)、差 \(4\)。

【答案】

\[a=5\]
