例題 2積分法　分子が分母の導関数になる積分

不定積分 \(\displaystyle\int\dfrac{2 x + 2}{x^{2} + 2 x + 1}\,dx\) を求めよ。

解き方（まず考え方）

\(\displaystyle\int\dfrac{g'}{g}dx=\log|g|+C\)。分母の導関数を計算し、分子との定数倍の関係を見抜く。\(x^2+cx+1>0\) なので絶対値は不要。

コツ分子が分母の導関数なら、対数に直行。

解答

STEP 1 分子と分母の関係

分母 \(g(x)=x^{2} + 2 x + 1\) の導関数は \(g'(x)=2 x + 2\)。分子はその \(1\) 倍。

STEP 2 公式
\[\int\dfrac{g'(x)}{g(x)}dx=\log|g(x)|+C\]
STEP 3 積分
\[\int\dfrac{2 x + 2}{x^{2} + 2 x + 1}dx=1\int\dfrac{2 x + 2}{x^{2} + 2 x + 1}dx=1\log(x^{2} + 2 x + 1)+C\]

【答案（テストに書く形）】

\[1\log(x^{2} + 2 x + 1)+C\]
