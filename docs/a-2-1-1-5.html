別冊練習問題 5 の解答　部分分数に分けて和を求める

(1)　次の和を計算せよ。 \[\dfrac{1}{x(x + 1)}+\dfrac{1}{(x + 1)(x + 2)}+\dfrac{1}{(x + 2)(x + 3)}+\dfrac{1}{(x + 3)(x + 4)}\]

1項ずつ部分分数に分ける

公式 \(\dfrac1{A(A+d)}=\dfrac1d\left(\dfrac1A-\dfrac1{A+d}\right)\) を使う。（確かめ：\(\dfrac1A-\dfrac1{A+d}=\dfrac{d}{A(A+d)}\)）

\[\dfrac1{1}\left(\dfrac{1}{x}-\dfrac{1}{x + 1}\right)+\dfrac1{1}\left(\dfrac{1}{x + 1}-\dfrac{1}{x + 2}\right)+\dfrac1{1}\left(\dfrac{1}{x + 2}-\dfrac{1}{x + 3}\right)+\dfrac1{1}\left(\dfrac{1}{x + 3}-\dfrac{1}{x + 4}\right)\]

途中の項が消える

前の項の「\(-\)」と次の項の「\(+\)」が打ち消し合う。残るのは最初と最後だけ。

\[\dfrac1{1}\left(\dfrac{1}{x}-\dfrac{1}{x + 4}\right)\]

通分してまとめる

\[\dfrac1{1}\cdot\dfrac{x + 4-x}{x(x + 4)}=\dfrac1{1}\cdot\dfrac{4}{x(x + 4)}=\dfrac{4}{x(x + 4)}\]

【答案】

\[\dfrac{4}{x(x + 4)}\]

答

(2)　次の和を計算せよ。 \[\dfrac{1}{x(x + 3)}+\dfrac{1}{(x + 3)(x + 6)}+\dfrac{1}{(x + 6)(x + 9)}\]

1項ずつ部分分数に分ける

公式 \(\dfrac1{A(A+d)}=\dfrac1d\left(\dfrac1A-\dfrac1{A+d}\right)\) を使う。（確かめ：\(\dfrac1A-\dfrac1{A+d}=\dfrac{d}{A(A+d)}\)）

\[\dfrac1{3}\left(\dfrac{1}{x}-\dfrac{1}{x + 3}\right)+\dfrac1{3}\left(\dfrac{1}{x + 3}-\dfrac{1}{x + 6}\right)+\dfrac1{3}\left(\dfrac{1}{x + 6}-\dfrac{1}{x + 9}\right)\]

途中の項が消える

前の項の「\(-\)」と次の項の「\(+\)」が打ち消し合う。残るのは最初と最後だけ。

\[\dfrac1{3}\left(\dfrac{1}{x}-\dfrac{1}{x + 9}\right)\]

通分してまとめる

\[\dfrac1{3}\cdot\dfrac{x + 9-x}{x(x + 9)}=\dfrac1{3}\cdot\dfrac{9}{x(x + 9)}=\dfrac{3}{x(x + 9)}\]

【答案】

\[\dfrac{3}{x(x + 9)}\]

答

(3)　次の和を計算せよ。 \[\dfrac{1}{x(x + 2)}+\dfrac{1}{(x + 2)(x + 4)}+\dfrac{1}{(x + 4)(x + 6)}+\dfrac{1}{(x + 6)(x + 8)}+\dfrac{1}{(x + 8)(x + 10)}\]

1項ずつ部分分数に分ける

公式 \(\dfrac1{A(A+d)}=\dfrac1d\left(\dfrac1A-\dfrac1{A+d}\right)\) を使う。（確かめ：\(\dfrac1A-\dfrac1{A+d}=\dfrac{d}{A(A+d)}\)）

\[\dfrac1{2}\left(\dfrac{1}{x}-\dfrac{1}{x + 2}\right)+\dfrac1{2}\left(\dfrac{1}{x + 2}-\dfrac{1}{x + 4}\right)+\dfrac1{2}\left(\dfrac{1}{x + 4}-\dfrac{1}{x + 6}\right)+\dfrac1{2}\left(\dfrac{1}{x + 6}-\dfrac{1}{x + 8}\right)+\dfrac1{2}\left(\dfrac{1}{x + 8}-\dfrac{1}{x + 10}\right)\]

途中の項が消える

前の項の「\(-\)」と次の項の「\(+\)」が打ち消し合う。残るのは最初と最後だけ。

\[\dfrac1{2}\left(\dfrac{1}{x}-\dfrac{1}{x + 10}\right)\]

通分してまとめる

\[\dfrac1{2}\cdot\dfrac{x + 10-x}{x(x + 10)}=\dfrac1{2}\cdot\dfrac{10}{x(x + 10)}=\dfrac{5}{x(x + 10)}\]

【答案】

\[\dfrac{5}{x(x + 10)}\]
