章末問題導関数の計算

例題1〜10で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. \(y=(x^{2} - 3 x + 2)e^{-2x}\) を微分せよ。
  2. \(y=\dfrac{2 x + 5}{x^{2} + 1}\) を微分せよ。
  3. \(y=\sin^{2}(3 x^{2} + 2 x)\) を微分せよ。
  4. \(y=\log(x^{2} + 5)-2\log x\ (x>0)\) を微分せよ。
  5. \(y=x^{3}e^{-2x}\ (x>0)\) を、対数微分法で微分せよ。
  6. 曲線 \(x=\log{\left(t \right)},\ y=t^{2}\) の \(t=1\) に対応する点における接線の傾きと接線の方程式を求めよ。
  7. 楕円 \(\dfrac{x^2}{36}+\dfrac{y^2}{9}=1\) 上の点 \(\left(3,\ \dfrac{3 \sqrt{3}}{2}\right)\) における接線の方程式を、陰関数の微分で求めよ。
  8. \(f(x)=\sin4x\) の第 \(n\) 次導関数を求めよ。
  9. \(f(x)=x e^{x}\) のとき、\(\displaystyle\lim_{h\to0}\dfrac{f(1+h)-f(1)}{h}\) を、微分係数の定義を用いて求めよ。
  10. \(y=x^{5x}\ (x>0)\) を微分せよ。
