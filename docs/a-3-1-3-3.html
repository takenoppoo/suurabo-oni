別冊練習問題 3 の解答　$x\to\infty$ の無理式の極限

(1)　次の極限値を求めよ。 \[\lim_{x\to\infty}\left(\sqrt{4 x^{2} + 8 x}-\sqrt{4 x^{2}}\right)\]

\(\infty-\infty\) の形

有理化する。

有理化

\[\sqrt{4 x^{2} + 8 x}-\sqrt{4 x^{2}}=\dfrac{8 x}{\sqrt{4 x^{2} + 8 x}+\sqrt{4 x^{2}}}\]

\(x\) でわって \(x\to\infty\)

\[=\dfrac{8}{\sqrt{4+\frac{8}{x}}+\sqrt{4+\frac{0}{x}}}\to\dfrac{8}{22}=2\]

(2)　次の極限値を求めよ。 \[\lim_{x\to\infty}\left(\sqrt{x^{2} + 3 x}-\sqrt{x^{2} - x}\right)\]

\(\infty-\infty\) の形

有理化する。

有理化

\[\sqrt{x^{2} + 3 x}-\sqrt{x^{2} - x}=\dfrac{4 x}{\sqrt{x^{2} + 3 x}+\sqrt{x^{2} - x}}\]

\(x\) でわって \(x\to\infty\)

\[=\dfrac{4}{\sqrt{1+\frac{3}{x}}+\sqrt{1+\frac{-1}{x}}}\to\dfrac{4}{2}=2\]

有理化

\(x\) でわって \(x\to\infty\)
