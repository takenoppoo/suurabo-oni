例題 6平面上の曲線と複素数平面　点を別の点のまわりに回転する

複素数平面上で、点 \(\beta=3 + i\) を、点 \(\alpha=1 + i\) を中心に \(90^\circ\) 回転した点 \(\gamma\) を求めよ。

解き方（まず考え方）

回転の中心 \(\alpha\) を原点に移し、\(\gamma-\alpha=(\cos\theta+i\sin\theta)(\beta-\alpha)\)。最後に \(\alpha\) を足す。

コツ中心を原点に平行移動 → 回す → 戻す。

解答

STEP 1 αを原点に移す

\[\beta-\alpha=3 + i-(1 + i)=2\]

STEP 2 回転

\(90^\circ\) 回転は \(\cos90^\circ+i\sin90^\circ=i\) をかける。

\[\gamma-\alpha=\left(i\right)(2)\]
STEP 3 もとに戻す

\[\gamma=\alpha+(\gamma-\alpha)=1 + 3 i\]

【答案（テストに書く形）】

\[\gamma=1 + 3 i\]
