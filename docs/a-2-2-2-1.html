別冊練習問題 1 の解答　3点を通る円の方程式

(1)　3点 \(A(0,\ 0)\)、\(B(6,\ 0)\)、\(C(2,\ 4)\) を通る円の方程式を求めよ。また、その中心と半径を答えよ。

円の方程式を一般形でおく

\(x^2+y^2+lx+my+n=0\) とおき、3点の座標を代入する。

\[\begin{cases}n=0\\ 6 l + n + 36=0\\ 2 l + 4 m + n + 20=0\end{cases}\]

連立方程式を解く

上から順に引き算して文字を減らすと

\[l=-6,\quad m=-2,\quad n=0\]

標準形に直す（平方完成）

\[x^{2} - 6 x + y^{2} - 2 y=0\]\[(x-3)^2+(y-1)^2=10\]

【答案】

\[(x-3)^2+(y-1)^2=10\qquad \text{中心 }(3,\ 1),\ \text{半径 }\sqrt{10}\]

答

(2)　3点 \(A(-1,\ 1)\)、\(B(3,\ -3)\)、\(C(5,\ 3)\) を通る円の方程式を求めよ。また、その中心と半径を答えよ。

円の方程式を一般形でおく

\(x^2+y^2+lx+my+n=0\) とおき、3点の座標を代入する。

\[\begin{cases}- l + m + n + 2=0\\ 3 l - 3 m + n + 18=0\\ 5 l + 3 m + n + 34=0\end{cases}\]

連立方程式を解く

上から順に引き算して文字を減らすと

\[l=-5,\quad m=-1,\quad n=-6\]

標準形に直す（平方完成）

\[x^{2} - 5 x + y^{2} - y - 6=0\]\[(x-2)^2+y^2=\dfrac{25}{2}\]

【答案】

\[(x-2)^2+y^2=\dfrac{25}{2}\qquad \text{中心 }(\dfrac{5}{2},\ \dfrac{1}{2}),\ \text{半径 }\dfrac{5 \sqrt{2}}{2}\]

答

(3)　3点 \(A(2,\ -1)\)、\(B(4,\ 5)\)、\(C(-2,\ 3)\) を通る円の方程式を求めよ。また、その中心と半径を答えよ。

円の方程式を一般形でおく

\(x^2+y^2+lx+my+n=0\) とおき、3点の座標を代入する。

\[\begin{cases}2 l - m + n + 5=0\\ 4 l + 5 m + n + 41=0\\ - 2 l + 3 m + n + 13=0\end{cases}\]

連立方程式を解く

上から順に引き算して文字を減らすと

\[l=-3,\quad m=-5,\quad n=-4\]

標準形に直す（平方完成）

\[x^{2} - 3 x + y^{2} - 5 y - 4=0\]\[(x-1)^2+(y-2)^2=\dfrac{25}{2}\]

【答案】

\[(x-1)^2+(y-2)^2=\dfrac{25}{2}\qquad \text{中心 }(\dfrac{3}{2},\ \dfrac{5}{2}),\ \text{半径 }\dfrac{5 \sqrt{2}}{2}\]
