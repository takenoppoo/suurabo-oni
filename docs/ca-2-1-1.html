別冊章末問題の解答

1.　整式 \(5 x^{4} - 3 x^{3} + 2 x - 7\) を \(5 x^{2} + 2 x - 1\) で割ったときの商と余りを求めよ。

商を1項ずつ立てて引く

最高次の項どうしを割って商の項を決め、（割る式）×（商の項）を引く。余りの次数が割る式より小さくなるまで繰り返す。

\(5 x^{4}\div\left(5 x^{2}\right)=x^{2}\) を商に立てる。

\[5 x^{4} - 3 x^{3} + 2 x - 7-\left(x^{2}\right)\left(5 x^{2} + 2 x - 1\right)=- 5 x^{3} + x^{2} + 2 x - 7\]

\(- 5 x^{3}\div\left(5 x^{2}\right)=- x\) を商に立てる。

\[- 5 x^{3} + x^{2} + 2 x - 7-\left(- x\right)\left(5 x^{2} + 2 x - 1\right)=3 x^{2} + x - 7\]

\(3 x^{2}\div\left(5 x^{2}\right)=\dfrac{3}{5}\) を商に立てる。

\[3 x^{2} + x - 7-\left(\dfrac{3}{5}\right)\left(5 x^{2} + 2 x - 1\right)=- \dfrac{x}{5} - \dfrac{32}{5}\]

商と余りを読む

\[\text{商 }x^{2} - x + \dfrac{3}{5},\quad \text{余り }- \dfrac{x}{5} - \dfrac{32}{5}\]

確かめ

\[\begin{aligned}&\left(5 x^{2} + 2 x - 1\right)\left(x^{2} - x + \dfrac{3}{5}\right)+\left(- \dfrac{x}{5} - \dfrac{32}{5}\right)\\ &=5 x^{4} - 3 x^{3} + 2 x - 7\end{aligned}\]

（例題1の型）

【答案】

\[\text{商 }x^{2} - x + \dfrac{3}{5},\quad \text{余り }- \dfrac{x}{5} - \dfrac{32}{5}\]

答

2.　整式 \(P(x)\) を \(x^{2} + x - 6\) で割ると、商が \(2 x + 5\)、余りが \(- 3 x + 2\) である。(1) \(P(x)\) を求めよ。(2) \(P(x)\) を \(x - 2\) で割った余りを求めよ。

割り算の関係式を書く

\[P(x)=(\text{割る式})\times(\text{商})+(\text{余り})\]\[P(x)=\left(x^{2} + x - 6\right)\left(2 x + 5\right)+\left(- 3 x + 2\right)\]

展開して \(P(x)\) を求める

\[P(x)=2 x^{3} + 7 x^{2} - 10 x - 28\]

割る式を因数分解する

\[x^{2} + x - 6=(x - 2)(x + 3)\]

よって \(P(x)=(x - 2)\{(x + 3)(2 x + 5)\}+(- 3 x + 2)\)。

余りを x - 2 で割る

\(x - 2\) で割ったとき、商のかたまりの部分は割り切れる。残る \(- 3 x + 2\) を \(x - 2\) で割った余りが答え。

\[- 3 x + 2=-3\left(x - 2\right)+-4\ \Rightarrow\ \text{余り }-4\]

（例題2の型）

【答案】

\[P(x)=2 x^{3} + 7 x^{2} - 10 x - 28,\quad \text{余り }-4\]

答

3.　次の計算をして、できるだけ簡単な分数式で答えよ。 \[\dfrac{4}{x + 1}-\dfrac{3}{x - 2}+\dfrac{12}{x^{2} - x - 2}\]

分母を因数分解して通分する

\(x^{2} - x - 2=\left(x + 1\right)\left(x - 2\right)\) なので、共通分母は \(\left(x + 1\right)\left(x - 2\right)\)。

\[\dfrac{4}{x + 1}-\dfrac{3}{x - 2}+\dfrac{12}{x^{2} - x - 2}=\dfrac{4\left(x - 2\right)-3\left(x + 1\right)+12}{\left(x + 1\right)\left(x - 2\right)}\]

分子を展開して整理する

\[\dfrac{4 x - 8- 3 x - 3+12}{\left(x + 1\right)\left(x - 2\right)}=\dfrac{x + 1}{\left(x + 1\right)\left(x - 2\right)}\]

分子を因数分解して約分する

\[\dfrac{x + 1}{\left(x + 1\right)\left(x - 2\right)}=\dfrac{x + 1}{\left(x + 1\right)\left(x - 2\right)}=\dfrac{1}{x - 2}\]

（例題3の型）

【答案】

\[\dfrac{1}{x - 2}\]

答

4.　次の計算をせよ。 \[\dfrac{x^{2} - 7 x + 6}{x^{2} - 4 x - 12}\div\dfrac{x^{2} + 4 x - 5}{x^{2} + 4 x + 4}\]

各式を因数分解する

\[\dfrac{x^{2} - 7 x + 6}{x^{2} - 4 x - 12}=\dfrac{(x - 1)(x - 6)}{(x + 2)(x - 6)}\qquad \dfrac{x^{2} + 4 x - 5}{x^{2} + 4 x + 4}=\dfrac{(x - 1)(x + 5)}{(x + 2)(x + 2)}\]

割り算を、逆数の掛け算に直す

\[\dfrac{(x - 1)(x - 6)}{(x + 2)(x - 6)}\times\dfrac{(x + 2)(x + 2)}{(x - 1)(x + 5)}\]

約分する

分子と分母に共通な因数を消す。

\[\dfrac{x + 2}{x + 5}=\dfrac{x + 2}{x + 5}\]

（例題4の型）

【答案】

\[\dfrac{x + 2}{x + 5}\]

答

5.　次の和を計算せよ。 \[\dfrac{1}{x(x + 4)}+\dfrac{1}{(x + 4)(x + 8)}+\dfrac{1}{(x + 8)(x + 12)}\]

1項ずつ部分分数に分ける

公式 \(\dfrac1{A(A+d)}=\dfrac1d\left(\dfrac1A-\dfrac1{A+d}\right)\) を使う。（確かめ：\(\dfrac1A-\dfrac1{A+d}=\dfrac{d}{A(A+d)}\)）

\[\dfrac1{4}\left(\dfrac{1}{x}-\dfrac{1}{x + 4}\right)+\dfrac1{4}\left(\dfrac{1}{x + 4}-\dfrac{1}{x + 8}\right)+\dfrac1{4}\left(\dfrac{1}{x + 8}-\dfrac{1}{x + 12}\right)\]

途中の項が消える

前の項の「\(-\)」と次の項の「\(+\)」が打ち消し合う。残るのは最初と最後だけ。

\[\dfrac1{4}\left(\dfrac{1}{x}-\dfrac{1}{x + 12}\right)\]

通分してまとめる

\[\dfrac1{4}\cdot\dfrac{x + 12-x}{x(x + 12)}=\dfrac1{4}\cdot\dfrac{12}{x(x + 12)}=\dfrac{3}{x(x + 12)}\]

（例題5の型）

【答案】

\[\dfrac{3}{x(x + 12)}\]

答

6.　\(4 x^{4} + x^{2} - x + 6\) を \(2 x^{2} - x + 1\) で割ったときの商と余りを求めよ。

筆算の要領で割る

最高次の項どうしを割って商を立て、引く操作をくり返す（次数が \(Q\) より下がるまで）。

商と余り

\[\text{商 }2 x^{2} + x,\qquad \text{余り }- 2 x + 6\]

検算

\[(2 x^{2} - x + 1)(2 x^{2} + x)+(- 2 x + 6)=4 x^{4} + x^{2} - x + 6\]

（例題6の型）

【答案】

\[\text{商 }2 x^{2} + x,\ \text{余り }- 2 x + 6\]

答

7.　次の式を簡単にせよ。\(\dfrac{\dfrac{1}{x-2}-\dfrac{1}{x+5}}{\dfrac{1}{x-2}+\dfrac{1}{x+5}}\)

分子を通分する

分子 \(\dfrac1{x-2}-\dfrac1{x+5}\) の分母をそろえる。

\[\dfrac{x+5}{(x-2)(x+5)}-\dfrac{x-2}{(x-2)(x+5)}=\dfrac{(x+5)-(x-2)}{(x-2)(x+5)}=\dfrac{7}{(x-2)(x+5)}\]

分母を通分する

分母 \(\dfrac1{x-2}+\dfrac1{x+5}\) も同じ分母にそろえる。

\[\dfrac{x+5}{(x-2)(x+5)}+\dfrac{x-2}{(x-2)(x+5)}=\dfrac{(x+5)+(x-2)}{(x-2)(x+5)}=\dfrac{2 x + 3}{(x-2)(x+5)}\]

割り算にして約分

分子 \(\div\) 分母 は、分母の逆数をかける。

\[\dfrac{7}{(x-2)(x+5)}\div\dfrac{2 x + 3}{(x-2)(x+5)}=\dfrac{7}{(x-2)(x+5)}\times\dfrac{(x-2)(x+5)}{2 x + 3}\]

\((x-2)(x+5)\) が約分できる。

\[=\dfrac{7}{2 x + 3}\]

（例題7の型）

【答案】

\[\dfrac{7}{2 x + 3}\]

答

8.　\(\displaystyle\sum_{k=1}^{8}\dfrac{1}{k(k+4)}\) の値を求めよ。

部分分数に分ける

\(\dfrac1{k(k+4)}=\dfrac1{4}\left(\dfrac1k-\dfrac1{k+4}\right)\)。

和をとる

\(k=1,\ldots,8\) で、4 つおきに打ち消し合う。

\[\dfrac1{4}\left(\dfrac1{1}+\dfrac1{2}+\dfrac1{3}+\dfrac1{4}-\dfrac1{9}+\dfrac1{10}+\dfrac1{11}+\dfrac1{12}\right)\]

計算

\[\dfrac{1681}{3960}\]

（例題8の型）

【答案】

\[\dfrac{1681}{3960}\]

答

9.　整式 \(x^4+Ax^2+Bx-6\) が \(x^{2} + 2 x - 3\) で割り切れるように、定数 \(A,\ B\) の値を定めよ。

割り算して余りを求める

\(x^4+Ax^2+Bx-6\) を \(x^{2} + 2 x - 3\) で割った余り：

\[- 2 A x + 3 A + B x - 20 x + 15\]

余り \(=0\) より

\(x\) の係数と定数項がともに 0。

\[A=-5,\quad B=10\]

（例題9の型）

【答案】

\[A=-5,\ B=10\]

答

10.　整数 \(n\) について、\(\dfrac{n^2+5n+12}{n+1}\) が整数となるような \(n\) をすべて求めよ。

割り算

\[\dfrac{n^2+5n+12}{n+1}=n+4+\dfrac{8}{n+1}\]

整数になる条件

\(n+1\) が \(8\) の約数：\(n+1=\pm1,\ \pm2,\ \pm4,\ \pm8\)。

答え

\[n=-9,\ -5,\ -3,\ -2,\ 0,\ 1,\ 3,\ 7\]

（例題10の型）

【答案】

\[n=-9,\ -5,\ -3,\ -2,\ 0,\ 1,\ 3,\ 7\]

答
