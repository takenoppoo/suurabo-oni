ホーム ＞ 数学III ＞ 数列の極限

例題 1極限　分数式の極限（最高次でわる）

次の極限値を求めよ。 \[\lim_{n\to\infty}\dfrac{3 n^{2} + 2 n + 1}{2 n^{2} - n + 5}\]

解き方（まず考え方）

分母・分子を分母の最高次の項でわる。\(\dfrac1n,\ \dfrac1{n^2},\cdots\to0\) を使う。\(\dfrac{\infty}{\infty}\) のまま判断しない。

コツ一番強い項（最高次）だけが、\(n\) が大きいときの勝負を決める。

解答

STEP 1 最高次の項でわる

分母の最高次は \(n^2\)。分母・分子を \(n^2\) でわる。

\[\dfrac{3 n^{2} + 2 n + 1}{2 n^{2} - n + 5}=\dfrac{3 + \dfrac{2}{n} + \dfrac{1}{n^{2}}}{2 - \dfrac{1}{n} + \dfrac{5}{n^{2}}}\]
STEP 2 \(\dfrac1n,\ \dfrac1{n^2}\to0\) を使う

\(\lim_{n\to\infty}\dfrac1n=0,\ \ \lim_{n\to\infty}\dfrac1{n^2}=0\)。

\[\lim_{n\to\infty}\dfrac{3 + \dfrac{2}{n} + \dfrac{1}{n^{2}}}{2 - \dfrac{1}{n} + \dfrac{5}{n^{2}}}=\dfrac{3+0+0}{2+0+0}=\dfrac{3}{2}\]

【答案（テストに書く形）】

\[\dfrac{3}{2}\]
