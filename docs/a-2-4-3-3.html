別冊練習問題 3 の解答　小数第何位に初めて0でない数字が現れるか

(1)　\(\log_{10}2=0.3010,\ \log_{10}3=0.4771\) として、\(\left(\dfrac1{3}\right)^{30}\) を小数で表したとき、小数第何位にはじめて 0 でない数字が現れるか。

常用対数をとる

\[\log_{10}\left(\dfrac1{3}\right)^{30}=-30\log_{10}3=-30\times\left(\log_{10}3\right)=-14.3130\]

整数ではさむ

\(-15\leqq\log_{10}x<-14\) のとき \(10^{-15}\leqq x<10^{-14}\)。

\[-15\leqq -14.3130<-14\]

小数第何位かを決める

\(10^{-15}\leqq x<10^{-14}\) より、\(x\) を小数で書くと小数第 \(15\) 位にはじめて 0 でない数字が現れる。

【答案】

\[\text{小数第 15 位}\]

答
