ホーム ＞ 数学III ＞ 不定積分・置換積分・部分積分

別冊練習問題 6 の解答　x√(ax+b) の置換積分

(1)　不定積分 \(\displaystyle\int x\sqrt{2x+1}\,dx\) を求めよ。

置換を決める

根号の中身を文字にする。

\[u=\sqrt{2x+1}\]

両辺を2乗して \(x\) を \(u\) で表す。

\[u^2=2x+1\ \Rightarrow\ x=\dfrac{u^2-1}{2}\]

\(dx\) を \(u\) で表す

\(u^2=2x+1\) の両辺を微分する。

\[2u\,du=2\,dx\ \Rightarrow\ dx=\dfrac{2u}{2}\,du\]

\(u\) の式に書きかえる

\[\int x\sqrt{2x+1}\,dx=\int\dfrac{u^2-1}{2}\cdot u\cdot\dfrac{2u}{2}\,du\]

係数をまとめ、\(u\) の累乗を整理する。

\[=\dfrac{1}{2}\int(u^2-1)u^2\,du=\dfrac{1}{2}\int(u^4-u^2)\,du\]

積分する

\(\int u^ndu=\dfrac{u^{n+1}}{n+1}\) を使う。

\[=\dfrac{1}{2}\left(\dfrac{u^5}{5}-\dfrac{u^3}{3}\right)+C=\dfrac{u^{5}}{10} - \dfrac{u^{3}}{6}+C\]

\(x\) に戻す

\(u^3\) でくくり、\(u^2=2x+1\) を使う。

\[=\dfrac{1}{2}\,u^3\left(\dfrac{u^2}{5}-\dfrac{1}{3}\right)=\dfrac{1}{2}\,u^3\cdot\dfrac{3u^2-5}{15}\]

\(u^2=2x+1\)、\(u^3=(2x+1)\sqrt{2x+1}\) を入れる。

\[3u^2-5=3(2x+1)-5=6 x - 2\]\[=\dfrac{1}{30}(2x+1)\sqrt{2x+1}\,(6 x - 2)+C\]

（\((2x+1)\sqrt{2x+1}=(2x+1)^{\frac32}\)）

【答案】

\[\dfrac{1}{30}(2x+1)\sqrt{2x+1}\,(6 x - 2)+C\]

答

(2)　不定積分 \(\displaystyle\int x\sqrt{x+4}\,dx\) を求めよ。

置換を決める

根号の中身を文字にする。

\[u=\sqrt{x+4}\]

両辺を2乗して \(x\) を \(u\) で表す。

\[u^2=x+4\ \Rightarrow\ x=u^2-4\]

\(dx\) を \(u\) で表す

\(u^2=x+4\) の両辺を微分する。

\[2u\,du=\,dx\ \Rightarrow\ dx=2u\,du\]

\(u\) の式に書きかえる

\[\int x\sqrt{x+4}\,dx=\int(u^2-4)\cdot u\cdot2u\,du\]

係数をまとめ、\(u\) の累乗を整理する。

\[=2\int(u^2-4)u^2\,du=2\int(u^4-4u^2)\,du\]

積分する

\(\int u^ndu=\dfrac{u^{n+1}}{n+1}\) を使う。

\[=2\left(\dfrac{u^5}{5}-\dfrac{4u^3}{3}\right)+C=\dfrac{2 u^{5}}{5} - \dfrac{8 u^{3}}{3}+C\]

\(x\) に戻す

\(u^3\) でくくり、\(u^2=x+4\) を使う。

\[=2\,u^3\left(\dfrac{u^2}{5}-\dfrac{4}{3}\right)=2\,u^3\cdot\dfrac{3u^2-20}{15}\]

\(u^2=x+4\)、\(u^3=(x+4)\sqrt{x+4}\) を入れる。

\[3u^2-20=3(x+4)-20=3 x - 8\]\[=\dfrac{2}{15}(x+4)\sqrt{x+4}\,(3 x - 8)+C\]

（\((x+4)\sqrt{x+4}=(x+4)^{\frac32}\)）

【答案】

\[\dfrac{2}{15}(x+4)\sqrt{x+4}\,(3 x - 8)+C\]

答

(3)　不定積分 \(\displaystyle\int x\sqrt{3x+1}\,dx\) を求めよ。

置換を決める

根号の中身を文字にする。

\[u=\sqrt{3x+1}\]

両辺を2乗して \(x\) を \(u\) で表す。

\[u^2=3x+1\ \Rightarrow\ x=\dfrac{u^2-1}{3}\]

\(dx\) を \(u\) で表す

\(u^2=3x+1\) の両辺を微分する。

\[2u\,du=3\,dx\ \Rightarrow\ dx=\dfrac{2u}{3}\,du\]

\(u\) の式に書きかえる

\[\int x\sqrt{3x+1}\,dx=\int\dfrac{u^2-1}{3}\cdot u\cdot\dfrac{2u}{3}\,du\]

係数をまとめ、\(u\) の累乗を整理する。

\[=\dfrac{2}{9}\int(u^2-1)u^2\,du=\dfrac{2}{9}\int(u^4-u^2)\,du\]

積分する

\(\int u^ndu=\dfrac{u^{n+1}}{n+1}\) を使う。

\[=\dfrac{2}{9}\left(\dfrac{u^5}{5}-\dfrac{u^3}{3}\right)+C=\dfrac{2 u^{5}}{45} - \dfrac{2 u^{3}}{27}+C\]

\(x\) に戻す

\(u^3\) でくくり、\(u^2=3x+1\) を使う。

\[=\dfrac{2}{9}\,u^3\left(\dfrac{u^2}{5}-\dfrac{1}{3}\right)=\dfrac{2}{9}\,u^3\cdot\dfrac{3u^2-5}{15}\]

\(u^2=3x+1\)、\(u^3=(3x+1)\sqrt{3x+1}\) を入れる。

\[3u^2-5=3(3x+1)-5=9 x - 2\]\[=\dfrac{2}{135}(3x+1)\sqrt{3x+1}\,(9 x - 2)+C\]

（\((3x+1)\sqrt{3x+1}=(3x+1)^{\frac32}\)）

【答案】

\[\dfrac{2}{135}(3x+1)\sqrt{3x+1}\,(9 x - 2)+C\]
