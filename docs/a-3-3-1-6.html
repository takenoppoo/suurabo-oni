ホーム ＞ 数学III ＞ 不定積分・置換積分・部分積分

別冊練習問題 6 の解答　x√(ax+b) の置換積分

(1)　不定積分 \(\displaystyle\int x\sqrt{2x+1}\,dx\) を求めよ。

置換

\(u=\sqrt{2x+1}\) とおくと \(x=\dfrac{u^2-1}{2},\ dx=\dfrac{2u}{2}du\)。

\(u\) の積分

\[\int x\sqrt{2x+1}\,dx=\int\dfrac{u^2-1}{2}\cdot u\cdot\dfrac{2u}{2}du=\int(\dfrac{u^{4}}{2} - \dfrac{u^{2}}{2})\,du\]

積分して戻す

\[=\dfrac{u^{5}}{10} - \dfrac{u^{3}}{6}+C\]

\(u=\sqrt{2x+1}\) を戻して整理：

\[\dfrac{\sqrt{2 x + 1} \left(6 x^{2} + x - 1\right)}{15}+C\]

【答案】

\[\dfrac{\sqrt{2 x + 1} \left(6 x^{2} + x - 1\right)}{15}+C\]

答

(2)　不定積分 \(\displaystyle\int x\sqrt{1x+4}\,dx\) を求めよ。

置換

\(u=\sqrt{1x+4}\) とおくと \(x=\dfrac{u^2-4}{1},\ dx=\dfrac{2u}{1}du\)。

\(u\) の積分

\[\int x\sqrt{1x+4}\,dx=\int\dfrac{u^2-4}{1}\cdot u\cdot\dfrac{2u}{1}du=\int(2 u^{4} - 8 u^{2})\,du\]

積分して戻す

\[=\dfrac{2 u^{5}}{5} - \dfrac{8 u^{3}}{3}+C\]

\(u=\sqrt{1x+4}\) を戻して整理：

\[\dfrac{2 \sqrt{x + 4} \left(3 x^{2} + 4 x - 32\right)}{15}+C\]

【答案】

\[\dfrac{2 \sqrt{x + 4} \left(3 x^{2} + 4 x - 32\right)}{15}+C\]

答

(3)　不定積分 \(\displaystyle\int x\sqrt{3x+1}\,dx\) を求めよ。

置換

\(u=\sqrt{3x+1}\) とおくと \(x=\dfrac{u^2-1}{3},\ dx=\dfrac{2u}{3}du\)。

\(u\) の積分

\[\int x\sqrt{3x+1}\,dx=\int\dfrac{u^2-1}{3}\cdot u\cdot\dfrac{2u}{3}du=\int(\dfrac{2 u^{4}}{9} - \dfrac{2 u^{2}}{9})\,du\]

積分して戻す

\[=\dfrac{2 u^{5}}{45} - \dfrac{2 u^{3}}{27}+C\]

\(u=\sqrt{3x+1}\) を戻して整理：

\[\dfrac{2 \sqrt{3 x + 1} \left(27 x^{2} + 3 x - 2\right)}{135}+C\]

【答案】

\[\dfrac{2 \sqrt{3 x + 1} \left(27 x^{2} + 3 x - 2\right)}{135}+C\]
