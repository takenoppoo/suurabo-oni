1.　\(y=(x^{2} - 3 x + 2)e^{-2x}\) を微分せよ。

積の微分

\[\{f(x)g(x)\}'=f'(x)g(x)+f(x)g'(x)\]

各部分を微分

\(u=x^{2} - 3 x + 2\)、\(v=e^{-2x}\)。

\[u'=2 x - 3,\qquad v'=-2e^{-2x}\]

組み合わせる

\[y'=(2 x - 3)e^{-2x}+(x^{2} - 3 x + 2)\cdot -2e^{-2x}=\left(- 2 x^{2} + 8 x - 7\right)e^{-2x}\]

（例題1の型）

【答案】

\[y'=\left(- 2 x^{2} + 8 x - 7\right)e^{-2x}\]

答

2.　\(y=\dfrac{2 x + 5}{x^{2} + 1}\) を微分せよ。

商の微分

\[\left\{\dfrac{f}{g}\right\}'=\dfrac{f'g-fg'}{g^2}\]

代入

\[y'=\dfrac{2(x^{2} + 1)-(2 x + 5)\cdot 2x}{(x^{2} + 1)^2}\]

整理

\[y'=\dfrac{- 2 x^{2} - 10 x + 2}{(x^{2} + 1)^2}\]

（例題2の型）

【答案】

\[y'=\dfrac{- 2 x^{2} - 10 x + 2}{(x^{2} + 1)^2}\]

答

3.　\(y=\sin^{2}(3 x^{2} + 2 x)\) を微分せよ。

合成関数の微分

\[\{f(g(x))\}'=f'(g(x))\,g'(x)\]

外側から順に

外側 \((\ \ )^{2}\)、中 \(\sin(\ \ )\)、内側 \(3 x^{2} + 2 x\)。

\[y'=2\sin^{1}(3 x^{2} + 2 x)\cdot\cos(3 x^{2} + 2 x)\cdot(6 x + 2)\]

整理

\[y'=12 x + 4\sin^{1}(3 x^{2} + 2 x)\cos(3 x^{2} + 2 x)\]

（例題3の型）

【答案】

\[y'=12 x + 4\sin^{1}(3 x^{2} + 2 x)\cos(3 x^{2} + 2 x)\]

4.　\(y=\log(x^{2} + 5)+-2\log x\ (x>0)\) を微分せよ。

公式

\[(\log x)'=\dfrac1x,\qquad \{\log g(x)\}'=\dfrac{g'(x)}{g(x)}\]

各項を微分

\[\{\log(x^{2} + 5)\}'=\dfrac{2 x}{x^{2} + 5},\qquad (-2\log x)'=\dfrac{-2}{x}\]

たす

\[y'=\dfrac{2x}{x^{2} + 5}+\dfrac{-2}{x}\]

（例題4の型）

【答案】

\[y'=\dfrac{2x}{x^{2} + 5}+\dfrac{-2}{x}\]

答

5.　\(y=x^{3}e^{-2x}\ (x>0)\) を、対数微分法で微分せよ。

両辺の対数をとる（\(x>0\)）

\[\log y=3\log x+-2x\]

両辺を \(x\) で微分

\[\dfrac{y'}{y}=\dfrac{3}{x}+-2\]

\(y'\) を求める

\[y'=y\left(\dfrac{3}{x}+-2\right)=x^{3}e^{-2x}\left(\dfrac{3}{x}+-2\right)=(-2x+3)x^{2}e^{-2x}\]

（例題5の型）

【答案】

\[y'=(-2x+3)x^{2}e^{-2x}\]

答

6.　曲線 \(x=\log{\left(t \right)},\ y=t^{2}\) の \(t=1\) に対応する点における接線の傾きと接線の方程式を求めよ。

\(t\) で微分

\[\dfrac{dx}{dt}=\dfrac{1}{t},\qquad \dfrac{dy}{dt}=2 t\]

\(\dfrac{dy}{dx}\)

\[\dfrac{dy}{dx}=\dfrac{dy/dt}{dx/dt}=2 t^{2}\]

接線

\(t=1\) のとき 点 \((0,\ 1)\)、傾き \(2\)。

\[y-1=2(x-0)\]

（例題6の型）

【答案】

\[\text{傾き }2,\ \ y-1=2(x-0)\]

答

\[y=- 0.288675134594813 x + 3.46410161513775\]

（例題7の型）

8.　\(f(x)=\sin4x\) の第 \(n\) 次導関数を求めよ。

順に微分

\[f'=4\cos4x=4\sin\left(4x+\dfrac\pi2\right),\ \ f''=-16\sin4x=16\sin(4x+\pi)\]

規則

微分のたびに \(\times4\)、角が \(+\dfrac\pi2\)。

一般形

\[f^{(n)}(x)=4^n\sin\left(4x+\dfrac{n\pi}{2}\right)\]

（例題8の型）

【答案】

\[4^n\sin\left(4x+\dfrac{n\pi}{2}\right)\]

答

9.　\(f(x)=x e^{x}\) のとき、\(\displaystyle\lim_{h\to0}\dfrac{f(1+h)-f(1)}{h}\) を、微分係数の定義を用いて求めよ。

微分係数の定義

\[f'(a)=\lim_{h\to0}\dfrac{f(a+h)-f(a)}{h}\]

極限を導関数に

\(f(x)=x e^{x}\)。\(f'(x)=x e^{x} + e^{x}\)。

値

\[f'(1)=2 e\]

（例題9の型）

【答案】

\[2 e\]

10.　\(y=x^{5x}\ (x>0)\) を微分せよ。

両辺の対数

\[\log y=5x\log x\]

両辺を \(x\) で微分

\[\dfrac{y'}{y}=5\log x+5\]

答え

\[y'=x^{5 x}\,(\log x+1)\cdot5\]

（例題10の型）

【答案】

\[y'=5\,x^{5x}(\log x+1)\]
