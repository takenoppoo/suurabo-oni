別冊章末問題の解答

1.　\(y=(x^{2} - 3 x + 2)e^{-2x}\) を微分せよ。

積の微分の公式を書く

\[\{f(x)g(x)\}'=f'(x)g(x)+f(x)g'(x)\]

\(f,\ g\) を決める

\(f=x^{2} - 3 x + 2\)、\(g=e^{-2x}\) とする。

\(f'\) を求める

\[f'=2 x - 3\]

\(g'\) を求める

\((e^{u})'=e^{u}\cdot u'\) を使う。\(u=-2x\) の導関数は \(-2\)。

\[g'=-2\cdot e^{-2x}=-2e^{-2x}\]

公式に代入する

\[y'=(2 x - 3)e^{-2x}+(x^{2} - 3 x + 2)\cdot -2e^{-2x}\]

\(e^{-2x}\) でくくる

共通因数 \(e^{-2x}\) でくくる。

\[y'=\left\{(2 x - 3)-2(x^{2} - 3 x + 2)\right\}e^{-2x}\]

かっこをはずして整理する。

\[=\left\{2 x - 3- 2 x^{2} + 6 x - 4\right\}e^{-2x}=\left(- 2 x^{2} + 8 x - 7\right)e^{-2x}\]

（例題1の型）

【答案】

\[y'=\left(- 2 x^{2} + 8 x - 7\right)e^{-2x}\]

答

2.　\(y=\dfrac{2 x + 5}{x^{2} + 1}\) を微分せよ。

商の微分の公式を書く

\[\left\{\dfrac{f}{g}\right\}'=\dfrac{f'g-fg'}{g^2}\]

\(f,\ g\) とその導関数

\(f=2 x + 5,\ \ g=x^{2} + 1\)。

\[f'=2,\qquad g'=2x\]

公式に代入する

\[y'=\dfrac{2\cdot(x^{2} + 1)-(2 x + 5)\cdot2x}{(x^{2} + 1)^2}\]

分子を展開する

\[2(x^{2} + 1)=2 x^{2} + 2,\qquad (2 x + 5)\cdot2x=4 x^{2} + 10 x\]

引き算に注意して、かっこをはずす。

\[(2 x^{2} + 2)-(4 x^{2} + 10 x)=- 2 x^{2} - 10 x + 2\]

答え

\[y'=\dfrac{- 2 x^{2} - 10 x + 2}{(x^{2} + 1)^2}\]

（例題2の型）

【答案】

\[y'=\dfrac{- 2 x^{2} - 10 x + 2}{(x^{2} + 1)^2}\]

答

3.　\(y=\sin^{2}(3 x^{2} + 2 x)\) を微分せよ。

合成関数の微分の公式を書く

\[\{f(g(x))\}'=f'(g(x))\,g'(x)\]

層に分ける

\(u=3 x^{2} + 2 x\)、\(v=\sin u\)、\(y=v^{2}\) とおく。

各層を微分する

\[\dfrac{dy}{dv}=2v=2\sinu,\qquad \dfrac{dv}{du}=\cos u,\qquad \dfrac{du}{dx}=6 x + 2\]

かけ合わせる

\[y'=\dfrac{dy}{dv}\cdot\dfrac{dv}{du}\cdot\dfrac{du}{dx}=2\sin(3 x^{2} + 2 x)\cdot\cos(3 x^{2} + 2 x)\cdot(6 x + 2)\]

係数をまとめる

\[y'=12 x + 4\sin(3 x^{2} + 2 x)\cos(3 x^{2} + 2 x)\]

（例題3の型）

【答案】

\[y'=12 x + 4\sin(3 x^{2} + 2 x)\cos(3 x^{2} + 2 x)\]

答

4.　\(y=\log(x^{2} + 5)-2\log x\ (x>0)\) を微分せよ。

公式を確認する

\[(\log x)'=\dfrac1x,\qquad \{\log g(x)\}'=\dfrac{g'(x)}{g(x)}\]

第1項を微分する

\(g=x^{2} + 5\) とおくと \(g'=2x\)。

\[\{\log(x^{2} + 5)\}'=\dfrac{g'}{g}=\dfrac{2x}{x^{2} + 5}\]

第2項を微分する

定数 \(-2\) はそのまま外に出す。

\[(-2\log x)'=-2\cdot\dfrac1x=\dfrac{-2}{x}\]

たす

\[y'=\dfrac{2x}{x^{2} + 5}+\dfrac{-2}{x}\]

（例題4の型）

【答案】

\[y'=\dfrac{2x}{x^{2} + 5}+\dfrac{-2}{x}\]

答

5.　\(y=x^{3}e^{-2x}\ (x>0)\) を、対数微分法で微分せよ。

両辺の対数をとる（\(x>0\)）

\(y=x^{3}e^{-2x}\) の両辺の対数をとり、積を和に直す。

\[\log y=\log x^{3}+\log e^{-2x}=3\log x-2x\]

両辺を \(x\) で微分する

左辺は \(y\) が \(x\) の関数なので、合成関数の微分で \(\dfrac{y'}{y}\)。

\[\dfrac{y'}{y}=\dfrac{3}{x}-2\]

\(y'\) について解く

両辺に \(y\) をかけ、\(y=x^{3}e^{-2x}\) を代入する。

\[y'=y\left(\dfrac{3}{x}-2\right)=x^{3}e^{-2x}\left(\dfrac{3}{x}-2\right)\]

かっこをはずして整理

\[x^{3}\cdot\dfrac{3}{x}=3x^{2},\qquad x^{3}\cdot-2=-2x^{3}\]

\(x^{3}=x\cdot x^{2}\) として \(x^{2}\) でくくる。

\[y'=\left(3-2x\right)x^{2}e^{-2x}\]

（例題5の型）

【答案】

\[y'=(-2x+3)x^{2}e^{-2x}\]

答

6.　曲線 \(x=\log{\left(t \right)},\ y=t^{2}\) の \(t=1\) に対応する点における接線の傾きと接線の方程式を求めよ。

\(t\) で微分する

\[\dfrac{dx}{dt}=\dfrac{1}{t},\qquad \dfrac{dy}{dt}=2 t\]

\(\dfrac{dy}{dx}\) を求める

\(\dfrac{dy}{dx}=\dfrac{dy/dt}{dx/dt}\) を使う。

\[\dfrac{dy}{dx}=\dfrac{2 t}{\dfrac{1}{t}}=2 t^{2}\]

接点の座標を求める

\(t=1\) を \(x,\ y\) に代入する。

\[x=0,\qquad y=1\]

接線の傾きを求める

\(t=1\) を \(\dfrac{dy}{dx}\) に代入する。

\[\dfrac{dy}{dx}=2\]

接線の方程式

点 \((0,\ 1)\)、傾き \(2\) の直線。

\[y-1=2x\]

（例題6の型）

【答案】

\[\text{傾き }2,\ \ y-1=2x\]

答

7.　楕円 \(\dfrac{x^2}{36}+\dfrac{y^2}{9}=1\) 上の点 \(\left(3,\ \dfrac{3 \sqrt{3}}{2}\right)\) における接線の方程式を、陰関数の微分で求めよ。

両辺を \(x\) で微分する

\(\dfrac{d}{dx}\dfrac{x^2}{36}=\dfrac{2x}{36}\)。

\(y\) は \(x\) の関数なので、合成関数の微分で \(\dfrac{d}{dx}\dfrac{y^2}{9}=\dfrac{2y}{9}\cdot\dfrac{dy}{dx}\)。

\[\dfrac{2x}{36}+\dfrac{2y}{9}\cdot\dfrac{dy}{dx}=0\]

\(\dfrac{dy}{dx}\) について解く

第1項を移項する。

\[\dfrac{2y}{9}\cdot\dfrac{dy}{dx}=-\dfrac{2x}{36}\]

両辺に \(\dfrac{9}{2y}\) をかける。

\[\dfrac{dy}{dx}=-\dfrac{2x}{36}\cdot\dfrac{9}{2y}=-\dfrac{9x}{36y}\]

点が楕円上にあることを確かめる

\[\dfrac{3^2}{36}+\dfrac{\left(\dfrac{3 \sqrt{3}}{2}\right)^2}{9}=\dfrac{9}{36}+\dfrac{\dfrac{27}{4}}{9}=1\]

接線の傾きを求める

\(x=3,\ y=\dfrac{3 \sqrt{3}}{2}\) を代入する。

\[\dfrac{dy}{dx}=-\dfrac{9\cdot3}{36\cdot\dfrac{3 \sqrt{3}}{2}}=- \dfrac{\sqrt{3}}{6}\]

接線の方程式

\((3,\ \dfrac{3 \sqrt{3}}{2})\) を通り傾き \(- \dfrac{\sqrt{3}}{6}\) の直線。

\[y-\dfrac{3 \sqrt{3}}{2}=- \dfrac{\sqrt{3}}{6}(x-3)\]

\(y\) について整理する。

\[y=- \dfrac{\sqrt{3} x}{6} + 2 \sqrt{3}\]

（例題7の型）

【答案】

\[y=- \dfrac{\sqrt{3} x}{6} + 2 \sqrt{3}\]

答

8.　\(f(x)=\sin4x\) の第 \(n\) 次導関数を求めよ。

1回微分する

\((\sin ax)'=a\cos ax\) を使う。

\[f'=4\cos4x=4\sin\left(4x+\dfrac\pi2\right)\]

\(\cos\theta=\sin\left(\theta+\dfrac\pi2\right)\) で \(\sin\) にそろえる。

2回微分する

\[f''=4\cdot4\left(-\sin4x\right)=-16\sin4x=16\sin(4x+\pi)\]

3回微分する

\[f'''=-16\cdot4\cos4x=-64\cos4x=64\sin\left(4x+\dfrac{3\pi}{2}\right)\]

規則を見つける

微分のたびに \(\times4\)、角が \(+\dfrac\pi2\) ずつ増える。

\(n\)\(f^{(n)}(x)\)
1\(4\sin\left(4x+\dfrac\pi2\right)\)
2\(16\sin(4x+\pi)\)
3\(64\sin\left(4x+\dfrac{3\pi}{2}\right)\)
\(n\)\(4^n\sin\left(4x+\dfrac{n\pi}{2}\right)\)

一般形

\[f^{(n)}(x)=4^n\sin\left(4x+\dfrac{n\pi}{2}\right)\]

（例題8の型）

【答案】

\[4^n\sin\left(4x+\dfrac{n\pi}{2}\right)\]

答

9.　\(f(x)=x e^{x}\) のとき、\(\displaystyle\lim_{h\to0}\dfrac{f(1+h)-f(1)}{h}\) を、微分係数の定義を用いて求めよ。

微分係数の定義を確認する

\[f'(a)=\lim_{h\to0}\dfrac{f(a+h)-f(a)}{h}\]

求める極限は \(a=1\) の場合そのものである。

\(f'(x)\) を求める

\(f(x)=x e^{x}\) を微分する。

\[f'(x)=x e^{x} + e^{x}\]

\(x=1\) を代入する

\[f'(1)=2 e\]

（例題9の型）

【答案】

\[2 e\]

答

10.　\(y=x^{5x}\ (x>0)\) を微分せよ。

両辺の対数をとる

\(y=x^{5x}\) の両辺の対数をとる。\(\log x^{p}=p\log x\) を使う。

\[\log y=5x\log x\]

右辺を積の微分で微分する

\((x\log x)'=\log x+x\cdot\dfrac1x=\log x+1\)。

\[\dfrac{y'}{y}=5\left(\log x+1\right)\]

\(y'\) について解く

両辺に \(y\) をかける。

\[y'=5y\left(\log x+1\right)=5x^{5x}(\log x+1)\]

（例題10の型）

【答案】

\[y'=5x^{5x}(\log x+1)\]
