別冊練習問題 1 の解答　条件つきで整数をつくる個数

(1)　0, 1, 2, 3, 4, 5 の6個の数字から異なる3個を選んでできる3桁の奇数の個数

一の位は 1, 3, 5 の3通り。百の位は 0 と一の位の数字を除く \(4\) 通り、十の位は残り4個から \(4\) 通り。 \[3\times4\times4=48\]

【答案】

\[48\ \text{個}\]

答

(2)　0, 1, 2, 3, 4 の5個の数字から異なる4個を選んでできる4桁の偶数の個数

一の位が 0：\(4\times3\times2=24\)。一の位が 2 か 4（2通り）：千の位 \(3\) 通り、百の位 \(3\) 通り、十の位 \(2\) 通り → \(2\times3\times3\times2=36\)。 \[24+36=60\]

【答案】

\[60\ \text{個}\]

答

(3)　0, 1, 2, 3, 4, 5 の6個の数字から異なる3個を選んでできる3桁の5の倍数の個数

一の位が 0：\(5\times4=20\)。一の位が 5：百の位 \(4\) 通り（0 と 5 以外）、十の位 \(4\) 通り → \(16\)。 \[20+16=36\]

【答案】

\[36\ \text{個}\]
