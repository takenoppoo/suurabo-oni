章末問題数学的帰納法

例題1〜5で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. 次の等式が、すべての自然数 \(n\) で成り立つことを数学的帰納法で証明せよ。 \[\sum_{k=1}^{n}k^{3}=\dfrac{n^{2} \left(n + 1\right)^{2}}{4}\]
  2. すべての自然数 \(n\) について、\(11^n-1\) が \(10\) の倍数であることを数学的帰納法で証明せよ。
  3. すべての自然数 \(n\) について、不等式 \(6^n\geqq1+5n\) が成り立つことを数学的帰納法で証明せよ。
  4. \(a_1=5,\ \ a_{n+1}=6 a_n+5\) で定められる数列について、一般項を推定し、それを数学的帰納法で証明せよ。
  5. 次の等式が、すべての自然数 \(n\) で成り立つことを数学的帰納法で証明せよ。 \[\sum_{k=1}^{n}k\cdot6^{k-1}=\dfrac{6^{n} n}{5} - \dfrac{6^{n}}{25} + \dfrac{1}{25}\]
