章末問題和の記号Σ

例題1〜10で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. 次の和を \(n\) の式で表せ（因数分解した形で答えよ）。 \[\sum_{k=1}^{n}\left(4 k^{2} + 2 k + 3\right)\]
  2. 数列 \(1,\ 7,\ 19,\ 37,\ 61,\ \cdots\) の一般項 \(a_n\) を求めよ。
  3. 次の和を \(n\) の式で表せ。 \[\sum_{k=1}^{n}\dfrac{1}{k(k+3)}\]
  4. 次の和 \(S_n\) を求めよ。 \[S_n=\sum_{k=1}^{n}k\cdot4^{k}\]
  5. 数列 \(\{a_n\}\) の初項から第 \(n\) 項までの和 \(S_n\) が \(S_n=2 n^{2} - 3 n + 2\) で表されるとき、一般項 \(a_n\) を求めよ。
  6. \(\displaystyle\sum_{k=1}^{n}k(k+5)\) を \(n\) の式で表せ。
  7. 数列 \(4,\ 7,\ 11,\ 16,\ 22,\ 29,\ \cdots\) の階差数列が等差数列であるとき、一般項 \(a_n\) を求めよ。
  8. \(\displaystyle\sum_{k=1}^{9}\dfrac{1}{(2k+1)(2k+1+2)(2k+1+4)}\) を計算せよ。
  9. \(\displaystyle\sum_{k=1}^{5}k\cdot4^{k-1}\) を求めよ。
  10. 数列 \(\{a_n\}\) の初項から第 \(n\) 項までの和が \(S_n=2 n^{2} + 3 n\) であるとき、一般項 \(a_n\) を求めよ。
