ホーム ＞ 数学III ＞ 数列の極限

別冊練習問題 1 の解答　分数式の極限（最高次でわる）

(1)　次の極限値を求めよ。 \[\lim_{n\to\infty}\dfrac{5 n^{2} - 3 n + 2}{4 n^{2} + n + 1}\]

最高次の項でわる

分母の最高次は \(n^2\)。分母・分子を \(n^2\) でわる。

\[\dfrac{5 n^{2} - 3 n + 2}{4 n^{2} + n + 1}=\dfrac{5 - \dfrac{3}{n} + \dfrac{2}{n^{2}}}{4 + \dfrac{1}{n} + \dfrac{1}{n^{2}}}\]

\(\dfrac1n,\ \dfrac1{n^2}\to0\) を使う

\(\lim_{n\to\infty}\dfrac1n=0,\ \ \lim_{n\to\infty}\dfrac1{n^2}=0\)。

\[\lim_{n\to\infty}\dfrac{5 - \dfrac{3}{n} + \dfrac{2}{n^{2}}}{4 + \dfrac{1}{n} + \dfrac{1}{n^{2}}}=\dfrac{5+0+0}{4+0+0}=\dfrac{5}{4}\]

【答案】

\[\dfrac{5}{4}\]

答

(2)　次の極限値を求めよ。 \[\lim_{n\to\infty}\dfrac{2 n^{2} + 7 n - 1}{6 n^{2} + 3 n + 2}\]

最高次の項でわる

分母の最高次は \(n^2\)。分母・分子を \(n^2\) でわる。

\[\dfrac{2 n^{2} + 7 n - 1}{6 n^{2} + 3 n + 2}=\dfrac{2 + \dfrac{7}{n} - \dfrac{1}{n^{2}}}{6 + \dfrac{3}{n} + \dfrac{2}{n^{2}}}\]

\(\dfrac1n,\ \dfrac1{n^2}\to0\) を使う

\(\lim_{n\to\infty}\dfrac1n=0,\ \ \lim_{n\to\infty}\dfrac1{n^2}=0\)。

\[\lim_{n\to\infty}\dfrac{2 + \dfrac{7}{n} - \dfrac{1}{n^{2}}}{6 + \dfrac{3}{n} + \dfrac{2}{n^{2}}}=\dfrac{2+0+0}{6+0+0}=\dfrac{1}{3}\]

【答案】

\[\dfrac{1}{3}\]

答

(3)　次の極限値を求めよ。 \[\lim_{n\to\infty}\dfrac{7 n^{2} + n}{3 n^{2} - 2 n + 4}\]

最高次の項でわる

分母の最高次は \(n^2\)。分母・分子を \(n^2\) でわる。

\[\dfrac{7 n^{2} + n}{3 n^{2} - 2 n + 4}=\dfrac{7 + \dfrac{1}{n}}{3 - \dfrac{2}{n} + \dfrac{4}{n^{2}}}\]

\(\dfrac1n,\ \dfrac1{n^2}\to0\) を使う

\(\lim_{n\to\infty}\dfrac1n=0,\ \ \lim_{n\to\infty}\dfrac1{n^2}=0\)。

\[\lim_{n\to\infty}\dfrac{7 + \dfrac{1}{n}}{3 - \dfrac{2}{n} + \dfrac{4}{n^{2}}}=\dfrac{7+0+0}{3+0+0}=\dfrac{7}{3}\]

【答案】

\[\dfrac{7}{3}\]
