別冊練習問題 1 の解答　不定積分と定積分の計算

(1)　(1) 不定積分 \(\displaystyle\int\left(6 x^{2} - 4 x + 1\right)dx\) を求めよ。(2) 定積分 \(\displaystyle\int_{1}^{3}\left(6 x^{2} - 4 x + 1\right)dx\) の値を求めよ。

各項を積分する

\(\int x^n\,dx=\dfrac{x^{n+1}}{n+1}+C\)。

\[\int\left(6 x^{2} - 4 x + 1\right)dx=x- 2 x^{2}+2 x^{3}+C\]

不定積分

積分定数を \(C\) として

\[\int\left(6 x^{2} - 4 x + 1\right)dx=2 x^{3} - 2 x^{2} + x+C\]

定積分：両端の値を代入

定積分では \(C\) は不要。

\[\int_{1}^{3}\left(6 x^{2} - 4 x + 1\right)dx=\Big[2 x^{3} - 2 x^{2} + x\Big]_{1}^{3}\]\[F(3)=39,\quad F(1)=1\]

値を求める

\[F(3)-F(1)=39-\left(1\right)=38\]

【答案】

\[\text{(1) }2 x^{3} - 2 x^{2} + x+C\quad\text{(2) }38\]

答

(2)　(1) 不定積分 \(\displaystyle\int\left(4 x^{2} + 3 x - 2\right)dx\) を求めよ。(2) 定積分 \(\displaystyle\int_{0}^{2}\left(4 x^{2} + 3 x - 2\right)dx\) の値を求めよ。

各項を積分する

\(\int x^n\,dx=\dfrac{x^{n+1}}{n+1}+C\)。

\[\int\left(4 x^{2} + 3 x - 2\right)dx=- 2 x+\dfrac{3 x^{2}}{2}+\dfrac{4 x^{3}}{3}+C\]

不定積分

積分定数を \(C\) として

\[\int\left(4 x^{2} + 3 x - 2\right)dx=\dfrac{4 x^{3}}{3} + \dfrac{3 x^{2}}{2} - 2 x+C\]

定積分：両端の値を代入

定積分では \(C\) は不要。

\[\int_{0}^{2}\left(4 x^{2} + 3 x - 2\right)dx=\Big[\dfrac{4 x^{3}}{3} + \dfrac{3 x^{2}}{2} - 2 x\Big]_{0}^{2}\]\[F(2)=\dfrac{38}{3},\quad F(0)=0\]

値を求める

\[F(2)-F(0)=\dfrac{38}{3}-\left(0\right)=\dfrac{38}{3}\]

【答案】

\[\text{(1) }\dfrac{4 x^{3}}{3} + \dfrac{3 x^{2}}{2} - 2 x+C\quad\text{(2) }\dfrac{38}{3}\]

答

(3)　(1) 不定積分 \(\displaystyle\int\left(4 x^{3} - 3 x^{2} + 2 x + 1\right)dx\) を求めよ。(2) 定積分 \(\displaystyle\int_{-1}^{2}\left(4 x^{3} - 3 x^{2} + 2 x + 1\right)dx\) の値を求めよ。

各項を積分する

\(\int x^n\,dx=\dfrac{x^{n+1}}{n+1}+C\)。

\[\int\left(4 x^{3} - 3 x^{2} + 2 x + 1\right)dx=x- x^{3}+x^{2}+x^{4}+C\]

不定積分

積分定数を \(C\) として

\[\int\left(4 x^{3} - 3 x^{2} + 2 x + 1\right)dx=x^{4} - x^{3} + x^{2} + x+C\]

定積分：両端の値を代入

定積分では \(C\) は不要。

\[\int_{-1}^{2}\left(4 x^{3} - 3 x^{2} + 2 x + 1\right)dx=\Big[x^{4} - x^{3} + x^{2} + x\Big]_{-1}^{2}\]\[F(2)=14,\quad F(-1)=2\]

値を求める

\[F(2)-F(-1)=14-\left(2\right)=12\]

【答案】

\[\text{(1) }x^{4} - x^{3} + x^{2} + x+C\quad\text{(2) }12\]
