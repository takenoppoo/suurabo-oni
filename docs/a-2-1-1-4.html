別冊練習問題 4 の解答　分数式の乗除（因数分解して約分）

(1)　次の計算をせよ。 \[\dfrac{x^{2} - 5 x + 4}{x^{2} + 2 x - 3}\div\dfrac{x^{2} - 2 x - 8}{x^{2} + 6 x + 9}\]

各式を因数分解する

\[\dfrac{x^{2} - 5 x + 4}{x^{2} + 2 x - 3}=\dfrac{(x - 4)(x - 1)}{(x - 1)(x + 3)}\qquad \dfrac{x^{2} - 2 x - 8}{x^{2} + 6 x + 9}=\dfrac{(x - 4)(x + 2)}{(x + 3)(x + 3)}\]

割り算を、逆数の掛け算に直す

\[\dfrac{(x - 4)(x - 1)}{(x - 1)(x + 3)}\times\dfrac{(x + 3)(x + 3)}{(x - 4)(x + 2)}\]

約分する

分子と分母に共通な因数を消す。

\[\dfrac{x + 3}{x + 2}=\dfrac{x + 3}{x + 2}\]

【答案】

\[\dfrac{x + 3}{x + 2}\]

答

(2)　次の計算をせよ。 \[\dfrac{x^{2} + 3 x - 10}{x^{2} - 4 x - 5}\div\dfrac{x^{2} - 5 x + 6}{x^{2} - 10 x + 25}\]

各式を因数分解する

\[\dfrac{x^{2} + 3 x - 10}{x^{2} - 4 x - 5}=\dfrac{(x - 2)(x + 5)}{(x + 1)(x - 5)}\qquad \dfrac{x^{2} - 5 x + 6}{x^{2} - 10 x + 25}=\dfrac{(x - 2)(x - 3)}{(x - 5)(x - 5)}\]

割り算を、逆数の掛け算に直す

\[\dfrac{(x - 2)(x + 5)}{(x + 1)(x - 5)}\times\dfrac{(x - 5)(x - 5)}{(x - 2)(x - 3)}\]

約分する

分子と分母に共通な因数を消す。

\[\dfrac{\left(x - 5\right) \left(x + 5\right)}{\left(x - 3\right) \left(x + 1\right)}=\dfrac{x^{2} - 25}{x^{2} - 2 x - 3}\]

【答案】

\[\dfrac{\left(x - 5\right) \left(x + 5\right)}{\left(x - 3\right) \left(x + 1\right)}\]

答

(3)　次の計算をせよ。 \[\dfrac{x^{2} + x - 12}{x^{2} - 2 x - 3}\div\dfrac{x^{2} + 3 x - 4}{x^{2} + 2 x + 1}\]

各式を因数分解する

\[\dfrac{x^{2} + x - 12}{x^{2} - 2 x - 3}=\dfrac{(x + 4)(x - 3)}{(x - 3)(x + 1)}\qquad \dfrac{x^{2} + 3 x - 4}{x^{2} + 2 x + 1}=\dfrac{(x + 4)(x - 1)}{(x + 1)(x + 1)}\]

割り算を、逆数の掛け算に直す

\[\dfrac{(x + 4)(x - 3)}{(x - 3)(x + 1)}\times\dfrac{(x + 1)(x + 1)}{(x + 4)(x - 1)}\]

約分する

分子と分母に共通な因数を消す。

\[\dfrac{x + 1}{x - 1}=\dfrac{x + 1}{x - 1}\]

【答案】

\[\dfrac{x + 1}{x - 1}\]
