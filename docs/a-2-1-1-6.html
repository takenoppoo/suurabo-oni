別冊練習問題 6 の解答　4次式を2次式で割る筆算

(1)　\(x^{4} + 2 x^{2} - 3\) を \(x^{2} + x - 1\) で割ったときの商と余りを求めよ。

筆算の要領で割る

最高次の項どうしを割って商を立て、引く操作をくり返す（次数が \(Q\) より下がるまで）。

商と余り

\[\text{商 }x^{2} - x + 4,\qquad \text{余り }- 5 x + 1\]

検算

\[(x^{2} + x - 1)(x^{2} - x + 4)+(- 5 x + 1)=x^{4} + 2 x^{2} - 3\]

【答案】

\[\text{商 }x^{2} - x + 4,\ \text{余り }- 5 x + 1\]

答

(2)　\(3 x^{4} - x^{3} + 2 x^{2} + 4\) を \(x^{2} + 2\) で割ったときの商と余りを求めよ。

筆算の要領で割る

最高次の項どうしを割って商を立て、引く操作をくり返す（次数が \(Q\) より下がるまで）。

商と余り

\[\text{商 }3 x^{2} - x - 4,\qquad \text{余り }2 x + 12\]

検算

\[(x^{2} + 2)(3 x^{2} - x - 4)+(2 x + 12)=3 x^{4} - x^{3} + 2 x^{2} + 4\]

【答案】

\[\text{商 }3 x^{2} - x - 4,\ \text{余り }2 x + 12\]

答

(3)　\(x^{5} - x^{3} + 2 x - 1\) を \(x^{2} - 2 x + 3\) で割ったときの商と余りを求めよ。

筆算の要領で割る

最高次の項どうしを割って商を立て、引く操作をくり返す（次数が \(Q\) より下がるまで）。

商と余り

\[\text{商 }x^{3} + 2 x^{2} - 6,\qquad \text{余り }- 10 x + 17\]

検算

\[(x^{2} - 2 x + 3)(x^{3} + 2 x^{2} - 6)+(- 10 x + 17)=x^{5} - x^{3} + 2 x - 1\]

【答案】

\[\text{商 }x^{3} + 2 x^{2} - 6,\ \text{余り }- 10 x + 17\]
