別冊練習問題 5 の解答　2つの円の共通弦

(1)　2つの円 \(C_1:\ x^2+y^2=25\)、\(C_2:\ (x-3)^2+(y-4)^2=25\) は2点で交わる。(1) 2つの交点を通る直線の方程式 (2) 2つの交点を結ぶ線分（共通弦）の長さ を求めよ。

2つの円の方程式を展開する

\[C_1:\ x^{2} + y^{2} - 25=0,\qquad C_2:\ x^{2} - 6 x + y^{2} - 8 y=0\]

共通弦の方程式（2式の差）

2つの円の交点は両方の式を満たすので、2式の差も満たす。2次の項が消えて直線になる。

\[(x^{2} + y^{2} - 25)-(x^{2} - 6 x + y^{2} - 8 y)=0\ \Rightarrow\ 6 x + 8 y - 25=0\]

整理して

\[6x+8y-25=0\]

共通弦の長さ

円 \(C_1\)（中心 \(O\)、半径 \(\sqrt{25}\)）と共通弦の距離：

\[d=\dfrac{|-25|}{\sqrt{6^2+8^2}}=\dfrac{5}{2}\]\[l=2\sqrt{r^2-d^2}=2\sqrt{25-\dfrac{25}{4}}=5 \sqrt{3}\]

【答案】

\[\text{(1) }6x+8y-25=0\qquad \text{(2) }5 \sqrt{3}\]

答

(2)　2つの円 \(C_1:\ x^2+y^2=13\)、\(C_2:\ (x-2)^2+(y+1)^2=10\) は2点で交わる。(1) 2つの交点を通る直線の方程式 (2) 2つの交点を結ぶ線分（共通弦）の長さ を求めよ。

2つの円の方程式を展開する

\[C_1:\ x^{2} + y^{2} - 13=0,\qquad C_2:\ x^{2} - 4 x + y^{2} + 2 y - 5=0\]

共通弦の方程式（2式の差）

2つの円の交点は両方の式を満たすので、2式の差も満たす。2次の項が消えて直線になる。

\[(x^{2} + y^{2} - 13)-(x^{2} - 4 x + y^{2} + 2 y - 5)=0\ \Rightarrow\ 4 x - 2 y - 8=0\]

整理して

\[2x-y-4=0\]

共通弦の長さ

円 \(C_1\)（中心 \(O\)、半径 \(\sqrt{13}\)）と共通弦の距離：

\[d=\dfrac{|-4|}{\sqrt{2^2+-1^2}}=\dfrac{4 \sqrt{5}}{5}\]\[l=2\sqrt{r^2-d^2}=2\sqrt{13-\dfrac{16}{5}}=\dfrac{14 \sqrt{5}}{5}\]

【答案】

\[\text{(1) }2x-y-4=0\qquad \text{(2) }\dfrac{14 \sqrt{5}}{5}\]

答

(3)　2つの円 \(C_1:\ x^2+y^2=20\)、\(C_2:\ (x-4)^2+(y-2)^2=10\) は2点で交わる。(1) 2つの交点を通る直線の方程式 (2) 2つの交点を結ぶ線分（共通弦）の長さ を求めよ。

2つの円の方程式を展開する

\[C_1:\ x^{2} + y^{2} - 20=0,\qquad C_2:\ x^{2} - 8 x + y^{2} - 4 y + 10=0\]

共通弦の方程式（2式の差）

2つの円の交点は両方の式を満たすので、2式の差も満たす。2次の項が消えて直線になる。

\[(x^{2} + y^{2} - 20)-(x^{2} - 8 x + y^{2} - 4 y + 10)=0\ \Rightarrow\ 8 x + 4 y - 30=0\]

整理して

\[4x+2y-15=0\]

共通弦の長さ

円 \(C_1\)（中心 \(O\)、半径 \(\sqrt{20}\)）と共通弦の距離：

\[d=\dfrac{|-15|}{\sqrt{4^2+2^2}}=\dfrac{3 \sqrt{5}}{2}\]\[l=2\sqrt{r^2-d^2}=2\sqrt{20-\dfrac{45}{4}}=\sqrt{35}\]

【答案】

\[\text{(1) }4x+2y-15=0\qquad \text{(2) }\sqrt{35}\]
