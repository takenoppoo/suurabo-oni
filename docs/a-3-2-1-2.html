別冊練習問題 2 の解答　商の微分

(1)　\(y=\dfrac{2 x - 1}{x^{2} + 3}\) を微分せよ。

商の微分

\[\left\{\dfrac{f}{g}\right\}'=\dfrac{f'g-fg'}{g^2}\]

代入

\[y'=\dfrac{2(x^{2} + 3)-(2 x - 1)\cdot 2x}{(x^{2} + 3)^2}\]

整理

\[y'=\dfrac{- 2 x^{2} + 2 x + 6}{(x^{2} + 3)^2}\]

【答案】

\[y'=\dfrac{- 2 x^{2} + 2 x + 6}{(x^{2} + 3)^2}\]

答
