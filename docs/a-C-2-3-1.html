別冊練習問題 1 の解答　極形式での積と商

(1)　\(z_1=\sqrt{3} + i,\ z_2=1 + \sqrt{3} i\) のとき、\(z_1z_2\) と \(\dfrac{z_1}{z_2}\) を、極形式を用いて計算せよ。

極形式にする

\(z=r(\cos\theta+i\sin\theta)\)。

\[z_1=2\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right),\qquad z_2=2\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right)\]

積

\(z_1z_2=r_1r_2\{\cos(\theta_1+\theta_2)+i\sin(\theta_1+\theta_2)\}\)。

\[z_1z_2=4\left(\cos\dfrac{\pi}{2}+i\sin\dfrac{\pi}{2}\right)=4 i\]

商

\(\dfrac{z_1}{z_2}=\dfrac{r_1}{r_2}\{\cos(\theta_1-\theta_2)+i\sin(\theta_1-\theta_2)\}\)。

\[\dfrac{z_1}{z_2}=1.0\left(\cos- \dfrac{\pi}{6}+i\sin- \dfrac{\pi}{6}\right)=\dfrac{\sqrt{3}}{2} - \dfrac{i}{2}\]

【答案】

\[z_1z_2=4 i,\ \dfrac{z_1}{z_2}=\dfrac{\sqrt{3}}{2} - \dfrac{i}{2}\]

答

(2)　\(z_1=\dfrac{3}{2} + \dfrac{3 \sqrt{3} i}{2},\ z_2=\sqrt{3} + i\) のとき、\(z_1z_2\) と \(\dfrac{z_1}{z_2}\) を、極形式を用いて計算せよ。

極形式にする

\(z=r(\cos\theta+i\sin\theta)\)。

\[z_1=3\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right),\qquad z_2=2\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right)\]

積

\(z_1z_2=r_1r_2\{\cos(\theta_1+\theta_2)+i\sin(\theta_1+\theta_2)\}\)。

\[z_1z_2=6\left(\cos\dfrac{\pi}{2}+i\sin\dfrac{\pi}{2}\right)=6 i\]

商

\(\dfrac{z_1}{z_2}=\dfrac{r_1}{r_2}\{\cos(\theta_1-\theta_2)+i\sin(\theta_1-\theta_2)\}\)。

\[\dfrac{z_1}{z_2}=1.5\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right)=\dfrac{3 \sqrt{3}}{4} + \dfrac{3 i}{4}\]

【答案】

\[z_1z_2=6 i,\ \dfrac{z_1}{z_2}=\dfrac{3 \sqrt{3}}{4} + \dfrac{3 i}{4}\]

答

(3)　\(z_1=-1 + \sqrt{3} i,\ z_2=\dfrac{1}{2} + \dfrac{\sqrt{3} i}{2}\) のとき、\(z_1z_2\) と \(\dfrac{z_1}{z_2}\) を、極形式を用いて計算せよ。

極形式にする

\(z=r(\cos\theta+i\sin\theta)\)。

\[z_1=2\left(\cos\dfrac{2 \pi}{3}+i\sin\dfrac{2 \pi}{3}\right),\qquad z_2=1\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right)\]

積

\(z_1z_2=r_1r_2\{\cos(\theta_1+\theta_2)+i\sin(\theta_1+\theta_2)\}\)。

\[z_1z_2=2\left(\cos\pi+i\sin\pi\right)=-2\]

商

\(\dfrac{z_1}{z_2}=\dfrac{r_1}{r_2}\{\cos(\theta_1-\theta_2)+i\sin(\theta_1-\theta_2)\}\)。

\[\dfrac{z_1}{z_2}=2.0\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right)=1 + \sqrt{3} i\]

【答案】

\[z_1z_2=-2,\ \dfrac{z_1}{z_2}=1 + \sqrt{3} i\]
