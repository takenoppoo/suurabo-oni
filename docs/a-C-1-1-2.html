別冊練習問題 2 の解答　ベクトルの大きさと垂直条件

(1)　\(|\vec a|=3,\ |\vec b|=2,\ \vec a\cdot\vec b=2\) のとき、(1) \(|\vec a+2\vec b|\) (2) \(\vec a+t\vec b\) と \(\vec a-\vec b\) が垂直になる \(t\) の値を求めよ。

\(|k\vec a+l\vec b|^2\) を展開

\(|k\vec a+l\vec b|^2=k^2|\vec a|^2+2kl\,\vec a\cdot\vec b+l^2|\vec b|^2\)。

\[|\vec a+2\vec b|^2=1\cdot9+4\cdot2+4\cdot4=33\]

大きさを求める

\[|\vec a+2\vec b|=\sqrt{33}=\sqrt{33}\]

垂直条件

\((\vec a+t\vec b)\cdot(\vec a-\vec b)=0\) を展開する。

\[|\vec a|^2-\vec a\cdot\vec b+t\,\vec a\cdot\vec b-t|\vec b|^2=0\]\[9-2+2\,t-4\,t=0\ \Rightarrow\ -2\,t=-7\]\[t=\dfrac{7}{2}\]

【答案】

\[\text{(1) }\sqrt{33}\quad\text{(2) }t=\dfrac{7}{2}\]

答

(2)　\(|\vec a|=2,\ |\vec b|=4,\ \vec a\cdot\vec b=3\) のとき、(1) \(|3\vec a-\vec b|\) (2) \(\vec a+t\vec b\) と \(\vec a-\vec b\) が垂直になる \(t\) の値を求めよ。

\(|k\vec a+l\vec b|^2\) を展開

\(|k\vec a+l\vec b|^2=k^2|\vec a|^2+2kl\,\vec a\cdot\vec b+l^2|\vec b|^2\)。

\[|3\vec a-\vec b|^2=9\cdot4+-6\cdot3+1\cdot16=34\]

大きさを求める

\[|3\vec a-\vec b|=\sqrt{34}=\sqrt{34}\]

垂直条件

\((\vec a+t\vec b)\cdot(\vec a-\vec b)=0\) を展開する。

\[|\vec a|^2-\vec a\cdot\vec b+t\,\vec a\cdot\vec b-t|\vec b|^2=0\]\[4-3+3\,t-16\,t=0\ \Rightarrow\ -13\,t=-1\]\[t=\dfrac{1}{13}\]

【答案】

\[\text{(1) }\sqrt{34}\quad\text{(2) }t=\dfrac{1}{13}\]

答

(3)　\(|\vec a|=4,\ |\vec b|=3,\ \vec a\cdot\vec b=5\) のとき、(1) \(|2\vec a+\vec b|\) (2) \(\vec a+t\vec b\) と \(\vec a-\vec b\) が垂直になる \(t\) の値を求めよ。

\(|k\vec a+l\vec b|^2\) を展開

\(|k\vec a+l\vec b|^2=k^2|\vec a|^2+2kl\,\vec a\cdot\vec b+l^2|\vec b|^2\)。

\[|2\vec a+\vec b|^2=4\cdot16+4\cdot5+1\cdot9=93\]

大きさを求める

\[|2\vec a+\vec b|=\sqrt{93}=\sqrt{93}\]

垂直条件

\((\vec a+t\vec b)\cdot(\vec a-\vec b)=0\) を展開する。

\[|\vec a|^2-\vec a\cdot\vec b+t\,\vec a\cdot\vec b-t|\vec b|^2=0\]\[16-5+5\,t-9\,t=0\ \Rightarrow\ -4\,t=-11\]\[t=\dfrac{11}{4}\]

【答案】

\[\text{(1) }\sqrt{93}\quad\text{(2) }t=\dfrac{11}{4}\]
