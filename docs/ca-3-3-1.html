ホーム ＞ 数学III ＞ 不定積分・置換積分・部分積分

別冊章末問題の解答

1.　不定積分 \(\displaystyle\int 5x(x^{2} + 4)^{3}\,dx\) を求めよ。

置換を決める

\(u=x^{2} + 4\) とおくと \(du=2x\,dx\)、すなわち \(x\,dx=\dfrac12du\)。

\(u\) で積分

\[\int 5 x(x^{2} + 4)^{3}dx=5\int u^{3}\cdot\dfrac12du=\dfrac{5}{2}\cdot\dfrac{u^{4}}{4}+C\]

\(x\) に戻す

\[=\dfrac{5}{8}(x^{2} + 4)^{4}+C\]

（例題1の型）

【答案】

\[\dfrac{5}{8}(x^{2} + 4)^{4}+C\]

答

2.　不定積分 \(\displaystyle\int\dfrac{8 x + 24}{x^{2} + 6 x + 1}\,dx\) を求めよ。

分子と分母の関係

分母 \(g(x)=x^{2} + 6 x + 1\) の導関数は \(g'(x)=2 x + 6\)。分子はその \(4\) 倍。

公式

\[\int\dfrac{g'(x)}{g(x)}dx=\log|g(x)|+C\]

積分

\[\int\dfrac{8 x + 24}{x^{2} + 6 x + 1}dx=4\int\dfrac{2 x + 6}{x^{2} + 6 x + 1}dx=4\log(x^{2} + 6 x + 1)+C\]

（例題2の型）

【答案】

\[4\log(x^{2} + 6 x + 1)+C\]

答

3.　不定積分 \(\displaystyle\int(x + 5)e^{3x}\,dx\) を求めよ。

部分積分の公式

\[\int f g'\,dx=fg-\int f'g\,dx\]

\(f,g'\) を決める

\(f=x + 5\)、\(g'=e^{3x}\)（\(g=\dfrac{1}{3}e^{3x}\)）。多項式の方を \(f\) にして、微分で次数を下げる。

計算

\[\int(x + 5)e^{3x}dx=(x + 5)\cdot\dfrac{1}{3}e^{3x}-\int\dfrac{1}{3}e^{3x}dx\]\[=\left(\dfrac{x}{3} + \dfrac{14}{9}\right)\,e^{3x}+C\]

（例題3の型）

【答案】

\[\left(\dfrac{x}{3} + \dfrac{14}{9}\right)e^{3x}+C\]

答

4.　不定積分 \(\displaystyle\int x^{6}\log x\,dx\ (x>0)\) を求めよ。

役割分担

\(f=\log x\)（微分すると \(\dfrac1x\)）、\(g'=x^{6}\)（\(g=\dfrac{x^{7}}{7}\)）。

部分積分

\[\int x^{6}\log x\,dx=\dfrac{x^{7}}{7}\log x-\int\dfrac1x\cdot\dfrac{x^{7}}{7}dx\]

残りを積分

\[=\dfrac{x^{7}}{7}\log x-\dfrac1{7}\int x^{6}dx=\dfrac{x^{7}}{7}\log x-\dfrac{x^{7}}{49}+C\]

（例題4の型）

【答案】

\[\dfrac{x^{7}}{7}\log x-\dfrac{x^{7}}{49}+C\]

答

5.　不定積分 \(\displaystyle\int\sin^26x\,dx\) を求めよ。

次数を下げる

半角の公式 \(\sin^2\theta=\dfrac{1-\cos2\theta}{2}\) を使う。

\[\sin^26x=\dfrac{1-\cos12x}{2}\]

積分

\[\int\sin^26x\,dx=\dfrac12\int(1-\cos12x)dx=\dfrac12\left(x-\dfrac{\sin12x}{12}\right)+C\]

（例題5の型）

【答案】

\[\dfrac{x}{2}-\dfrac{\sin12x}{24}+C\]

答

6.　不定積分 \(\displaystyle\int x\sqrt{2x+3}\,dx\) を求めよ。

置換

\(u=\sqrt{2x+3}\) とおくと \(x=\dfrac{u^2-3}{2},\ dx=\dfrac{2u}{2}du\)。

\(u\) の積分

\[\int x\sqrt{2x+3}\,dx=\int\dfrac{u^2-3}{2}\cdot u\cdot\dfrac{2u}{2}du=\int(\dfrac{u^{4}}{2} - \dfrac{3 u^{2}}{2})\,du\]

積分して戻す

\[=\dfrac{u^{5}}{10} - \dfrac{u^{3}}{2}+C\]

\(u=\sqrt{2x+3}\) を戻して整理：

\[\dfrac{\sqrt{2 x + 3} \left(2 x^{2} + x - 3\right)}{5}+C\]

（例題6の型）

【答案】

\[\dfrac{\sqrt{2 x + 3} \left(2 x^{2} + x - 3\right)}{5}+C\]

答

7.　不定積分 \(\displaystyle\int\dfrac{dx}{(x-1)(x+2)}\) を求めよ。

部分分数

\[\dfrac1{(x-1)(x+2)}=\dfrac{1}{3}\left(\dfrac1{x-1}-\dfrac1{x+2}\right)\]

積分

\[\dfrac{1}{3}\left(\log|x-1|-\log|x+2|\right)+C\]

まとめる

\[\dfrac{1}{3}\log\left|\dfrac{x-1}{x+2}\right|+C\]

（例題7の型）

【答案】

\[\dfrac{1}{3}\log\left|\dfrac{x-1}{x+2}\right|+C\]

答

8.　不定積分 \(\displaystyle\int e^{2x}\cos x\,dx\) を求めよ。

1回目の部分積分

\(J=\int e^{2x}\cos x\,dx\)。\(e^{2x}\) を積分する側にして部分積分。

2回目

もう一度部分積分すると \(J\) 自身が現れる。

\(J\) について解く

\[J=\dfrac{\left(\sin{\left(x \right)} + 2 \cos{\left(x \right)}\right) e^{2 x}}{5}+C\]

（例題8の型）

【答案】

\[\dfrac{\left(\sin{\left(x \right)} + 2 \cos{\left(x \right)}\right) e^{2 x}}{5}+C\]

答

9.　不定積分 \(\displaystyle\int\sin^{5}x\cos^{2}x\,dx\) を求めよ。

方針

sin の指数が奇数 → \(\cos x=u\) とおき、残りの偶数乗を \(\sin^2+\cos^2=1\) で書きかえる。

計算

\[\int\sin^{5}x\cos^{2}x\,dx\]

答え

\[- \dfrac{\left(15 \sin^{4}{\left(x \right)} + 12 \sin^{2}{\left(x \right)} + 8\right) \cos^{3}{\left(x \right)}}{105}+C\]

（例題9の型）

【答案】

\[- \dfrac{\left(15 \sin^{4}{\left(x \right)} + 12 \sin^{2}{\left(x \right)} + 8\right) \cos^{3}{\left(x \right)}}{105}+C\]

答

10.　不定積分 \(\displaystyle\int\tan5x\,dx\) を求めよ。

分子を導関数に

\[\tan5x=\dfrac{\sin5x}{\cos5x}=-\dfrac1{5}\cdot\dfrac{(\cos5x)'}{\cos5x}\]

積分

\[\int\tan5x\,dx=-\dfrac1{5}\log|\cos5x|+C\]

（例題10の型）

【答案】

\[-\dfrac1{5}\log|\cos5x|+C\]

答
