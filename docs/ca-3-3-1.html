ホーム ＞ 数学III ＞ 不定積分・置換積分・部分積分

別冊章末問題の解答

1.　不定積分 \(\displaystyle\int 5x(x^{2} + 4)^{3}\,dx\) を求めよ。

置換を決める

\(u=x^{2} + 4\) とおいて両辺を \(x\) で微分する。

\[\dfrac{du}{dx}=2x\ \Rightarrow\ du=2x\,dx\]

積分の中にある \(x\,dx\) をそのまま使えるよう、両辺を2でわる。

\[x\,dx=\dfrac12\,du\]

\(u\) で書きかえる

\(x^2+4\) を \(u\)、\(x\,dx\) を \(\dfrac12du\) に置きかえる。

\[\int 5\left(x^{2} + 4\right)^{3}\,x\,dx=5\int \left(x^{2} + 4\right)^{3}\cdot x\,dx\]\[=5\int u^{3}\cdot\dfrac12\,du=\dfrac{5}{2}\int u^{3}\,du\]

\(u\) で積分

\(\int u^{n}du=\dfrac{u^{n+1}}{n+1}\) を使う。

\[\dfrac{5}{2}\cdot\dfrac{u^{4}}{4}+C=\dfrac{5}{8}u^{4}+C\]

\(x\) に戻す

\(u=x^{2} + 4\) を戻す。

\[=\dfrac{5}{8}\left(x^{2} + 4\right)^{4}+C\]

検算（微分して確かめる）

\[\left\{\dfrac{5}{8}\left(x^{2} + 4\right)^{4}\right\}'=\dfrac{5}{8}\cdot4\left(x^{2} + 4\right)^{3}\cdot2x=5x\left(x^{2} + 4\right)^{3}\]

（例題1の型）

【答案】

\[\dfrac{5}{8}(x^{2} + 4)^{4}+C\]

答

2.　不定積分 \(\displaystyle\int\dfrac{8 x + 24}{x^{2} + 6 x + 1}\,dx\) を求めよ。

分母を微分する

\(g(x)=x^{2} + 6 x + 1\) とおき、導関数を求める。

\[g'(x)=2 x + 6\]

分子と見比べる

分子 \(8 x + 24\) と \(g'(x)=2 x + 6\) を比べる。

\[8 x + 24=4\left(2 x + 6\right)=4\,g'(x)\]

分子は \(g'(x)\) の \(4\) 倍。

定数を外に出す

定数 \(4\) は積分の外に出せる。

\[\int\dfrac{8 x + 24}{x^{2} + 6 x + 1}dx=4\int\dfrac{2 x + 6}{x^{2} + 6 x + 1}dx\]

公式を使う

\(\int\dfrac{g'(x)}{g(x)}dx=\log|g(x)|+C\)（\(g(x)\) は負になることもあるので絶対値をつける）。

\[=4\log|x^{2} + 6 x + 1|+C\]

（例題2の型）

【答案】

\[4\log|x^{2} + 6 x + 1|+C\]

答

3.　不定積分 \(\displaystyle\int(x + 5)e^{3x}\,dx\) を求めよ。

部分積分の公式

\[\int f\,g'\,dx=f\,g-\int f'\,g\,dx\]

\(f,g'\) を決める

多項式の方を \(f\)（微分すると次数が下がる）、\(e^{3x}\) の方を \(g'\) にする。

\[f=x + 5,\qquad f'=1\]\[g'=e^{3x}\ \Rightarrow\ g=\int e^{3x}dx=\dfrac{1}{3}e^{3x}\]

公式に代入

\[\int(x + 5)e^{3x}dx=(x + 5)\cdot\dfrac{1}{3}e^{3x}-\int1\cdot\dfrac{1}{3}e^{3x}dx\]

残りの積分を計算

\(\int e^{3x}dx=\dfrac{1}{3}e^{3x}\) なので、

\[\int\dfrac{1}{3}e^{3x}dx=\dfrac{1}{3}\cdot\dfrac{1}{3}e^{3x}=\dfrac{1}{9}e^{3x}\]\[\int(x + 5)e^{3x}dx=\dfrac{1}{3}(x + 5)e^{3x}-\dfrac{1}{9}e^{3x}+C\]

\(e^{3x}\) でくくる

\[=\left\{\dfrac{1}{3}(x + 5)-\dfrac{1}{9}\right\}e^{3x}+C\]\[=\left(\dfrac{x}{3} + \dfrac{14}{9}\right)e^{3x}+C\]

（例題3の型）

【答案】

\[\left(\dfrac{x}{3} + \dfrac{14}{9}\right)e^{3x}+C\]

答

4.　不定積分 \(\displaystyle\int x^{6}\log x\,dx\ (x>0)\) を求めよ。

部分積分の公式

\[\int f\,g'\,dx=f\,g-\int f'\,g\,dx\]

役割分担

\(\log x\) は積分しにくいので \(f\)（微分する側）にする。

\[f=\log x,\qquad f'=\dfrac1x\]\[g'=x^{6}\ \Rightarrow\ g=\int x^{6}dx=\dfrac{x^{7}}{7}\]

公式に代入

\[\int x^{6}\log x\,dx=\log x\cdot\dfrac{x^{7}}{7}-\int\dfrac1x\cdot\dfrac{x^{7}}{7}dx\]

残りの積分を整える

\(\dfrac1x\cdot x^{7}=x^{6}\)、\(\dfrac1{7}\) は外に出す。

\[\int\dfrac1x\cdot\dfrac{x^{7}}{7}dx=\dfrac1{7}\int x^{6}dx=\dfrac1{7}\cdot\dfrac{x^{7}}{7}=\dfrac{x^{7}}{49}\]

答え

\[\int x^{6}\log x\,dx=\dfrac{x^{7}}{7}\log x-\dfrac{x^{7}}{49}+C\]

（例題4の型）

【答案】

\[\dfrac{x^{7}}{7}\log x-\dfrac{x^{7}}{49}+C\]

答

5.　不定積分 \(\displaystyle\int\sin^26x\,dx\) を求めよ。

次数を下げる

半角の公式 \(\sin^2\theta=\dfrac{1-\cos2\theta}{2}\) に \(\theta=6x\) を代入する。

\[\sin^26x=\dfrac{1-\cos(2\cdot6x)}{2}=\dfrac{1-\cos12x}{2}\]

積分を2つに分ける

\[\int\sin^26x\,dx=\int\dfrac{1-\cos12x}{2}dx=\dfrac12\int dx-\dfrac12\int\cos12x\,dx\]

それぞれ積分

\(\int dx=x\)、\(\int\cos kx\,dx=\dfrac{\sin kx}{k}\) を使う（\(k=12\)）。

\[\dfrac12\cdot x-\dfrac12\cdot\dfrac{\sin12x}{12}\]

答え

\[=\dfrac{x}{2}-\dfrac{\sin12x}{24}+C\]

（例題5の型）

【答案】

\[\dfrac{x}{2}-\dfrac{\sin12x}{24}+C\]

答

6.　不定積分 \(\displaystyle\int x\sqrt{2x+3}\,dx\) を求めよ。

置換を決める

根号の中身を文字にする。

\[u=\sqrt{2x+3}\]

両辺を2乗して \(x\) を \(u\) で表す。

\[u^2=2x+3\ \Rightarrow\ x=\dfrac{u^2-3}{2}\]

\(dx\) を \(u\) で表す

\(u^2=2x+3\) の両辺を微分する。

\[2u\,du=2\,dx\ \Rightarrow\ dx=\dfrac{2u}{2}\,du\]

\(u\) の式に書きかえる

\[\int x\sqrt{2x+3}\,dx=\int\dfrac{u^2-3}{2}\cdot u\cdot\dfrac{2u}{2}\,du\]

係数をまとめ、\(u\) の累乗を整理する。

\[=\dfrac{1}{2}\int(u^2-3)u^2\,du=\dfrac{1}{2}\int(u^4-3u^2)\,du\]

積分する

\(\int u^ndu=\dfrac{u^{n+1}}{n+1}\) を使う。

\[=\dfrac{1}{2}\left(\dfrac{u^5}{5}-\dfrac{3u^3}{3}\right)+C=\dfrac{u^{5}}{10} - \dfrac{u^{3}}{2}+C\]

\(x\) に戻す

\(u^3\) でくくり、\(u^2=2x+3\) を使う。

\[=\dfrac{1}{2}\,u^3\left(\dfrac{u^2}{5}-\dfrac{3}{3}\right)=\dfrac{1}{2}\,u^3\cdot\dfrac{3u^2-15}{15}\]

\(u^2=2x+3\)、\(u^3=(2x+3)\sqrt{2x+3}\) を入れる。

\[3u^2-15=3(2x+3)-15=6 x - 6\]\[=\dfrac{1}{30}(2x+3)\sqrt{2x+3}\,(6 x - 6)+C\]

（\((2x+3)\sqrt{2x+3}=(2x+3)^{\frac32}\)）

（例題6の型）

【答案】

\[\dfrac{1}{30}(2x+3)\sqrt{2x+3}\,(6 x - 6)+C\]

答

7.　不定積分 \(\displaystyle\int\dfrac{dx}{(x-1)(x+2)}\) を求めよ。

部分分数に分ける

\[\dfrac1{(x-1)(x+2)}=\dfrac{A}{x-1}+\dfrac{B}{x+2}\]

両辺に \((x-1)(x+2)\) をかけて分母をはらう。

\[1=A(x+2)+B(x-1)\]

\(A,B\) を求める

\(x=1\) を代入すると \(B\) の項が消える。

\[1=A(1-(-2))\ \Rightarrow\ 1=3A\ \Rightarrow\ A=\dfrac{1}{3}\]

\(x=-2\) を代入すると \(A\) の項が消える。

\[1=B(-2-1)\ \Rightarrow\ 1=-3B\ \Rightarrow\ B=- \dfrac{1}{3}\]\[\dfrac1{(x-1)(x+2)}=\dfrac{1}{3}\left(\dfrac1{x-1}-\dfrac1{x+2}\right)\]

項ごとに積分

\(\int\dfrac{dx}{x-p}=\log|x-p|\) を使う。

\[\int\dfrac1{x-1}dx=\log|x-1|,\qquad\int\dfrac1{x+2}dx=\log|x+2|\]\[\dfrac{1}{3}\left(\log|x-1|-\log|x+2|\right)+C\]

対数をまとめる

\(\log|P|-\log|Q|=\log\left|\dfrac PQ\right|\) を使う。

\[\dfrac{1}{3}\log\left|\dfrac{x-1}{x+2}\right|+C\]

（例題7の型）

【答案】

\[\dfrac{1}{3}\log\left|\dfrac{x-1}{x+2}\right|+C\]

答

8.　不定積分 \(\displaystyle\int e^{2x}\cos x\,dx\) を求めよ。

おくものを決める

\(P=\int e^{2x}\sin x\,dx\)、\(Q=\int e^{2x}\cos x\,dx\) とおく。求めたいのは \(Q\)。\(e^{2x}\) を積分する側にして、\(P\) と \(Q\) をそれぞれ部分積分する。

\[\int e^{2x}\,dx=\dfrac1{2}e^{2x}\]

\(P\) を部分積分

\(f=\sin x,\ f'=\cos x,\ g=\dfrac1{2}e^{2x}\)。

\[P=\dfrac1{2}e^{2x}\sin x-\int\cos x\cdot\dfrac1{2}e^{2x}\,dx=\dfrac1{2}e^{2x}\sin x-\dfrac1{2}Q\]

\(Q\) を部分積分

\(f=\cos x,\ f'=-\sin x,\ g=\dfrac1{2}e^{2x}\)。

\[Q=\dfrac1{2}e^{2x}\cos x-\int(-\sin x)\cdot\dfrac1{2}e^{2x}\,dx=\dfrac1{2}e^{2x}\cos x+\dfrac1{2}P\]

\(Q\) だけの式にする

\(Q\) の式に、もう一方の式を代入し、かっこをはずす。

\[Q=\dfrac1{2}e^{2x}\cos x+\dfrac1{2}\left(\dfrac1{2}e^{2x}\sin x-\dfrac1{2}Q\right)\]

\(Q\) を含む項を左辺に集める。

\[Q+\dfrac1{4}Q=\dfrac1{2}e^{2x}\cos x+\dfrac1{4}e^{2x}\sin x\]

\(Q\) について解く

両辺に \(4\) をかけて分数をなくす。

\[(4+1)\,Q=e^{2x}(2\cos x+\sin x)\]

両辺を \(5\) でわる。

\[Q=\dfrac{e^{2x}(2\cos x+\sin x)}{5}+C\]

（例題8の型）

【答案】

\[\dfrac{e^{2x}(2\cos x+\sin x)}{5}+C\]

答

9.　不定積分 \(\displaystyle\int \sin^{5}x\cos^{2}x\,dx\) を求めよ。

置換を決める

\(\sin\) の指数 \(5\) が奇数なので、\(\sin x\) を1つ取り出し、\(u=\cos x\) とおく。

\[\dfrac{du}{dx}=-\sin x\ \Rightarrow\ \sin x\,dx=-du\]

残りを \(\cos x\) で表す

\[\sin^{5}x=\sin^{4}x\cdot\sin x=(\sin^2x)^{2}\sin x=(1-\cos^2x)^{2}\sin x\]

したがって

\[\int\sin^{5}x\cos^{2}x\,dx=\int(1-\cos^2x)^{2}\cos^{2}x\cdot\sin x\,dx\]

\(u\) の式にする

\(\cos x=u,\ \sin x\,dx=-du\) を代入する。

\[=-\int(1-u^2)^{2}u^{2}\,du\]

展開して \(u\) の多項式にする。

\[=-\int\left(u^{6} - 2 u^{4} + u^{2}\right)du\]

積分する

各項に \(\int u^ndu=\dfrac{u^{n+1}}{n+1}\) を使う。

\[=-\left(\dfrac{u^{7}}{7} - \dfrac{2 u^{5}}{5} + \dfrac{u^{3}}{3}\right)+C\]\[=- \dfrac{u^{7}}{7} + \dfrac{2 u^{5}}{5} - \dfrac{u^{3}}{3}+C\]

\(x\) に戻す

\(u=\cos x\) を戻す。

\[=-\dfrac{1}{7}\cos^{7}x+\dfrac{2}{5}\cos^{5}x-\dfrac{1}{3}\cos^{3}x+C\]

（例題9の型）

【答案】

\[-\dfrac{1}{7}\cos^{7}x+\dfrac{2}{5}\cos^{5}x-\dfrac{1}{3}\cos^{3}x+C\]

答

10.　不定積分 \(\displaystyle\int\tan 5x\,dx\) を求めよ。

\(\tan\) を \(\sin,\cos\) で表す

\[\tan 5x=\dfrac{\sin 5x}{\cos 5x}\]

分母を微分する

\((\cos 5x)'=-5\sin 5x\) なので、分子 \(\sin 5x\) は \((\cos 5x)'\) の \(-\dfrac1{5}\) 倍。

\[\sin 5x=-\dfrac1{5}\cdot(\cos 5x)'\]

積分の形に直す

\[\int\tan 5x\,dx=-\dfrac1{5}\int\dfrac{(\cos 5x)'}{\cos 5x}dx\]

公式を使う

\(\int\dfrac{g'}{g}dx=\log|g|+C\) より、

\[=-\dfrac1{5}\log|\cos 5x|+C\]

（例題10の型）

【答案】

\[-\dfrac1{5}\log|\cos 5x|+C\]
