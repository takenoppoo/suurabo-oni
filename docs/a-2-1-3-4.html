別冊練習問題 4 の解答　不等式の証明（差をとって平方の和にする）

(1)　\(a^{2} + b^{2} + 1\geqq a b + a + b\) を証明せよ。ただし文字はすべて実数とし、等号が成り立つときの条件も答えよ。

左辺 \(-\) 右辺 を計算する

\[\text{左辺}-\text{右辺}=a^{2} - a b - a + b^{2} - b + 1\]

平方の和（または平方）に変形する

\[a^{2} - a b - a + b^{2} - b + 1=\dfrac12\left\{(a-b)^2+(a-1)^2+(b-1)^2\right\}\]

0以上であることを示す

実数の平方は 0 以上なので、上の式は 0 以上。よって 左辺 \(\geqq\) 右辺。

等号が成り立つ条件

\(a=b=1\) のとき。

【答案】

\[\text{（証明終）}\ \ \text{等号成立：}$a=b=1$ のとき。\]

答

(2)　\(\left(a^{2} + b^{2}\right) \left(x^{2} + y^{2}\right)\geqq \left(a x + b y\right)^{2}\) を証明せよ。ただし文字はすべて実数とし、等号が成り立つときの条件も答えよ。

左辺 \(-\) 右辺 を計算する

\[\text{左辺}-\text{右辺}=a^{2} y^{2} - 2 a b x y + b^{2} x^{2}\]

平方の和（または平方）に変形する

\[a^{2} y^{2} - 2 a b x y + b^{2} x^{2}=(ay-bx)^2\]

0以上であることを示す

実数の平方は 0 以上なので、上の式は 0 以上。よって 左辺 \(\geqq\) 右辺。

等号が成り立つ条件

\(ay=bx\) のとき。

【答案】

\[\text{（証明終）}\ \ \text{等号成立：}$ay=bx$ のとき。\]

答

(3)　\(a^{2} + b^{2} + c^{2} + 3\geqq 2 a + 2 b + 2 c\) を証明せよ。ただし文字はすべて実数とし、等号が成り立つときの条件も答えよ。

左辺 \(-\) 右辺 を計算する

\[\text{左辺}-\text{右辺}=a^{2} - 2 a + b^{2} - 2 b + c^{2} - 2 c + 3\]

平方の和（または平方）に変形する

\[a^{2} - 2 a + b^{2} - 2 b + c^{2} - 2 c + 3=(a-1)^2+(b-1)^2+(c-1)^2\]

0以上であることを示す

実数の平方は 0 以上なので、上の式は 0 以上。よって 左辺 \(\geqq\) 右辺。

等号が成り立つ条件

\(a=b=c=1\) のとき。

【答案】

\[\text{（証明終）}\ \ \text{等号成立：}$a=b=c=1$ のとき。\]
