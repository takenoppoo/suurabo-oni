例題 9数と式　置き換えのあと、さらに因数分解

\((x^{2} + 3 x)^2+7(x^{2} + 3 x)+10\) を因数分解せよ。

解き方（まず考え方）

共通のかたまり \(X=x^2+ax\) で2次式にする。因数分解後は \(X\) をもどし、さらに因数分解できる因数がないかを必ず確かめる。

コツ置き換えは通過点。ゴールまで、もどしてもう一度チェック。

解答

STEP 1 かたまりで置き換える

\(X=x^{2} + 3 x\) とおく。

\[(x^{2} + 3 x)^2+7(x^{2} + 3 x)+10=X^2+7X+10\]

❓ なぜ置き換えると解けるの？

\(x^2+ax\) が2回出てくるから、1つのかたまり \(X\) として扱える。4次式が、\(X\) の2次式（たすき掛けや和と積で解ける形）になる。

STEP 2 \(X\) で因数分解
\[X^2+7X+10=(X+2)(X+5)\]
STEP 3 \(X\) をもどし、さらに分解
\[(x^{2} + 3 x + 2)(x^{2} + 3 x + 5)=\left(x + 1\right) \left(x + 2\right) \left(x^{2} + 3 x + 5\right)\]

❓ なぜ「もどしたあと」にまた調べるの？

\(X\) の式の因数は \(X+p\) の形。\(X\) をもどすと \(x^2+ax+p\) の2次式になる。2次式は、さらに分けられることがある。例題の最初の問題（\(a=3\)）では：

因数かけて・たして分けられる？
\(x^2+3x+2\)かけて2・たして3 → \(1,\ 2\)○　\((x+1)(x+2)\)
\(x^2+3x+5\)かけて5・たして3 → なし（\(9-20<0\)）×　このまま

分けられる因数が残っていないか、全部の因数を確かめて初めて完成。

【答案（テストに書く形）】

\[\left(x + 1\right) \left(x + 2\right) \left(x^{2} + 3 x + 5\right)\]
