別冊練習問題 2 の解答　割り算の関係式から元の式を求める

(1)　整式 \(P(x)\) を \(x^{2} - x - 2\) で割ると、商が \(x + 3\)、余りが \(2 x - 5\) である。(1) \(P(x)\) を求めよ。(2) \(P(x)\) を \(x - 2\) で割った余りを求めよ。

割り算の関係式を書く

\[P(x)=(\text{割る式})\times(\text{商})+(\text{余り})\]\[P(x)=\left(x^{2} - x - 2\right)\left(x + 3\right)+\left(2 x - 5\right)\]

展開して \(P(x)\) を求める

\[P(x)=x^{3} + 2 x^{2} - 3 x - 11\]

割る式を因数分解する

\[x^{2} - x - 2=(x - 2)(x + 1)\]

よって \(P(x)=(x - 2)\{(x + 1)(x + 3)\}+(2 x - 5)\)。

余りを x - 2 で割る

\(x - 2\) で割ったとき、商のかたまりの部分は割り切れる。残る \(2 x - 5\) を \(x - 2\) で割った余りが答え。

\[2 x - 5=2\left(x - 2\right)-1\ \Rightarrow\ \text{余り }-1\]

【答案】

\[P(x)=x^{3} + 2 x^{2} - 3 x - 11,\quad \text{余り }-1\]

(2)　整式 \(P(x)\) を \(x^{2} - 4 x + 3\) で割ると、商が \(3 x - 2\)、余りが \(- x + 6\) である。(1) \(P(x)\) を求めよ。(2) \(P(x)\) を \(x - 3\) で割った余りを求めよ。

割り算の関係式を書く

\[P(x)=(\text{割る式})\times(\text{商})+(\text{余り})\]\[P(x)=\left(x^{2} - 4 x + 3\right)\left(3 x - 2\right)+\left(- x + 6\right)\]

展開して \(P(x)\) を求める

\[P(x)=3 x^{3} - 14 x^{2} + 16 x\]

割る式を因数分解する

\[x^{2} - 4 x + 3=(x - 3)(x - 1)\]

よって \(P(x)=(x - 3)\{(x - 1)(3 x - 2)\}+(- x + 6)\)。

余りを x - 3 で割る

\(x - 3\) で割ったとき、商のかたまりの部分は割り切れる。残る \(- x + 6\) を \(x - 3\) で割った余りが答え。

\[- x + 6=-\left(x - 3\right)+3\ \Rightarrow\ \text{余り }3\]

【答案】

\[P(x)=3 x^{3} - 14 x^{2} + 16 x,\quad \text{余り }3\]

答

(3)　整式 \(P(x)\) を \(x^{2} - 3 x - 4\) で割ると、商が \(x - 4\)、余りが \(4 x + 1\) である。(1) \(P(x)\) を求めよ。(2) \(P(x)\) を \(x + 1\) で割った余りを求めよ。

割り算の関係式を書く

\[P(x)=(\text{割る式})\times(\text{商})+(\text{余り})\]\[P(x)=\left(x^{2} - 3 x - 4\right)\left(x - 4\right)+\left(4 x + 1\right)\]

展開して \(P(x)\) を求める

\[P(x)=x^{3} - 7 x^{2} + 12 x + 17\]

割る式を因数分解する

\[x^{2} - 3 x - 4=(x - 4)(x + 1)\]

よって \(P(x)=(x + 1)\{(x - 4)(x - 4)\}+(4 x + 1)\)。

余りを x + 1 で割る

\(x + 1\) で割ったとき、商のかたまりの部分は割り切れる。残る \(4 x + 1\) を \(x + 1\) で割った余りが答え。

\[4 x + 1=4\left(x + 1\right)-3\ \Rightarrow\ \text{余り }-3\]

【答案】

\[P(x)=x^{3} - 7 x^{2} + 12 x + 17,\quad \text{余り }-3\]
