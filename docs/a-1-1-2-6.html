別冊練習問題 6 の解答　3次式の因数分解（因数定理）

(1)　\(x^{3} + 2 x^{2} - 5 x - 6\) を因数分解せよ。

因数定理で1つ見つける

定数項の約数から候補を探す。\(x=-1\) を代入すると

\[P(-1)=(-1)^{3}+2\cdot (-1)^{2}-5\cdot (-1)-6=0\]

0 なので \(x+1\) を因数にもつ。

組立除法で割る

\(x^{3} + 2 x^{2} - 5 x - 6\) を \(x + 1\) でわる。係数を並べ、左に \(-1\) をおく。

\(1\)\(2\)\(-5\)\(-6\)
\(-1\) を下ろしてかける\(-1\)\(-1\)\(6\)
たして下へ\(1\)\(1\)\(-6\)\(0\)

左から順に「たす → \(-1\) をかける → 次の列へ」をくり返す。いちばん右（余り）が \(0\)、残りが商の係数。

\[x^{3} + 2 x^{2} - 5 x - 6=(x + 1)(x^{2} + x - 6)\]

商をさらに因数分解

\[x^{2} + x - 6=\left(x - 2\right) \left(x + 3\right)\]\[x^{3} + 2 x^{2} - 5 x - 6=\left(x - 2\right) \left(x + 1\right) \left(x + 3\right)\]

【答案】

\[\left(x - 2\right) \left(x + 1\right) \left(x + 3\right)\]

(2)　\(x^{3} - 3 x^{2} - 10 x + 24\) を因数分解せよ。

因数定理で1つ見つける

定数項の約数から候補を探す。\(x=2\) を代入すると

\[P(2)=2^{3}-3\cdot 2^{2}-10\cdot 2+24=0\]

0 なので \(x-2\) を因数にもつ。

組立除法で割る

\(x^{3} - 3 x^{2} - 10 x + 24\) を \(x - 2\) でわる。係数を並べ、左に \(2\) をおく。

\(1\)\(-3\)\(-10\)\(24\)
\(2\) を下ろしてかける\(2\)\(-2\)\(-24\)
たして下へ\(1\)\(-1\)\(-12\)\(0\)

左から順に「たす → \(2\) をかける → 次の列へ」をくり返す。いちばん右（余り）が \(0\)、残りが商の係数。

\[x^{3} - 3 x^{2} - 10 x + 24=(x - 2)(x^{2} - x - 12)\]

商をさらに因数分解

\[x^{2} - x - 12=\left(x - 4\right) \left(x + 3\right)\]\[x^{3} - 3 x^{2} - 10 x + 24=\left(x - 4\right) \left(x - 2\right) \left(x + 3\right)\]

【答案】

\[\left(x - 4\right) \left(x - 2\right) \left(x + 3\right)\]

(3)　\(2 x^{3} + 12 x^{2} + 6 x - 20\) を因数分解せよ。

因数定理で1つ見つける

定数項の約数から候補を探す。\(x=1\) を代入すると

\[P(1)=2\cdot 1^{3}+12\cdot 1^{2}+6\cdot 1-20=0\]

0 なので \(x-1\) を因数にもつ。

組立除法で割る

\(2 x^{3} + 12 x^{2} + 6 x - 20\) を \(x - 1\) でわる。係数を並べ、左に \(1\) をおく。

\(2\)\(12\)\(6\)\(-20\)
\(1\) を下ろしてかける\(2\)\(14\)\(20\)
たして下へ\(2\)\(14\)\(20\)\(0\)

左から順に「たす → \(1\) をかける → 次の列へ」をくり返す。いちばん右（余り）が \(0\)、残りが商の係数。

\[2 x^{3} + 12 x^{2} + 6 x - 20=(x - 1)(2 x^{2} + 14 x + 20)\]

商をさらに因数分解

\[2 x^{2} + 14 x + 20=2 \left(x + 2\right) \left(x + 5\right)\]\[2 x^{3} + 12 x^{2} + 6 x - 20=2 \left(x - 1\right) \left(x + 2\right) \left(x + 5\right)\]

【答案】

\[2 \left(x - 1\right) \left(x + 2\right) \left(x + 5\right)\]
