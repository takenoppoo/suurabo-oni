別冊練習問題 5 の解答　相加・相乗平均で最小値を求める

(1)　\(x>0\) のとき、\(2 x + \dfrac{18}{x}\) の最小値と、そのときの \(x\) の値を求めよ。

積が定数になるように変形する

\(x>0\) より \(x-0>0\)。\(u=x-0\) とおくと \(u>0\)。

\[2 x + \dfrac{18}{x}=2u+\dfrac{18}{u}\]

相加・相乗平均の不等式を使う

\(u>0,\ \frac{q}{u}>0\) だから、\(A+B\geqq2\sqrt{AB}\) より

\[2u+\dfrac{18}{u}\geqq 2\sqrt{2 u\cdot\dfrac{18}{u}}=2\sqrt{36}=12\]

最小値

\[2 x + \dfrac{18}{x}\geqq 12=12\]

等号が成り立つ条件

\(2u=\dfrac{18}{u}\) すなわち \(u^2=9\)、\(u=3\)（\(u>0\) を満たす）。よって \(x=3\) のとき最小。

【答案】

\[x=3\ \text{のとき最小値 }12\]

答

(2)　\(x>2\) のとき、\(3 x + \dfrac{12}{x - 2}\) の最小値と、そのときの \(x\) の値を求めよ。

積が定数になるように変形する

\(x>2\) より \(x-2>0\)。\(u=x-2\) とおくと \(u>0\)。

\[3 x + \dfrac{12}{x - 2}=3u+\dfrac{12}{u}+6\]

相加・相乗平均の不等式を使う

\(u>0,\ \frac{q}{u}>0\) だから、\(A+B\geqq2\sqrt{AB}\) より

\[3u+\dfrac{12}{u}\geqq 2\sqrt{3 u\cdot\dfrac{12}{u}}=2\sqrt{36}=12\]

最小値

\[3 x + \dfrac{12}{x - 2}\geqq 12+6=18\]

等号が成り立つ条件

\(3u=\dfrac{12}{u}\) すなわち \(u^2=4\)、\(u=2\)（\(u>0\) を満たす）。よって \(x=4\) のとき最小。

【答案】

\[x=4\ \text{のとき最小値 }18\]

答

(3)　\(x>-1\) のとき、\(4 x + \dfrac{9}{x + 1}\) の最小値と、そのときの \(x\) の値を求めよ。

積が定数になるように変形する

\(x>-1\) より \(x+1>0\)。\(u=x+1\) とおくと \(u>0\)。

\[4 x + \dfrac{9}{x + 1}=4u+\dfrac{9}{u}-4\]

相加・相乗平均の不等式を使う

\(u>0,\ \frac{q}{u}>0\) だから、\(A+B\geqq2\sqrt{AB}\) より

\[4u+\dfrac{9}{u}\geqq 2\sqrt{4 u\cdot\dfrac{9}{u}}=2\sqrt{36}=12\]

最小値

\[4 x + \dfrac{9}{x + 1}\geqq 12-4=8\]

等号が成り立つ条件

\(4u=\dfrac{9}{u}\) すなわち \(u^2=\dfrac{9}{4}\)、\(u=\dfrac{3}{2}\)（\(u>0\) を満たす）。よって \(x=\dfrac{1}{2}\) のとき最小。

【答案】

\[x=\dfrac{1}{2}\ \text{のとき最小値 }8\]
