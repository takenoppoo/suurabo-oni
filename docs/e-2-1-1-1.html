ホーム ＞ 数学II ＞ 整式の割り算・分数式

例題 1いろいろな式　整式の割り算（筆算）

整式 \(6 x^{4} - x^{3} - 7 x^{2} + 5 x - 2\) を \(2 x^{2} + x - 3\) で割ったときの商と余りを求めよ。

解き方（まず考え方）

整式の割り算は数の筆算と同じ。降べきの順に並べ、最高次の項どうしを割って商の項を決め、割る式を掛けて引く。余りの次数が割る式の次数より小さくなるまで繰り返す。

\[A=BQ+R\quad(R\text{ の次数}<B\text{ の次数})\]
コツ割り算は「何回引けるか」の繰り返し。まず一番大きい次数の項だけを見て、1回ぶん引く。

解答

STEP 1 商を1項ずつ立てて引く

最高次の項どうしを割って商の項を決め、（割る式）×（商の項）を引く。余りの次数が割る式より小さくなるまで繰り返す。

\(6 x^{4}\div\left(2 x^{2}\right)=3 x^{2}\) を商に立てる。

\[6 x^{4} - x^{3} - 7 x^{2} + 5 x - 2-\left(3 x^{2}\right)\left(2 x^{2} + x - 3\right)=- 4 x^{3} + 2 x^{2} + 5 x - 2\]

\(- 4 x^{3}\div\left(2 x^{2}\right)=- 2 x\) を商に立てる。

\[- 4 x^{3} + 2 x^{2} + 5 x - 2-\left(- 2 x\right)\left(2 x^{2} + x - 3\right)=4 x^{2} - x - 2\]

\(4 x^{2}\div\left(2 x^{2}\right)=2\) を商に立てる。

\[4 x^{2} - x - 2-\left(2\right)\left(2 x^{2} + x - 3\right)=- 3 x + 4\]
STEP 2 商と余りを読む
\[\text{商 }3 x^{2} - 2 x + 2,\quad \text{余り }- 3 x + 4\]
STEP 3 確かめ
\[\begin{aligned}&\left(2 x^{2} + x - 3\right)\left(3 x^{2} - 2 x + 2\right)+\left(- 3 x + 4\right)\\ &=6 x^{4} - x^{3} - 7 x^{2} + 5 x - 2\end{aligned}\]

【答案（テストに書く形）】

\[\text{商 }3 x^{2} - 2 x + 2,\quad \text{余り }- 3 x + 4\]
