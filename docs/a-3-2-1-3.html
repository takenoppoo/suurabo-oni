別冊練習問題 3 の解答　合成関数の微分（三角関数）

(1)　\(y=\sin^{2}(x^{2} + x)\) を微分せよ。

合成関数の微分の公式を書く

\[\{f(g(x))\}'=f'(g(x))\,g'(x)\]

層に分ける

\(u=x^{2} + x\)、\(v=\sin u\)、\(y=v^{2}\) とおく。

各層を微分する

\[\dfrac{dy}{dv}=2v=2\sinu,\qquad \dfrac{dv}{du}=\cos u,\qquad \dfrac{du}{dx}=2 x + 1\]

かけ合わせる

\[y'=\dfrac{dy}{dv}\cdot\dfrac{dv}{du}\cdot\dfrac{du}{dx}=2\sin(x^{2} + x)\cdot\cos(x^{2} + x)\cdot(2 x + 1)\]

係数をまとめる

\[y'=4 x + 2\sin(x^{2} + x)\cos(x^{2} + x)\]

【答案】

\[y'=4 x + 2\sin(x^{2} + x)\cos(x^{2} + x)\]

答

(2)　\(y=\sin^{3}(2 x^{2} + x)\) を微分せよ。

合成関数の微分の公式を書く

\[\{f(g(x))\}'=f'(g(x))\,g'(x)\]

層に分ける

\(u=2 x^{2} + x\)、\(v=\sin u\)、\(y=v^{3}\) とおく。

各層を微分する

\[\dfrac{dy}{dv}=3v^{2}=3\sin^{2}u,\qquad \dfrac{dv}{du}=\cos u,\qquad \dfrac{du}{dx}=4 x + 1\]

かけ合わせる

\[y'=\dfrac{dy}{dv}\cdot\dfrac{dv}{du}\cdot\dfrac{du}{dx}=3\sin^{2}(2 x^{2} + x)\cdot\cos(2 x^{2} + x)\cdot(4 x + 1)\]

係数をまとめる

\[y'=12 x + 3\sin^{2}(2 x^{2} + x)\cos(2 x^{2} + x)\]

【答案】

\[y'=12 x + 3\sin^{2}(2 x^{2} + x)\cos(2 x^{2} + x)\]

答

(3)　\(y=\sin^{4}(x^{2} - x)\) を微分せよ。

合成関数の微分の公式を書く

\[\{f(g(x))\}'=f'(g(x))\,g'(x)\]

層に分ける

\(u=x^{2} - x\)、\(v=\sin u\)、\(y=v^{4}\) とおく。

各層を微分する

\[\dfrac{dy}{dv}=4v^{3}=4\sin^{3}u,\qquad \dfrac{dv}{du}=\cos u,\qquad \dfrac{du}{dx}=2 x - 1\]

かけ合わせる

\[y'=\dfrac{dy}{dv}\cdot\dfrac{dv}{du}\cdot\dfrac{du}{dx}=4\sin^{3}(x^{2} - x)\cdot\cos(x^{2} - x)\cdot(2 x - 1)\]

係数をまとめる

\[y'=8 x - 4\sin^{3}(x^{2} - x)\cos(x^{2} - x)\]

【答案】

\[y'=8 x - 4\sin^{3}(x^{2} - x)\cos(x^{2} - x)\]
