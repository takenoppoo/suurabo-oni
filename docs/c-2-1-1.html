章末問題整式の割り算・分数式

例題1〜10で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. 整式 \(5 x^{4} - 3 x^{3} + 2 x - 7\) を \(5 x^{2} + 2 x - 1\) で割ったときの商と余りを求めよ。
  2. 整式 \(P(x)\) を \(x^{2} + x - 6\) で割ると、商が \(2 x + 5\)、余りが \(- 3 x + 2\) である。(1) \(P(x)\) を求めよ。(2) \(P(x)\) を \(x - 2\) で割った余りを求めよ。
  3. 次の計算をして、できるだけ簡単な分数式で答えよ。 \[\dfrac{4}{x + 1}-\dfrac{3}{x - 2}+\dfrac{12}{x^{2} - x - 2}\]
  4. 次の計算をせよ。 \[\dfrac{x^{2} - 7 x + 6}{x^{2} - 4 x - 12}\div\dfrac{x^{2} + 4 x - 5}{x^{2} + 4 x + 4}\]
  5. 次の和を計算せよ。 \[\dfrac{1}{x(x + 4)}+\dfrac{1}{(x + 4)(x + 8)}+\dfrac{1}{(x + 8)(x + 12)}\]
  6. \(4 x^{4} + x^{2} - x + 6\) を \(2 x^{2} - x + 1\) で割ったときの商と余りを求めよ。
  7. 次の式を簡単にせよ。\(\dfrac{\dfrac{1}{x-2}-\dfrac{1}{x+5}}{\dfrac{1}{x-2}+\dfrac{1}{x+5}}\)
  8. \(\displaystyle\sum_{k=1}^{8}\dfrac{1}{k(k+4)}\) の値を求めよ。
  9. 整式 \(x^4+Ax^2+Bx-6\) が \(x^{2} + 2 x - 3\) で割り切れるように、定数 \(A,\ B\) の値を定めよ。
  10. 整数 \(n\) について、\(\dfrac{n^2+5n+12}{n+1}\) が整数となるような \(n\) をすべて求めよ。
