別冊練習問題 3 の解答　3つの項をもつ式の展開

(1)　\(\left(x^{2} + 2 x - 1\right)^{4}\) の展開式における \(x^{3}\) の項の係数を求めよ。

一般項（多項定理）を書く

\(x^2\) を \(i\) 個、\(2x\) を \(j\) 個、\(-1\) を \(l\) 個とる（\(i+j+l=4\)）。係数は

\[\dfrac{4!}{i!\,j!\,l!}\,(x^2)^i(2x)^j(-1)^l\]

\(x^{3}\) になる組 \((i,j,l)\) を数え上げる

\(x\) の指数：\(2i+j=3\)、個数：\(i+j+l=4\) を同時に満たす非負整数の組は

\[(0,3,1),\ (1,1,2)\]

各組の係数を計算する

\[\begin{aligned}(i,j,l)=(0,3,1):\ \dfrac{4!}{0!\,3!\,1!}\cdot 1^{0}(2)^{3}(-1)^{1}=-32\\ (i,j,l)=(1,1,2):\ \dfrac{4!}{1!\,1!\,2!}\cdot 1^{1}(2)^{1}(-1)^{2}=24\end{aligned}\]

合計する

\[(-32)+24=-8\]

【答案】

\[-8\]

答

(2)　\(\left(x^{2} - x + 2\right)^{5}\) の展開式における \(x^{5}\) の項の係数を求めよ。

一般項（多項定理）を書く

\(x^2\) を \(i\) 個、\(-1x\) を \(j\) 個、\(2\) を \(l\) 個とる（\(i+j+l=5\)）。係数は

\[\dfrac{5!}{i!\,j!\,l!}\,(x^2)^i(-1x)^j(2)^l\]

\(x^{5}\) になる組 \((i,j,l)\) を数え上げる

\(x\) の指数：\(2i+j=5\)、個数：\(i+j+l=5\) を同時に満たす非負整数の組は

\[(0,5,0),\ (1,3,1),\ (2,1,2)\]

各組の係数を計算する

\[\begin{aligned}(i,j,l)=(0,5,0):\ \dfrac{5!}{0!\,5!\,0!}\cdot 1^{0}(-1)^{5}(2)^{0}=-1\\ (i,j,l)=(1,3,1):\ \dfrac{5!}{1!\,3!\,1!}\cdot 1^{1}(-1)^{3}(2)^{1}=-40\\ (i,j,l)=(2,1,2):\ \dfrac{5!}{2!\,1!\,2!}\cdot 1^{2}(-1)^{1}(2)^{2}=-120\end{aligned}\]

合計する

\[(-1)+(-40)+(-120)=-161\]

【答案】

\[-161\]

答

(3)　\(\left(x^{2} + x - 2\right)^{4}\) の展開式における \(x^{4}\) の項の係数を求めよ。

一般項（多項定理）を書く

\(x^2\) を \(i\) 個、\(x\) を \(j\) 個、\(-2\) を \(l\) 個とる（\(i+j+l=4\)）。係数は

\[\dfrac{4!}{i!\,j!\,l!}\,(x^2)^i(1x)^j(-2)^l\]

\(x^{4}\) になる組 \((i,j,l)\) を数え上げる

\(x\) の指数：\(2i+j=4\)、個数：\(i+j+l=4\) を同時に満たす非負整数の組は

\[(0,4,0),\ (1,2,1),\ (2,0,2)\]

各組の係数を計算する

\[\begin{aligned}(i,j,l)=(0,4,0):\ \dfrac{4!}{0!\,4!\,0!}\cdot 1^{0}(1)^{4}(-2)^{0}=1\\ (i,j,l)=(1,2,1):\ \dfrac{4!}{1!\,2!\,1!}\cdot 1^{1}(1)^{2}(-2)^{1}=-24\\ (i,j,l)=(2,0,2):\ \dfrac{4!}{2!\,0!\,2!}\cdot 1^{2}(1)^{0}(-2)^{2}=24\end{aligned}\]

合計する

\[1+(-24)+24=1\]

【答案】

\[1\]
