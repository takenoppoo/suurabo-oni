別冊練習問題 5 の解答　点から平面への垂線の足

(1)　平面 \(\alpha:\ x + y + z=6\) と点 \(P\left(1,\ 1,\ 1\right)\) がある。\(P\) から \(\alpha\) に下ろした垂線の足 \(H\) の座標と、\(P\) と \(\alpha\) の距離を求めよ。

垂線の足を \(P\) から表す

平面の法線ベクトルは \(\vec n=\left(1,\ 1,\ 1\right)\)。\(H\) は \(P\) から \(\vec n\) 方向に進んだ点。

\[\overrightarrow{PH}=-t\,\vec n,\quad H=\left(- t + 1,\ - t + 1,\ - t + 1\right)\]

\(H\) が平面上にある条件

\[(- t + 1)+(- t + 1)+(- t + 1)=6\]\[3-3\,t=6\ \Rightarrow\ t=-1\]

\(H\) の座標と距離

\[H=\left(2,\ 2,\ 2\right)\]\[PH=|t|\,|\vec n|=1\times\sqrt{3}=\sqrt{3}\]

【答案】

\[H\left(2,\ 2,\ 2\right),\ \ \text{距離 }\sqrt{3}\]

(2)　平面 \(\alpha:\ 2 x + y - 2 z=6\) と点 \(P\left(1,\ 2,\ 3\right)\) がある。\(P\) から \(\alpha\) に下ろした垂線の足 \(H\) の座標と、\(P\) と \(\alpha\) の距離を求めよ。

垂線の足を \(P\) から表す

平面の法線ベクトルは \(\vec n=\left(2,\ 1,\ -2\right)\)。\(H\) は \(P\) から \(\vec n\) 方向に進んだ点。

\[\overrightarrow{PH}=-t\,\vec n,\quad H=\left(- 2 t + 1,\ - t + 2,\ 2 t + 3\right)\]

\(H\) が平面上にある条件

\[2(- 2 t + 1)+(- t + 2)+-2(2 t + 3)=6\]\[-2-9\,t=6\ \Rightarrow\ t=- \dfrac{8}{9}\]

\(H\) の座標と距離

\[H=\left(\dfrac{25}{9},\ \dfrac{26}{9},\ \dfrac{11}{9}\right)\]\[PH=|t|\,|\vec n|=\dfrac{8}{9}\times\sqrt{9}=\dfrac{8}{3}\]

【答案】

\[H\left(\dfrac{25}{9},\ \dfrac{26}{9},\ \dfrac{11}{9}\right),\ \ \text{距離 }\dfrac{8}{3}\]

答

(3)　平面 \(\alpha:\ x - y + 2 z=4\) と点 \(P\left(2,\ 0,\ -1\right)\) がある。\(P\) から \(\alpha\) に下ろした垂線の足 \(H\) の座標と、\(P\) と \(\alpha\) の距離を求めよ。

垂線の足を \(P\) から表す

平面の法線ベクトルは \(\vec n=\left(1,\ -1,\ 2\right)\)。\(H\) は \(P\) から \(\vec n\) 方向に進んだ点。

\[\overrightarrow{PH}=-t\,\vec n,\quad H=\left(- t + 2,\ t,\ - 2 t - 1\right)\]

\(H\) が平面上にある条件

\[(- t + 2)+-(t)+2(- 2 t - 1)=4\]\[0-6\,t=4\ \Rightarrow\ t=- \dfrac{2}{3}\]

\(H\) の座標と距離

\[H=\left(\dfrac{8}{3},\ - \dfrac{2}{3},\ \dfrac{1}{3}\right)\]\[PH=|t|\,|\vec n|=\dfrac{2}{3}\times\sqrt{6}=\dfrac{2 \sqrt{6}}{3}\]

【答案】

\[H\left(\dfrac{8}{3},\ - \dfrac{2}{3},\ \dfrac{1}{3}\right),\ \ \text{距離 }\dfrac{2 \sqrt{6}}{3}\]
