章末問題命題と条件・必要十分条件

例題1〜10で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. \(x\) は実数とする。 \(p:\ x>1\) は \(q:\ x^2>x\) であるための何条件か。
  2. 整数 \(n\) について、「\(n^2\) が4の倍数でないならば、\(n\) は奇数である」を証明せよ。
  3. \(\sqrt6\) が無理数であることを証明せよ。ただし、「整数 \(n\) について、\(n^2\) が偶数ならば \(n\) は偶数」は使ってよい。
  4. \(p:\ |x-2|<3,\quad q:\ x<a\) について \(,\ p\) が \(q\) の十分条件となる \(a\) の範囲を求めよ。
  5. \(a,\ b\) は実数とする。 \(p:\ (a-1)^2+(b-2)^2=0\) は \(q:\ a=1\) かつ \(b=2\) であるための何条件か。
  6. 命題「すべての実数 \(x\) について \(x^2+4x+1>0\)」の否定を述べ、元の命題と否定の真偽を答えよ。
  7. 命題「\(x^2=36\) ならば \(x=6\)」の逆・裏・対偶をつくり、それぞれの真偽を答えよ。
  8. \(\sqrt{3}+\sqrt{7}\) が無理数であることを、背理法で証明せよ。ただし \(\sqrt{21}\) が無理数であることは使ってよい。
  9. 整数 \(n\) について、「\(n^2\) が \(13\) の倍数ならば \(n\) は \(13\) の倍数である」ことを、対偶を利用して証明せよ。
  10. 実数 \(x\) についての条件 \(p:|x|<5\)、\(q:x<8\)、\(r:|x|<2\) について、\(p\) は \(q\) の何条件か、\(r\) は \(p\) の何条件かを答えよ。
