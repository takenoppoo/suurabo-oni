ホーム ＞ 数学III ＞ 導関数の計算

例題 1微分法　積の微分（多項式×指数関数）

\(y=(x^{2} + 2 x + 3)e^{2x}\) を微分せよ。

解き方（まず考え方）

\(\{fg\}'=f'g+fg'\)。\((e^{kx})'=ke^{kx}\) に注意して、\(e^{kx}\) をくくり出す。

コツ2つの要素の積は、片方ずつ動かして足す。

解答

STEP 1 積の微分
\[\{f(x)g(x)\}'=f'(x)g(x)+f(x)g'(x)\]
STEP 2 各部分を微分

\(u=x^{2} + 2 x + 3\)、\(v=e^{2x}\)。

\[u'=2 x + 2,\qquad v'=2e^{2x}\]
STEP 3 組み合わせる
\[y'=(2 x + 2)e^{2x}+(x^{2} + 2 x + 3)\cdot 2e^{2x}=\left(2 x^{2} + 6 x + 8\right)e^{2x}\]

【答案（テストに書く形）】

\[y'=\left(2 x^{2} + 6 x + 8\right)e^{2x}\]
