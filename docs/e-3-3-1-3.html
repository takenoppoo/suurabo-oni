例題 3積分法　部分積分（多項式×指数関数）

不定積分 \(\displaystyle\int(x + 1)e^{2x}\,dx\) を求めよ。

解き方（まず考え方）

\(\int fg'dx=fg-\int f'g\,dx\)。微分して簡単になる方（多項式）を \(f\)、積分しやすい方を \(g'\) にする。

コツ「微分でやせる方」と「積分してもふとらない方」に役を分ける。

解答

STEP 1 部分積分の公式
\[\int f g'\,dx=fg-\int f'g\,dx\]
STEP 2 \(f,g'\) を決める

\(f=x + 1\)、\(g'=e^{2x}\)（\(g=\dfrac{1}{2}e^{2x}\)）。多項式の方を \(f\) にして、微分で次数を下げる。

STEP 3 計算
\[\int(x + 1)e^{2x}dx=(x + 1)\cdot\dfrac{1}{2}e^{2x}-\int\dfrac{1}{2}e^{2x}dx\]\[=\left(\dfrac{x}{2} + \dfrac{1}{4}\right)\,e^{2x}+C\]

【答案（テストに書く形）】

\[\left(\dfrac{x}{2} + \dfrac{1}{4}\right)e^{2x}+C\]
