別冊練習問題 2 の解答　階差数列と一般項

(1)　数列 \(3,\ 6,\ 13,\ 24,\ 39,\ \cdots\) の一般項 \(a_n\) を求めよ。

階差数列を調べる

隣り合う項の差 \(b_n=a_{n+1}-a_n\) を求める。

\[b_1=3,\ b_2=7,\ b_3=11,\ b_4=15\]

公差 \(4\) の等差数列だから

\[b_n=3+(n-1)\times\left(4\right)=4 n - 1\]

公式を使う

\(n\geqq2\) のとき

\[a_n=a_1+\sum_{k=1}^{n-1}b_k=3+\sum_{k=1}^{n-1}\left(4 k - 1\right)\]

Σを計算する

\[=3+\left(4\right)\cdot\dfrac{(n-1)n}{2}+\left(-1\right)(n-1)=2 n^{2} - 3 n + 4\]

\(n=1\) のとき

\(a_1=3\) で、与えられた初項 \(a_1=3\) と一致するので、\(n=1\) でも成り立つ。

【答案】

\[a_n=2 n^{2} - 3 n + 4\]

答

(2)　数列 \(2,\ 6,\ 11,\ 17,\ 24,\ \cdots\) の一般項 \(a_n\) を求めよ。

階差数列を調べる

隣り合う項の差 \(b_n=a_{n+1}-a_n\) を求める。

\[b_1=4,\ b_2=5,\ b_3=6,\ b_4=7\]

公差 \(1\) の等差数列だから

\[b_n=4+(n-1)\times\left(1\right)=n + 3\]

公式を使う

\(n\geqq2\) のとき

\[a_n=a_1+\sum_{k=1}^{n-1}b_k=2+\sum_{k=1}^{n-1}\left(k + 3\right)\]

Σを計算する

\[=2+\left(1\right)\cdot\dfrac{(n-1)n}{2}+\left(3\right)(n-1)=\dfrac{n^{2}}{2} + \dfrac{5 n}{2} - 1\]

\(n=1\) のとき

\(a_1=2\) で、与えられた初項 \(a_1=2\) と一致するので、\(n=1\) でも成り立つ。

【答案】

\[a_n=\dfrac{n^{2}}{2} + \dfrac{5 n}{2} - 1\]

答

(3)　数列 \(5,\ 6,\ 10,\ 17,\ 27,\ \cdots\) の一般項 \(a_n\) を求めよ。

階差数列を調べる

隣り合う項の差 \(b_n=a_{n+1}-a_n\) を求める。

\[b_1=1,\ b_2=4,\ b_3=7,\ b_4=10\]

公差 \(3\) の等差数列だから

\[b_n=1+(n-1)\times\left(3\right)=3 n - 2\]

公式を使う

\(n\geqq2\) のとき

\[a_n=a_1+\sum_{k=1}^{n-1}b_k=5+\sum_{k=1}^{n-1}\left(3 k - 2\right)\]

Σを計算する

\[=5+\left(3\right)\cdot\dfrac{(n-1)n}{2}+\left(-2\right)(n-1)=\dfrac{3 n^{2}}{2} - \dfrac{7 n}{2} + 7\]

\(n=1\) のとき

\(a_1=5\) で、与えられた初項 \(a_1=5\) と一致するので、\(n=1\) でも成り立つ。

【答案】

\[a_n=\dfrac{3 n^{2}}{2} - \dfrac{7 n}{2} + 7\]
