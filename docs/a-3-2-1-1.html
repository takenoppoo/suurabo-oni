別冊練習問題 1 の解答　積の微分（多項式×指数関数）

(1)　\(y=(2 x^{2} - x + 1)e^{3x}\) を微分せよ。

積の微分

\[\{f(x)g(x)\}'=f'(x)g(x)+f(x)g'(x)\]

各部分を微分

\(u=2 x^{2} - x + 1\)、\(v=e^{3x}\)。

\[u'=4 x - 1,\qquad v'=3e^{3x}\]

組み合わせる

\[y'=(4 x - 1)e^{3x}+(2 x^{2} - x + 1)\cdot 3e^{3x}=\left(6 x^{2} + x + 2\right)e^{3x}\]

【答案】

\[y'=\left(6 x^{2} + x + 2\right)e^{3x}\]

答

(2)　\(y=(x^{2} - 4)e^{-3x}\) を微分せよ。

積の微分

\[\{f(x)g(x)\}'=f'(x)g(x)+f(x)g'(x)\]

各部分を微分

\(u=x^{2} - 4\)、\(v=e^{-3x}\)。

\[u'=2 x,\qquad v'=-3e^{-3x}\]

組み合わせる

\[y'=(2 x)e^{-3x}+(x^{2} - 4)\cdot -3e^{-3x}=\left(- 3 x^{2} + 2 x + 12\right)e^{-3x}\]

【答案】

\[y'=\left(- 3 x^{2} + 2 x + 12\right)e^{-3x}\]

答

(3)　\(y=(3 x^{2} + x)e^{2x}\) を微分せよ。

積の微分

\[\{f(x)g(x)\}'=f'(x)g(x)+f(x)g'(x)\]

各部分を微分

\(u=3 x^{2} + x\)、\(v=e^{2x}\)。

\[u'=6 x + 1,\qquad v'=2e^{2x}\]

組み合わせる

\[y'=(6 x + 1)e^{2x}+(3 x^{2} + x)\cdot 2e^{2x}=\left(6 x^{2} + 8 x + 1\right)e^{2x}\]

【答案】

\[y'=\left(6 x^{2} + 8 x + 1\right)e^{2x}\]
