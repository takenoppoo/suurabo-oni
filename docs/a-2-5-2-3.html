別冊練習問題 3 の解答　放物線とx軸で囲まれた面積

(1)　放物線 \(y=x^{2} - 2 x - 3\) と \(x\) 軸で囲まれた部分の面積 \(S\) を求めよ。

\(x\) 軸との交点を求める

\[x^{2} - 2 x - 3=0\ \Rightarrow\ \left(x - 3\right) \left(x + 1\right)=0\ \Rightarrow\ x=-1,\ 3\]

上下関係を調べる

\(-1\leqq x\leqq 3\) では曲線は \(x\) 軸の下側。例：\(x=1\) で \(y=-4\)。

面積を定積分で表す

面積 = （上）−（下）= \(0-f(x)\)。

\[S=\int_{-1}^{3}\left(- x^{2} + 2 x + 3\right)dx\]

計算する

\[S=\Big[- \dfrac{x^{3}}{3} + x^{2} + 3 x\Big]_{-1}^{3}=9-\left(- \dfrac{5}{3}\right)=\dfrac{32}{3}\]

【答案】

\[S=\dfrac{32}{3}\]

答

(2)　放物線 \(y=- x^{2} + 2 x + 3\) と \(x\) 軸で囲まれた部分の面積 \(S\) を求めよ。

\(x\) 軸との交点を求める

\[- x^{2} + 2 x + 3=0\ \Rightarrow\ - \left(x - 3\right) \left(x + 1\right)=0\ \Rightarrow\ x=-1,\ 3\]

上下関係を調べる

\(-1\leqq x\leqq 3\) では曲線は \(x\) 軸の上側。例：\(x=1\) で \(y=4\)。

面積を定積分で表す

面積 = （上）−（下）= \(f(x)-0\)。

\[S=\int_{-1}^{3}\left(- x^{2} + 2 x + 3\right)dx\]

計算する

\[S=\Big[- \dfrac{x^{3}}{3} + x^{2} + 3 x\Big]_{-1}^{3}=9-\left(- \dfrac{5}{3}\right)=\dfrac{32}{3}\]

【答案】

\[S=\dfrac{32}{3}\]

答

(3)　放物線 \(y=- 2 x^{2} + 8 x\) と \(x\) 軸で囲まれた部分の面積 \(S\) を求めよ。

\(x\) 軸との交点を求める

\[- 2 x^{2} + 8 x=0\ \Rightarrow\ - 2 x \left(x - 4\right)=0\ \Rightarrow\ x=0,\ 4\]

上下関係を調べる

\(0\leqq x\leqq 4\) では曲線は \(x\) 軸の上側。例：\(x=2\) で \(y=8\)。

面積を定積分で表す

面積 = （上）−（下）= \(f(x)-0\)。

\[S=\int_{0}^{4}\left(- 2 x^{2} + 8 x\right)dx\]

計算する

\[S=\Big[- \dfrac{2 x^{3}}{3} + 4 x^{2}\Big]_{0}^{4}=\dfrac{64}{3}-\left(0\right)=\dfrac{64}{3}\]

【答案】

\[S=\dfrac{64}{3}\]
