ホーム ＞ 数学A ＞ 場合の数（順列・組合せ）

例題 1場合の数と確率　条件つきで整数をつくる個数

0, 1, 2, 3, 4, 5 の6個の数字から異なる4個を選んで並べてできる4桁の整数のうち、偶数は何個あるか。

解き方（まず考え方）

『偶数＝一の位が 0, 2, 4』という条件と『千の位は 0 にできない』という条件が重なる。条件のきびしい位から決めるが、一の位が 0 かどうかで千の位の選び方が変わるので、一の位で場合分けする。

コツきびしい条件（一の位・千の位）を先に決め、場合分けで数え漏れ・重なりをなくす。

解答

STEP 1 一の位が 0 のとき
千・百・十の位は、残りの5個から3個を並べる。 \[5\times4\times3=60\ (\text{個})\]
STEP 2 一の位が 2 または 4 のとき（2通り）
一の位を決める：2通り。千の位は 0 と一の位に使った数字を除く \(6-2=4\) 通り。百の位は残り4個から4通り、十の位は3通り。 \[2\times4\times4\times3=96\ (\text{個})\]
STEP 3 合計
\[60+96=156\ (\text{個})\]

【答案（テストに書く形）】

\[156\ \text{個}\]
