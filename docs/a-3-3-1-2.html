別冊練習問題 2 の解答　分子が分母の導関数になる積分

(1)　不定積分 \(\displaystyle\int\dfrac{4 x + 6}{x^{2} + 3 x + 1}\,dx\) を求めよ。

分子と分母の関係

分母 \(g(x)=x^{2} + 3 x + 1\) の導関数は \(g'(x)=2 x + 3\)。分子はその \(2\) 倍。

公式

\[\int\dfrac{g'(x)}{g(x)}dx=\log|g(x)|+C\]

積分

\[\int\dfrac{4 x + 6}{x^{2} + 3 x + 1}dx=2\int\dfrac{2 x + 3}{x^{2} + 3 x + 1}dx=2\log(x^{2} + 3 x + 1)+C\]

【答案】

\[2\log(x^{2} + 3 x + 1)+C\]

答

(2)　不定積分 \(\displaystyle\int\dfrac{6 x + 12}{x^{2} + 4 x + 1}\,dx\) を求めよ。

分子と分母の関係

分母 \(g(x)=x^{2} + 4 x + 1\) の導関数は \(g'(x)=2 x + 4\)。分子はその \(3\) 倍。

公式

\[\int\dfrac{g'(x)}{g(x)}dx=\log|g(x)|+C\]

積分

\[\int\dfrac{6 x + 12}{x^{2} + 4 x + 1}dx=3\int\dfrac{2 x + 4}{x^{2} + 4 x + 1}dx=3\log(x^{2} + 4 x + 1)+C\]

【答案】

\[3\log(x^{2} + 4 x + 1)+C\]

答

(3)　不定積分 \(\displaystyle\int\dfrac{3 x + 3}{x^{2} + 2 x + 1}\,dx\) を求めよ。

分子と分母の関係

分母 \(g(x)=x^{2} + 2 x + 1\) の導関数は \(g'(x)=2 x + 2\)。分子はその \(\dfrac{3}{2}\) 倍。

公式

\[\int\dfrac{g'(x)}{g(x)}dx=\log|g(x)|+C\]

積分

\[\int\dfrac{3 x + 3}{x^{2} + 2 x + 1}dx=\dfrac{3}{2}\int\dfrac{2 x + 2}{x^{2} + 2 x + 1}dx=\dfrac{3}{2}\log(x^{2} + 2 x + 1)+C\]

【答案】

\[\dfrac{3}{2}\log(x^{2} + 2 x + 1)+C\]
