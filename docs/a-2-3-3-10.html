ホーム ＞ 数学II ＞ 三角関数の方程式・不等式・最大最小

別冊練習問題 10 の解答　sinθ+cosθ=t の置き換え（sinθcosθ を含む）

(1)　\(0\leqq\theta<2\pi\) のとき、\(y=\sin\theta+\cos\theta+2\sin\theta\cos\theta\) の最大値と最小値を求めよ。

置き換え

\(t=\sin\theta+\cos\theta=\sqrt2\sin\left(\theta+\dfrac\pi4\right)\) より \(-\sqrt2\leqq t\leqq\sqrt2\)。

\(\sin\theta\cos\theta=\dfrac{t^2-1}{2}\)。

\(t\) の関数

\[y=t^{2} + t - 1=t^{2} + t - 1\]

最大・最小

\[\text{最大 }1 + \sqrt{2},\qquad \text{最小 }- \dfrac{5}{4}\]

【答案】

\[\text{最大 }1 + \sqrt{2},\ \text{最小 }- \dfrac{5}{4}\]

答

(2)　\(0\leqq\theta<2\pi\) のとき、\(y=\sin\theta+\cos\theta-1\sin\theta\cos\theta\) の最大値と最小値を求めよ。

置き換え

\(t=\sin\theta+\cos\theta=\sqrt2\sin\left(\theta+\dfrac\pi4\right)\) より \(-\sqrt2\leqq t\leqq\sqrt2\)。

\(\sin\theta\cos\theta=\dfrac{t^2-1}{2}\)。

\(t\) の関数

\[y=- \dfrac{t^{2}}{2} + t + \dfrac{1}{2}=- \dfrac{t^{2}}{2} + t + \dfrac{1}{2}\]

最大・最小

\[\text{最大 }1,\qquad \text{最小 }- \sqrt{2} - \dfrac{1}{2}\]

【答案】

\[\text{最大 }1,\ \text{最小 }- \sqrt{2} - \dfrac{1}{2}\]

答

(3)　\(0\leqq\theta<2\pi\) のとき、\(y=\sin\theta+\cos\theta+3\sin\theta\cos\theta\) の最大値と最小値を求めよ。

置き換え

\(t=\sin\theta+\cos\theta=\sqrt2\sin\left(\theta+\dfrac\pi4\right)\) より \(-\sqrt2\leqq t\leqq\sqrt2\)。

\(\sin\theta\cos\theta=\dfrac{t^2-1}{2}\)。

\(t\) の関数

\[y=\dfrac{3 t^{2}}{2} + t - \dfrac{3}{2}=\dfrac{3 t^{2}}{2} + t - \dfrac{3}{2}\]

最大・最小

\[\text{最大 }\sqrt{2} + \dfrac{3}{2},\qquad \text{最小 }- \dfrac{5}{3}\]

【答案】

\[\text{最大 }\sqrt{2} + \dfrac{3}{2},\ \text{最小 }- \dfrac{5}{3}\]
