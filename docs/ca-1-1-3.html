1.　\(\sqrt{5+2\sqrt6}+\sqrt{5-2\sqrt6}\ \text{を計算せよ。}\)

6の約数の組 \((1,6),\ (2,3)\) のうち足して5になるのは \(2+3=5\)。

\[\sqrt{5+2\sqrt6}=\sqrt3+\sqrt2\]\[\sqrt{5-2\sqrt6}=\sqrt3-\sqrt2\]

（\(\sqrt3>\sqrt2\) なので引く向きに注意）

\[(\sqrt3+\sqrt2)+(\sqrt3-\sqrt2)=2\sqrt3\]

（例題1の型）

【答案】

\[2\sqrt3\]

答

2.　\(x=\dfrac{\sqrt3-\sqrt2}{\sqrt3+\sqrt2},\ y=\dfrac{\sqrt3+\sqrt2}{\sqrt3-\sqrt2}\ \text{のとき},\ x^2+y^2,\ x^3+y^3\ \text{を求めよ。}\)

\(x=\dfrac{(\sqrt3-\sqrt2)^2}{3-2}=3-2\sqrt6+2=5-2\sqrt6\)、\(y=\dfrac{(\sqrt3+\sqrt2)^2}{3-2}=5+2\sqrt6\)。

\[x+y=10,\qquad xy=25-24=1\]\[x^2+y^2=10^2-2\cdot1=98\]\[x^3+y^3=10^3-3\cdot1\cdot10=1000-30=970\]

（例題2の型）

【答案】

\[x^2+y^2=98,\ \ x^3+y^3=970\]

答

3.　\(x=\dfrac{\sqrt5-1}2\) のとき \(,\ x^2+x-1\) の値と \(,\ \dfrac1x\) の整数部分を求めよ。

\(x^2=\dfrac{(\sqrt5-1)^2}4=\dfrac{6-2\sqrt5}4=\dfrac{3-\sqrt5}2\)。

\[x^2+x-1=\dfrac{3-\sqrt5}2+\dfrac{\sqrt5-1}2-1=\dfrac22-1=0\]

\(\dfrac1x=\dfrac2{\sqrt5-1}=\dfrac{2(\sqrt5+1)}{5-1}=\dfrac{\sqrt5+1}2\)。\(2.2<\sqrt5<2.3\) より \(1.6<\dfrac{\sqrt5+1}2<1.65\)。整数部分は1。

（例題3の型）

【答案】

\[x^2+x-1=0,\ \text{整数部分は}\ 1\]

答

4.　\(2|x-1|+|x-4|=7\ \text{を解け。}\)

境目は \(x=1,\ 4\)。

① \(x<1\)：\(-2(x-1)-(x-4)=7\) → \(-3x+6=7\) → \(x=-\dfrac13\)（\(x<1\) をみたす）。

② \(1\leqq x<4\)：\(2(x-1)-(x-4)=7\) → \(x+2=7\) → \(x=5\)（範囲外）。

③ \(x\geqq4\)：\(2(x-1)+(x-4)=7\) → \(3x-6=7\) → \(x=\dfrac{13}3\)（\(x\geqq4\) をみたす）。

（例題4の型）

【答案】

\[x=-\dfrac13,\ \dfrac{13}3\]

答

5.　\((a+b\sqrt2)^2=17+12\sqrt2\) をみたす正の有理数 \(a,\ b\) を求めよ。

展開：

\[(a^2+2b^2)+2ab\sqrt2=17+12\sqrt2\]

係数を比べて \(a^2+2b^2=17\ \cdots①\)、\(ab=6\ \cdots②\)。

②より \(b=\dfrac6a\)。①に代入して

\[a^2+\dfrac{72}{a^2}=17\ \Rightarrow\ a^4-17a^2+72=0\ \Rightarrow\ (a^2-8)(a^2-9)=0\]

\(a^2=8\) だと \(a=2\sqrt2\) は無理数なので不適。\(a^2=9\) より \(a=3\)、\(b=2\)。

\[(3+2\sqrt2)^2=9+12\sqrt2+8=17+12\sqrt2\]

（例題5の型）

【答案】

\[a=3,\ b=2\]

答

6.　\(x=\dfrac{\sqrt{5}+\sqrt{2}}{\sqrt{5}-\sqrt{2}},\ y=\dfrac{\sqrt{5}-\sqrt{2}}{\sqrt{5}+\sqrt{2}}\) のとき、\(x^2+y^2\) の値を求めよ。

\(x\) を有理化

分母・分子に \(\sqrt{5}+\sqrt{2}\) をかける。

\[x=\dfrac{(\sqrt{5}+\sqrt{2})^2}{5-2}=\dfrac{2 \sqrt{10} + 7}{3}=\dfrac{2 \sqrt{10} + 7}{3}\]

\(y=\dfrac1x\) も同様

\(y=\dfrac{\sqrt{5}-\sqrt{2}}{\sqrt{5}+\sqrt{2}}=\dfrac{- 2 \sqrt{10} + 7}{3}\)。

\(x+y,\ xy\) から値を出す

\(x+y=\dfrac{14}{3},\ \ xy=1\)。

\[x^2+y^2=(x+y)^2-2xy=\dfrac{14}{3}^2-2=\dfrac{178}{9}\]

（例題6の型）

【答案】

\[\dfrac{178}{9}\]

答

7.　不等式 \(|x+2|+|x-1|<5\) を解け。

場合分けの境目

\(x=-2,\ 1\) を境に3つに分ける。

3つの場合

\(x<-2\)：左辺 \(-(x+2)-(x-1)=- 2 x - 1\)。\(- 2 x - 1<5\) より \(x>-3\)（\(x<-2\) との共通部分あり）。

\(-2\leqq x<1\)：左辺 \(3\) は一定で \(3<5\) 常に成立。

\(x\geqq 1\)：左辺 \(2 x + 1\)。\(2 x + 1<5\) より \(x<2\)。

合わせる

\[-3<x<2\]

（例題7の型）

【答案】

\[-3<x<2\]

答

8.　\(f(x)=|x+3|+|x-0|+|x-4|\) の最小値と、そのときの \(x\) を求めよ。

数直線で考える

\(|x+3|\) は \(x\) と \(-3\) の距離。\(f(x)\) は点 \(x\) から3点 \(-3,\ 0,\ 4\) までの距離の和。

両端の2点の距離の和は一定

\(x\) が \(-3\leqq x\leqq 4\) にあれば \(|x+3|+|x-4|=7\)（一定）。

真ん中の点を足す

残りの \(|x-0|\) は \(x=0\) のとき最小値 0。

\[f(0)=3+4=7\]

（例題8の型）

【答案】

\[x=0\ \text{のとき最小値 }7\]

答

9.　自然数 \(n\) で、\(\sqrt{\dfrac{1000}{n}}\) が自然数となるものをすべて求めよ。

素因数分解する

\(1000=2^{3}\times5^{3}\)。

\(\dfrac{%d}{n}\) が平方数になる条件

各素因数の指数がすべて偶数になるように \(n\) で割る。

\[n=10,\ 40,\ 250,\ 1000\]

個数・最大

条件をみたす \(n\) は \(4\) 個。最大は \(1000\)。

（例題9の型）

【答案】

\[n=10,\ 40,\ 250,\ 1000\]

答

10.　\(\dfrac1{\sqrt1+\sqrt2}+\dfrac1{\sqrt2+\sqrt3}+\cdots+\dfrac1{\sqrt{100}+\sqrt{101}}\) の値を求めよ。

各項を有理化

\(\dfrac1{\sqrt k+\sqrt{k+1}}=\dfrac{\sqrt{k+1}-\sqrt k}{(k+1)-k}=\sqrt{k+1}-\sqrt k\)。

並べて消える

\[(\sqrt2-\sqrt1)+(\sqrt3-\sqrt2)+\cdots+(\sqrt{101}-\sqrt{100})\]

残る項

\[=\sqrt{101}-1=-1 + \sqrt{101}\]

（例題10の型）

【答案】

\[-1 + \sqrt{101}\]
