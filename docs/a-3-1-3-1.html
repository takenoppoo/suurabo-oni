ホーム ＞ 数学III ＞ 関数の極限・連続

別冊練習問題 1 の解答　0/0 の不定形（約分）

(1)　次の極限値を求めよ。 \[\lim_{x\to3}\dfrac{2 x^{2} - 7 x + 3}{x^{2} - x - 6}\]

0/0 の不定形

\(x\to3\) で分母・分子とも 0。共通因数 \(x-3\) をくくり出す。

約分する

\[\dfrac{2 x^{2} - 7 x + 3}{x^{2} - x - 6}=\dfrac{(x - 3)(2 x - 1)}{(x - 3)(x + 2)}=\dfrac{2 x - 1}{x + 2}\quad(x\neq3)\]

代入する

\[\lim_{x\to3}\dfrac{2 x - 1}{x + 2}=\dfrac{5}{5}=1\]

【答案】

\[1\]

答

(2)　次の極限値を求めよ。 \[\lim_{x\to1}\dfrac{4 x^{2} - x - 3}{x^{2} + x - 2}\]

0/0 の不定形

\(x\to1\) で分母・分子とも 0。共通因数 \(x-1\) をくくり出す。

約分する

\[\dfrac{4 x^{2} - x - 3}{x^{2} + x - 2}=\dfrac{(x - 1)(4 x + 3)}{(x - 1)(x + 2)}=\dfrac{4 x + 3}{x + 2}\quad(x\neq1)\]

代入する

\[\lim_{x\to1}\dfrac{4 x + 3}{x + 2}=\dfrac{7}{3}=\dfrac{7}{3}\]

【答案】

\[\dfrac{7}{3}\]

答

(3)　次の極限値を求めよ。 \[\lim_{x\to-1}\dfrac{5 x^{2} + 7 x + 2}{x^{2} + 4 x + 3}\]

0/0 の不定形

\(x\to-1\) で分母・分子とも 0。共通因数 \(x+1\) をくくり出す。

約分する

\[\dfrac{5 x^{2} + 7 x + 2}{x^{2} + 4 x + 3}=\dfrac{(x + 1)(5 x + 2)}{(x + 1)(x + 3)}=\dfrac{5 x + 2}{x + 3}\quad(x\neq-1)\]

代入する

\[\lim_{x\to-1}\dfrac{5 x + 2}{x + 3}=\dfrac{-3}{2}=- \dfrac{3}{2}\]

【答案】

\[- \dfrac{3}{2}\]

答
