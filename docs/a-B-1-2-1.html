別冊練習問題 1 の解答　Σの公式と計算

(1)　次の和を \(n\) の式で表せ（因数分解した形で答えよ）。 \[\sum_{k=1}^{n}\left(6 k^{2} + 3 k - 2\right)\]

公式を使えるように分ける

\(\sum_{k=1}^n k^2=\dfrac{n(n+1)(2n+1)}6,\ \ \sum_{k=1}^n k=\dfrac{n(n+1)}2,\ \ \sum_{k=1}^n c=cn\)。

公式に代入する

\[\sum_{k=1}^n\left(6 k^{2} + 3 k - 2\right)=6\cdot\dfrac{n(n+1)(2n+1)}{6}+3\cdot\dfrac{n(n+1)}{2}-2\,n\]

共通因数でくくる

\(n\) を くくり、通分して整理する。

\[=\dfrac{n \left(4 n^{2} + 9 n + 1\right)}{2}\]

【答案】

\[\dfrac{n \left(4 n^{2} + 9 n + 1\right)}{2}\]

答

(2)　次の和を \(n\) の式で表せ（因数分解した形で答えよ）。 \[\sum_{k=1}^{n}\left(2 k^{2} - 3 k + 1\right)\]

公式を使えるように分ける

\(\sum_{k=1}^n k^2=\dfrac{n(n+1)(2n+1)}6,\ \ \sum_{k=1}^n k=\dfrac{n(n+1)}2,\ \ \sum_{k=1}^n c=cn\)。

公式に代入する

\[\sum_{k=1}^n\left(2 k^{2} - 3 k + 1\right)=2\cdot\dfrac{n(n+1)(2n+1)}{6}-3\cdot\dfrac{n(n+1)}{2}+1\,n\]

共通因数でくくる

\(n\) を くくり、通分して整理する。

\[=\dfrac{n \left(n - 1\right) \left(4 n + 1\right)}{6}\]

【答案】

\[\dfrac{n \left(n - 1\right) \left(4 n + 1\right)}{6}\]

答

(3)　次の和を \(n\) の式で表せ（因数分解した形で答えよ）。 \[\sum_{k=1}^{n}\left(12 k^{2} - 6 k\right)\]

公式を使えるように分ける

\(\sum_{k=1}^n k^2=\dfrac{n(n+1)(2n+1)}6,\ \ \sum_{k=1}^n k=\dfrac{n(n+1)}2,\ \ \sum_{k=1}^n c=cn\)。

公式に代入する

\[\sum_{k=1}^n\left(12 k^{2} - 6 k\right)=12\cdot\dfrac{n(n+1)(2n+1)}{6}-6\cdot\dfrac{n(n+1)}{2}\]

共通因数でくくる

\(n\) を くくり、通分して整理する。

\[=n \left(n + 1\right) \left(4 n - 1\right)\]

【答案】

\[n \left(n + 1\right) \left(4 n - 1\right)\]

答
