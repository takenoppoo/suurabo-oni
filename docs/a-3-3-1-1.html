ホーム ＞ 数学III ＞ 不定積分・置換積分・部分積分

別冊練習問題 1 の解答　置換積分（累乗の形）

(1)　不定積分 \(\displaystyle\int 3x(x^{2} + 2)^{4}\,dx\) を求めよ。

置換を決める

\(u=x^{2} + 2\) とおいて両辺を \(x\) で微分する。

\[\dfrac{du}{dx}=2x\ \Rightarrow\ du=2x\,dx\]

積分の中にある \(x\,dx\) をそのまま使えるよう、両辺を2でわる。

\[x\,dx=\dfrac12\,du\]

\(u\) で書きかえる

\(x^2+2\) を \(u\)、\(x\,dx\) を \(\dfrac12du\) に置きかえる。

\[\int 3\left(x^{2} + 2\right)^{4}\,x\,dx=3\int \left(x^{2} + 2\right)^{4}\cdot x\,dx\]\[=3\int u^{4}\cdot\dfrac12\,du=\dfrac{3}{2}\int u^{4}\,du\]

\(u\) で積分

\(\int u^{n}du=\dfrac{u^{n+1}}{n+1}\) を使う。

\[\dfrac{3}{2}\cdot\dfrac{u^{5}}{5}+C=\dfrac{3}{10}u^{5}+C\]

\(x\) に戻す

\(u=x^{2} + 2\) を戻す。

\[=\dfrac{3}{10}\left(x^{2} + 2\right)^{5}+C\]

検算（微分して確かめる）

\[\left\{\dfrac{3}{10}\left(x^{2} + 2\right)^{5}\right\}'=\dfrac{3}{10}\cdot5\left(x^{2} + 2\right)^{4}\cdot2x=3x\left(x^{2} + 2\right)^{4}\]

【答案】

\[\dfrac{3}{10}(x^{2} + 2)^{5}+C\]

答

(2)　不定積分 \(\displaystyle\int 6x(x^{2} + 3)^{2}\,dx\) を求めよ。

置換を決める

\(u=x^{2} + 3\) とおいて両辺を \(x\) で微分する。

\[\dfrac{du}{dx}=2x\ \Rightarrow\ du=2x\,dx\]

積分の中にある \(x\,dx\) をそのまま使えるよう、両辺を2でわる。

\[x\,dx=\dfrac12\,du\]

\(u\) で書きかえる

\(x^2+3\) を \(u\)、\(x\,dx\) を \(\dfrac12du\) に置きかえる。

\[\int 6\left(x^{2} + 3\right)^{2}\,x\,dx=6\int \left(x^{2} + 3\right)^{2}\cdot x\,dx\]\[=6\int u^{2}\cdot\dfrac12\,du=3\int u^{2}\,du\]

\(u\) で積分

\(\int u^{n}du=\dfrac{u^{n+1}}{n+1}\) を使う。

\[3\cdot\dfrac{u^{3}}{3}+C=u^{3}+C\]

\(x\) に戻す

\(u=x^{2} + 3\) を戻す。

\[=\left(x^{2} + 3\right)^{3}+C\]

検算（微分して確かめる）

\[\left\{\left(x^{2} + 3\right)^{3}\right\}'=1\cdot3\left(x^{2} + 3\right)^{2}\cdot2x=6x\left(x^{2} + 3\right)^{2}\]

【答案】

\[(x^{2} + 3)^{3}+C\]

答

(3)　不定積分 \(\displaystyle\int 4x(x^{2} + 1)^{5}\,dx\) を求めよ。

置換を決める

\(u=x^{2} + 1\) とおいて両辺を \(x\) で微分する。

\[\dfrac{du}{dx}=2x\ \Rightarrow\ du=2x\,dx\]

積分の中にある \(x\,dx\) をそのまま使えるよう、両辺を2でわる。

\[x\,dx=\dfrac12\,du\]

\(u\) で書きかえる

\(x^2+1\) を \(u\)、\(x\,dx\) を \(\dfrac12du\) に置きかえる。

\[\int 4\left(x^{2} + 1\right)^{5}\,x\,dx=4\int \left(x^{2} + 1\right)^{5}\cdot x\,dx\]\[=4\int u^{5}\cdot\dfrac12\,du=2\int u^{5}\,du\]

\(u\) で積分

\(\int u^{n}du=\dfrac{u^{n+1}}{n+1}\) を使う。

\[2\cdot\dfrac{u^{6}}{6}+C=\dfrac{1}{3}u^{6}+C\]

\(x\) に戻す

\(u=x^{2} + 1\) を戻す。

\[=\dfrac{1}{3}\left(x^{2} + 1\right)^{6}+C\]

検算（微分して確かめる）

\[\left\{\dfrac{1}{3}\left(x^{2} + 1\right)^{6}\right\}'=\dfrac{1}{3}\cdot6\left(x^{2} + 1\right)^{5}\cdot2x=4x\left(x^{2} + 1\right)^{5}\]

【答案】

\[\dfrac{1}{3}(x^{2} + 1)^{6}+C\]
