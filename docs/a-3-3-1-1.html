ホーム ＞ 数学III ＞ 不定積分・置換積分・部分積分

別冊練習問題 1 の解答　置換積分（累乗の形）

(1)　不定積分 \(\displaystyle\int 3x(x^{2} + 2)^{4}\,dx\) を求めよ。

置換を決める

\(u=x^{2} + 2\) とおくと \(du=2x\,dx\)、すなわち \(x\,dx=\dfrac12du\)。

\(u\) で積分

\[\int 3 x(x^{2} + 2)^{4}dx=3\int u^{4}\cdot\dfrac12du=\dfrac{3}{2}\cdot\dfrac{u^{5}}{5}+C\]

\(x\) に戻す

\[=\dfrac{3}{10}(x^{2} + 2)^{5}+C\]

【答案】

\[\dfrac{3}{10}(x^{2} + 2)^{5}+C\]

答

(2)　不定積分 \(\displaystyle\int 6x(x^{2} + 3)^{2}\,dx\) を求めよ。

置換を決める

\(u=x^{2} + 3\) とおくと \(du=2x\,dx\)、すなわち \(x\,dx=\dfrac12du\)。

\(u\) で積分

\[\int 6 x(x^{2} + 3)^{2}dx=6\int u^{2}\cdot\dfrac12du=3\cdot\dfrac{u^{3}}{3}+C\]

\(x\) に戻す

\[=(x^{2} + 3)^{3}+C\]

【答案】

\[1(x^{2} + 3)^{3}+C\]

答

(3)　不定積分 \(\displaystyle\int 4x(x^{2} + 1)^{5}\,dx\) を求めよ。

置換を決める

\(u=x^{2} + 1\) とおくと \(du=2x\,dx\)、すなわち \(x\,dx=\dfrac12du\)。

\(u\) で積分

\[\int 4 x(x^{2} + 1)^{5}dx=4\int u^{5}\cdot\dfrac12du=2\cdot\dfrac{u^{6}}{6}+C\]

\(x\) に戻す

\[=\dfrac{1}{3}(x^{2} + 1)^{6}+C\]

【答案】

\[\dfrac{1}{3}(x^{2} + 1)^{6}+C\]
