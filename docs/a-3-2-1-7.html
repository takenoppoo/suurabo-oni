別冊練習問題 7 の解答　陰関数の微分と接線

(1)　楕円 \(\dfrac{x^2}{16}+\dfrac{y^2}{4}=1\) 上の点 \(\left(2,\ 1.73205080756888\right)\) における接線の方程式を、陰関数の微分で求めよ。

両辺を \(x\) で微分

\[\dfrac{2x}{16}+\dfrac{2y}{4}\cdot\dfrac{dy}{dx}=0\]

\(\dfrac{dy}{dx}\)

\[\dfrac{dy}{dx}=-\dfrac{4x}{16y}\]

接線

\((2,\ 1.73205080756888)\) で傾き \(-0.288675134594813\)。

\[y=- 0.288675134594813 x + 2.3094010767585\]

【答案】

\[y=- 0.288675134594813 x + 2.3094010767585\]

答

(2)　楕円 \(\dfrac{x^2}{25}+\dfrac{y^2}{16}=1\) 上の点 \(\left(3,\ 3.2\right)\) における接線の方程式を、陰関数の微分で求めよ。

両辺を \(x\) で微分

\[\dfrac{2x}{25}+\dfrac{2y}{16}\cdot\dfrac{dy}{dx}=0\]

\(\dfrac{dy}{dx}\)

\[\dfrac{dy}{dx}=-\dfrac{16x}{25y}\]

接線

\((3,\ 3.2)\) で傾き \(-0.6\)。

\[y=- 0.6 x + 5.0\]

【答案】

\[y=- 0.6 x + 5.0\]

答
