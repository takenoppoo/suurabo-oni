ホーム ＞ 数学II ＞ 整式の割り算・分数式

例題 6いろいろな式　4次式を2次式で割る筆算

\(2 x^{4} - 3 x^{3} + x - 5\) を \(x^{2} - x + 2\) で割ったときの商と余りを求めよ。

解き方（まず考え方）

降べきの順に並べ、欠けている次数は 0 で補って筆算。余りの次数が割る式より小さくなったら終了。

コツ大きい項から順に消していく。

解答

STEP 1 筆算の要領で割る

最高次の項どうしを割って商を立て、引く操作をくり返す（次数が \(Q\) より下がるまで）。

STEP 2 商と余り
\[\text{商 }2 x^{2} - x - 5,\qquad \text{余り }- 2 x + 5\]
STEP 3 検算
\[(x^{2} - x + 2)(2 x^{2} - x - 5)+(- 2 x + 5)=2 x^{4} - 3 x^{3} + x - 5\]

【答案（テストに書く形）】

\[\text{商 }2 x^{2} - x - 5,\ \text{余り }- 2 x + 5\]
