章末問題平面ベクトル

例題1〜10で学んだ手順だけで解ける問題です。まず、どの例題の型かを見分けるところから始めましょう。

  1. \(\vec a=\left(3,\ 2\right),\ \vec b=\left(-2,\ 3\right)\) のとき、内積 \(\vec a\cdot\vec b\)、\(|\vec a|,\ |\vec b|\)、およびなす角 \(\theta\) を求めよ。
  2. \(|\vec a|=3,\ |\vec b|=5,\ \vec a\cdot\vec b=4\) のとき、(1) \(|\vec a-2\vec b|\) (2) \(\vec a+t\vec b\) と \(\vec a-\vec b\) が垂直になる \(t\) の値を求めよ。
  3. △\(OAB\) で、辺 \(OA\) 上に \(OC=\dfrac{1}{2}\,OA\) となる点 \(C\)、辺 \(OB\) 上に \(OD=\dfrac{1}{2}\,OB\) となる点 \(D\) をとる。\(AD\) と \(BC\) の交点を \(P\) とするとき、\(\overrightarrow{OP}\) を \(\vec a=\overrightarrow{OA}\)、\(\vec b=\overrightarrow{OB}\) で表せ。
  4. 点 \(A\left(0,\ 4\right)\) を通り、\(\vec n=\left(2,\ -1\right)\) に垂直な直線の方程式を求めよ。また、原点とこの直線の距離を求めよ。
  5. 座標平面上に \(O(0,0),\ A\left(3,\ -1\right),\ B\left(2,\ 4\right)\) がある。△\(OAB\) の面積と、\(B\) から直線 \(OA\) に下ろした垂線の足 \(H\) の座標を求めよ。
  6. \(\triangle OAB\) に対して \(\overrightarrow{OP}=k\overrightarrow{OA}+\dfrac{2}{7}\overrightarrow{OB}\) とする。3点 \(A,\ B,\ P\) が一直線上にあるとき、\(k\) の値を求めよ。また \(P\) は線分 \(AB\) をどのような比に内分するか。
  7. \(\triangle OAB\) で、辺 \(OA\) 上に \(OP:PA=2:3\)、辺 \(OB\) 上に \(OQ:QB=1:1\) となる点 \(P,Q\) をとる。線分 \(AQ\) と \(BP\) の交点を \(X\) とするとき、\(\overrightarrow{OX}\) を \(\overrightarrow{OA},\overrightarrow{OB}\) で表せ。
  8. \(\vec a=(4,2),\ \vec b=(1,3)\) とする。実数 \(t\) が変化するとき、\(|\vec a+t\vec b|\) の最小値と、そのときの \(t\) の値を求めよ。
  9. \(\triangle ABC\) で \(BC=10,\ CA=8,\ AB=6\) とする。内心 \(I\) について \(\overrightarrow{AI}\) を \(\overrightarrow{AB},\ \overrightarrow{AC}\) で表せ。
  10. \(\vec a=(5,2),\ \vec b=(2,1),\ \vec c=(1,4)\) のとき、\(\vec a+t\vec b\) が \(\vec c\) と垂直になるような実数 \(t\) の値を求めよ。
