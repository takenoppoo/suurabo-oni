例題 2いろいろな式　分数式の恒等式（部分分数分解）

等式 \(\dfrac{5 x + 1}{(x - 1)(x + 2)}=\dfrac{a}{x - 1}+\dfrac{b}{x + 2}\) が \(x\) についての恒等式となるように、定数 \(a,b\) の値を定めよ。

解き方（まず考え方）

分母を払って整式の恒等式に直す。次に係数比較か数値代入で \(a,b\) を決める。分母の因数 \(x-\alpha\) を 0 にする値 \(x=\alpha\) を代入すると、一方の文字だけが残って速い。

コツ分母が邪魔なら、両辺に分母を掛けて消す。消えたら、あとは整式の恒等式。

解答

STEP 1 分母を払う
\[5 x + 1=a\left(x + 2\right)+b\left(x - 1\right)\]
STEP 2 右辺を展開して \(x\) で整理する
\[5 x + 1=2 a - b + x \left(a + b\right)\]
STEP 3 係数を比べて連立方程式を解く
\[\begin{cases}x:\ a+b=5\\ \text{定数項}:\ 2 a - b=1\end{cases}\]

解くと

\[a=2,\quad b=3\]
STEP 4 別解（数値代入法）

\(x=1\) を代入：「\(6=a(3)\)」より \(a=2\)。\(x=-2\) を代入：「\(-9=b(-3)\)」より \(b=3\)。

【答案（テストに書く形）】

\[a=2,\ b=3\]
